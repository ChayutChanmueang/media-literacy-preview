# 📎 เช็คลิสต์เอกสารแนบสำหรับยื่นคำขอ (CAMT)

> ⚠️ **หมายเหตุสำคัญ:** ฟอร์มต้นทางมีแค่ช่อง "เอกสารแนบ" แบบ Choose Files เดียว **ไม่ได้ระบุรายชื่อเอกสารบังคับไว้ชัดเจน** รายการด้านล่างเป็นข้อเสนอตามธรรมเนียมทั่วไปของการขอใช้บริการเครื่องแม่ข่าย/โดเมนภายในหน่วยงานมหาวิทยาลัย — **ควรสอบถามเจ้าหน้าที่ CAMT อีกครั้งก่อนยื่นจริง** ว่าต้องใช้เอกสารชุดใดบ้าง และรับไฟล์เดียวหรือหลายไฟล์

## เอกสารที่มีอยู่แล้วในโปรเจกต์ (พร้อมใช้อ้างอิง/แนบได้ทันที)

| เอกสาร | ตำแหน่งไฟล์ | ใช้ทำอะไร |
| --- | --- | --- |
| ข้อเสนอโครงการวิจัย | [`docs/wiki/tor/ข้อเสนอโครงการวิจัย.docx`](../tor/ข้อเสนอโครงการวิจัย.docx) | อธิบายที่มา วัตถุประสงค์ และแหล่งทุนของโครงการ — ใช้ประกอบ "เหตุผล/ความจำเป็น" ได้ |
| TOR ขอบเขตงานระบบเว็บแอปพลิเคชัน | [`docs/wiki/tor/TOR_ขอบเขตงาน-ระบบเว็บแอปพลิเคชัน.md`](../tor/TOR_ขอบเขตงาน-ระบบเว็บแอปพลิเคชัน.md) | ระบุขอบเขตทางเทคนิคของระบบที่จะ deploy บนเครื่องแม่ข่ายที่ขอ |
| เอกสาร Requirement ต้นทาง | [`Interactive เกม-ระบบ.docx`](../tor/Interactive%20เกม-ระบบ.docx) | เอกสารต้นฉบับที่มาของโครงการ |

## เอกสารที่ควรเตรียมเพิ่ม (ยังไม่มีในโปรเจกต์ — ต้องจัดทำ/ขอลายเซ็นก่อน)

- [ ] **บันทึกข้อความ/หนังสือขออนุมัติ** จากหัวหน้าหน่วยงานต้นสังกัดของผู้ยื่นคำขอ (ถ้า CAMT กำหนดให้ต้องมีผู้บังคับบัญชาลงนามรับรองก่อนขอใช้ทรัพยากร)
- [ ] **รายชื่อผู้ดูแลระบบ/ผู้ติดต่อฉุกเฉิน** ฝั่งทีมพัฒนา กรณี CAMT ต้องติดต่อเรื่องความปลอดภัย/downtime ของ Container
- [ ] **สรุป Tech Stack โดยย่อ** (Vite + React 19 SPA, Supabase เป็น backend ภายนอก, ไม่มี database ที่ต้องรันบน Container เอง) เผื่อเจ้าหน้าที่ต้องประเมินทรัพยากร (CPU/RAM/Storage) ที่จะจัดสรรให้

## ก่อนอัปโหลด

1. ยืนยันกับเจ้าหน้าที่ CAMT ว่ารับไฟล์แนบกี่ไฟล์ และฟอร์แมตใดบ้าง (PDF/DOCX)
2. ถ้าต้องรวมเป็นไฟล์เดียว ให้รวมข้อเสนอโครงการ + TOR ขอบเขตงาน เป็น PDF ฉบับเดียวก่อนแนบ
3. ตรวจว่าเอกสารไม่มีข้อมูลที่ล้าสมัย (เช่น deadline งานอบรมที่อาจเลื่อน) ก่อนส่ง
