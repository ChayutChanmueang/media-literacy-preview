# 📄 เอกสารยื่นขอใช้เครื่องแม่ข่ายและโดเมนเนม (CAMT)

**หน่วยงานที่ยื่นขอ:** วิทยาลัยศิลปะ สื่อ และเทคโนโลยี มหาวิทยาลัยเชียงใหม่ (College of Arts, Media and Technology — **CAMT**, Chiang Mai University)
**แบบฟอร์มต้นทาง:** "แบบฟอร์มขอใช้เครื่องแม่ข่ายและโดเมนเนม" (ระบบภายในของ CAMT — ดูภาพหน้าจอที่แนบในบทสนทนาที่จัดทำเอกสารชุดนี้)
**สถานะ:** 🔍 ร่างเตรียมยื่น — ยังไม่ได้ส่งคำขอจริง

---

## ทำไมต้องมีเอกสารชุดนี้

โครงการปัจจุบัน deploy อยู่บน Vercel (ดู [AGENT.md](../../../AGENT.md#deployment--domain)) และเคยมีข้อเสนอเรื่อง domain handoff ใน [US-03-R2](../../agile/user-stories/archives/US-03-R2.md) ซึ่งถูก **ยกเลิก** ไปแล้วเพราะตอนนั้นตัดสินใจใช้วิธี URL Redirect แทน (ดู [US-03-04](../../agile/user-stories/US-03-04.md))

เอกสารชุดนี้เป็นแนวทางใหม่ที่ชัดเจนกว่าเดิม: **ยื่นขอทั้ง subdomain `.camt.cmu.ac.th` และเครื่องแม่ข่ายแบบ Container ของ CAMT โดยตรง** (ไม่ใช่แค่ redirect ไป Vercel) เพื่อให้โปรเจกต์มีโดเมนสถาบันที่จำง่ายและมี hosting ที่ CAMT ดูแลเอง

> ⚠️ **ผลกระทบต่อสถาปัตยกรรม:** ถ้าคำขอนี้ได้รับอนุมัติและเริ่มใช้งานจริง จะต้องกลับไปทบทวน/อัปเดต `AGENT.md` (หัวข้อ Deployment/Domain), `docs/software/01-system-design.md`, และสถานะของ US-03-R2/US-03-04 ให้ตรงกับความเป็นจริง — งานนี้ยังไม่ได้ทำเพราะคำขอยังไม่ได้ยื่น/ยังไม่อนุมัติ

## ก่อนยื่นจริง ต้องกรอก/ยืนยันเองด้วย

- ชื่อ-นามสกุลผู้ยื่นคำขอ, เบอร์โทรศัพท์, อีเมลติดต่อกลับ
