# งวดที่ 1: รายงานความคืบหน้าและการส่งมอบงาน

**งาน:** พัฒนาเว็บแอปพลิเคชันเชิงโต้ตอบ (Interactive Web Application) พร้อมเกมประกอบสื่อการเรียนรู้เท่าทันสื่อ สำหรับผู้สูงอายุ — "รู้ทันสื่อ Interactive"
**โครงการวิจัย:** "สร้างเสริมสมรรถนะด้านสื่อสังคมออนไลน์ การหลอกลวงออนไลน์ และการรู้เท่าทันเทคโนโลยีปัญญาประดิษฐ์ สำหรับผู้สูงอายุ และแอดมินโซเชียลมีเดียชุมชน เพื่อยกระดับพฤฒพลังผู้สูงอายุในยุคดิจิทัล"
**อ้างอิง:** บันทึกข้อตกลง ลงวันที่ 11 สิงหาคม 2569 และเอกสารแนบท้าย (ขอบเขตของงาน TOR 6 หน้า, ใบเสนอราคาเลขที่ DITCQ 58/69) — ต้นฉบับ: [MOU โครงการวิจัย Masscom ร่วม CAMT.pdf](./MOU%20โครงการวิจัย%20Masscom%20ร่วม%20CAMT.pdf)

### 2.2 เว็บแอปพลิเคชันเวอร์ชันทดสอบ

- เป็นเว็บแอปพลิเคชันหน้าเดียว (SPA) ออกแบบสำหรับมือถือเป็นหลัก เปิดจากลิงก์ที่แชร์ใน LINE ได้ทันที ไม่ต้องล็อกอินและไม่ต้องติดตั้งแอป (TOR ข้อ 3.1, 3.1.1)
- ลำดับการใช้งาน: หน้าแรก → หน้ายินยอมให้เก็บข้อมูล (เลือกช่วงอายุและพื้นที่) → สารบัญบทเรียน → ดูคลิป → เล่นเกม → บทถัดไป → เกมปิดท้าย/ใบประกาศ (TOR ข้อ 3.3 "ดูวิดีโอก่อน ตามด้วยเกมของหัวข้อนั้น")
- มีโหมดวิทยากร (`/facilitator`) สำหรับฉายบนจอโปรเจกเตอร์ โดยข้ามไปบทใดก่อนก็ได้ (TOR ข้อ 3.1.3 (6))
- ประวัติการเปลี่ยนแปลงแต่ละเวอร์ชันอยู่ใน [changelog](../../changelog.md)

### 4.2 หลังกำหนดส่งงวดที่ 1 (11–18 ก.ย. 2569) — เวอร์ชัน 0.13.0

- **แบบประเมินตนเองก่อน/หลังเรียน (15–16 ก.ย.):** หน้าเริ่ม หน้าคำถาม และหน้าจบ ใช้ร่วมกันทั้งก่อนและหลังเรียน ชุดคำถามแยกเป็นไฟล์ข้อมูล และบันทึกการตอบรายข้อผ่านระบบบันทึกกิจกรรม (รองรับ TOR ข้อ 2.3 และ 3.4 เรื่องการเชื่อมโยงกับแบบประเมินก่อน–หลังการอบรม)
- **ดีไซน์ชุดใหม่ (15–16 ก.ย.):** ปุ่ม การ์ดคะแนน การ์ดเฉลย และการ์ดเรียนจบแบบเดียวกันทั้งระบบ ปรับเกม G1, G3, G6, G11, G13 และแยกหน้าเลือกพื้นที่ออกจากหน้ายินยอม เพื่อไม่ให้แต่ละหน้าแน่นเกินไปสำหรับผู้สูงอายุ
- **เกมต้นแบบ Generative AI GP1/GP2 (11 ก.ย.):** ผู้เล่นลากคำมาเติมเพื่อสร้างคำสั่งให้ AI ผลลัพธ์ท้ายเกมเป็นภาพ/ข้อความที่เตรียมไว้ล่วงหน้า ไม่เรียก AI จริง ยังไม่อยู่ในลำดับการเรียนและยังไม่ได้ทดสอบกับผู้สูงอายุ
- **โหมดปกติ/โหมดวิจัย และลำดับการใช้งาน (17–18 ก.ย.):** แยกเส้นทางทดสอบภายในออกจากเส้นทางผู้ใช้จริง และในโหมดเลือกบทเอง จบเกมหรือจบคลิปแล้วกลับหน้าเลือกบทเรียนทันที ลดขั้นตอนที่ผู้สูงอายุอาจสับสน
- **สภาพแวดล้อมพัฒนา (18 ก.ย.):** เพิ่มชุดติดตั้งรันระบบบน Docker
