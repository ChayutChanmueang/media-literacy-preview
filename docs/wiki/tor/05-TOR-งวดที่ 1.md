# เทมเพลตรายงานการส่งมอบงาน งวดที่ 1

## งานจ้างเหมาพัฒนาเว็บแอปพลิเคชันเชิงโต้ตอบ (Interactive Web Application) พร้อมเกมประกอบสื่อการเรียนรู้รู้เท่าทันสื่อ สำหรับผู้สูงอายุ

> **วิธีใช้เทมเพลตนี้**
>
> - แทนข้อความใน `[ ... ]` ด้วยข้อมูลจริง แล้วลบกล่องคำแนะนำนี้ก่อนส่ง
> - ทุกรายการตรวจสอบอ้างถึงข้อใน **[04-MOU ข้อ 3 รายละเอียดงาน](./04-TOR_MOU_Masscom_CAMT.md#3-รายละเอียดงาน)** (ถอดความจาก `04-MOU โครงการวิจัย Masscom ร่วม CAMT.pdf`) โดยใช้รหัสอ้างอิงรูปแบบ `MOU 3.x.x (ลำดับ)` เพื่อให้คณะกรรมการตรวจรับเปิดเทียบกับต้นฉบับได้ทันที
> - ช่องสถานะ: `☑` = ส่งมอบครบ, `◐` = ส่งมอบบางส่วน (อธิบายในหมายเหตุ), `☐` = ยังไม่ส่งมอบ — **ห้ามติ๊ก ☑ โดยไม่มีหลักฐานกำกับ** (ลิงก์ ภาพหน้าจอ หรือเลขเอกสารแนบ)
> - รายการที่ตัวระบบทำต่างจากข้อความใน MOU (เช่น ใช้วิธีอื่นที่ได้ผลเทียบเท่า) ให้ระบุวิธีที่ใช้จริงในหมายเหตุ อย่าเขียนว่าทำตาม MOU ทุกตัวอักษรถ้าไม่ได้ทำ
