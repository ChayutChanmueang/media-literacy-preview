# งวดที่ 2: ระบบฉบับปรับปรุงและข้อมูลประเมินผล

## สรุปการส่งมอบ

ตามไฟล์ `TOR พัฒนา web application v.1.1.docx` งวดที่ 2 เป็น **งวดสุดท้าย** ต้องส่งมอบภายใน **30 ตุลาคม 2569** (สิ้นสุดระยะเวลาดำเนินการตาม MOU ข้อ 2; TOR ระบุภายใน 90 วันนับจากวันที่ลงนามในสัญญา) และมีเงื่อนไขการจ่ายเงิน **ร้อยละ 40 ของค่าจ้างทั้งหมด** หลังคณะกรรมการตรวจรับพัสดุตรวจรับเรียบร้อยแล้ว

วงเงินอ้างอิงใน TOR 360,000 บาท คิดเป็นเงินงวดที่ 2 **144,000 บาท** หากวงเงินตามสัญญาเป็นจำนวนเดียวกัน

## รายการที่ต้องส่งมอบ

- [ ] **ระบบฉบับปรับปรุงหลังผ่านการทดสอบใช้งานจริง**
- [ ] ระบบเวอร์ชันล่าสุดที่พร้อมส่งมอบและใช้งานตามขอบเขต
- [ ] รายการแก้ไขจากผลทดสอบ/การใช้งานจริง และผลยืนยันว่าดำเนินการแล้ว
- [ ] **ข้อมูลสำหรับการประเมินผล** ของโครงการ
- [ ] ไฟล์หรือชุดข้อมูลที่สนับสนุนระยะที่ 3–4 ของแผนงานวิจัย
- [ ] เอกสารอธิบายวิธีใช้ข้อมูลเพื่อการติดตามและประเมินผลในช่วงเดือนที่ 6–12
- [ ] เอกสารส่งมอบระบบฉบับสุดท้าย เช่น คู่มือใช้งานและข้อมูลทางเทคนิคที่ตกลงเพิ่มเติมในสัญญา

## เกณฑ์ตรวจรับเบื้องต้น

- [ ] ระบบฉบับล่าสุดติดตั้ง/เผยแพร่และเปิดใช้งานได้จริง
- [ ] ฟังก์ชันที่แก้ไขจากการทดสอบใช้งานจริงทำงานได้ตามที่แจ้งแก้ไข
- [ ] เกมและเส้นทางการเรียนรู้ของทั้ง 3 หัวข้อยังใช้งานได้ครบหลังปรับปรุง
- [ ] ข้อมูลประเมินผลเปิดอ่าน/นำเข้า/ส่งออกได้ตามรูปแบบที่ตกลง
- [ ] ชุดข้อมูลไม่มีข้อมูลระบุตัวตนหรือ Raw IP ที่ไม่อยู่ในขอบเขตการเก็บข้อมูล
- [ ] มีคำอธิบายฟิลด์ แหล่งที่มา ช่วงเวลา และข้อจำกัดของข้อมูลครบถ้วน
- [ ] มีการส่งมอบลิงก์/ไฟล์/สิทธิ์เข้าถึงที่จำเป็นต่อการดูแลและประเมินผล

## เอกสาร/หลักฐานที่ควรแนบ

1. ใบส่งมอบงานงวดที่ 2 (งวดสุดท้าย)
2. Release note หรือรายการเปลี่ยนแปลงจาก prototype ถึงเวอร์ชันสุดท้าย
3. รายงานผลการทดสอบซ้ำหลังแก้ไข พร้อมหลักฐานการปิดประเด็น
4. ลิงก์ระบบ production หรือแพ็กเกจระบบฉบับสุดท้าย
5. ชุดข้อมูลสำหรับประเมินผลในรูปแบบที่ตกลง เช่น CSV/XLSX/JSON
6. Data dictionary และคำอธิบายวิธีส่งออก/นำเข้าข้อมูล
7. รายงานสรุปความครบถ้วนและคุณภาพข้อมูล
8. คู่มือการใช้งาน/ดูแลระบบและรายชื่อช่องทางส่งมอบสิทธิ์เข้าถึง (ถ้ามี)
