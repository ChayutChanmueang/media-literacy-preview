แนวคิดและสัญลักษณ์หลัก (Identity Concept)

ภาพตราสัญลักษณ์ประจำโครงการ "สานพลัง สังคมสูงวัย ใส่ใจสุขภาพ แพร่ • น่าน • เชียงใหม่" ถ่ายทอดภาพลักษณ์กิจกรรมชุมชน ความเอาใจใส่ และการประสานความร่วมมือระหว่างช่วงวัย โดยมีโครงสร้างหลัก 3 ธีมสีจำแนกตามจังหวัดจัดกิจกรรมจริงเพื่อสร้างประสบการณ์ที่น่าจดจำและเข้าถึงท้องถิ่น

อ้างอิงไฟล์ภาพ: docs/wiki/design/_logo.jpg

ความหมายสีสันของตัวแทนสัญลักษณ์หลัก

สีม่วง (เชียงใหม่): สัญลักษณ์ของเจดีย์ โบราณสถาน และตัวละครชายสูงอายุ สื่อถึงความฉลาด ภูมิปัญญา และเสถียรภาพ
สีส้ม (แพร่): สัญลักษณ์วัดพระธาตุช่อแฮ และตัวละครเด็กชูมือ สื่อถึงความกระตือรือร้น ครอบครัว และความอบอุ่นใจ
สีเขียว (น่าน): สัญลักษณ์ของใบไม้บนยอด และตัวละครหญิงสูงอายุ สื่อถึงความสมดุล ธรรมชาติบำบัด และความสมบูรณ์
สีเขียวหัวเป็ด/Teal: ตัวหนังสือของตราสัญลักษณ์หลัก สื่อถึงการมีสุขภาพดี มีความสุข และกระฉับกระเฉง
ข้อควรระวังการใช้งานโลโก้
  • Clear Space: ต้องเว้นช่องว่างอย่างน้อย 16px รอบโลโก้ในการจัดหน้าเว็บเสมอ
  • พื้นหลังหน้าเว็บ: แนะนำให้วางตราสัญลักษณ์บนพื้นหลังสีขาวหรือสีครีมสว่างเพื่อคอนทราสต์ที่ดี
  • ข้อห้ามบิดเบือน: ห้ามบีบ ยืด ปรับองศาเอียง หรือสลับสีกราฟิกแต่ละส่วนของโลโก้ต้นฉบับ
แรงบันดาลใจเลย์เอาต์ (GreenTravel UI Reference)

สคริปต์สลับธีมอัตโนมัติตามจังหวัดจัดกิจกรรม

ในแอปพลิเคชัน React+Vite ของจริง เมื่อได้รับข้อมูลพิกัดสถานที่จัดงานของวัยเก๋าจากหน้ากดยินยอม (Consent) สามารถเรียกใช้คำสั่งนี้เพื่อสลับธีมหน้าเว็บ:

// ฟังก์ชันเปลี่ยนธีมหลักของแอปตามจังหวัดจัดกิจกรรม
export const applyThemeFromProvince = (province) => {
  let themeName = 'teal'; // สีสากล/ทั่วไป
  
  if (province) {
    if (province.includes('เชียงใหม่')) themeName = 'purple';
    else if (province.includes('แพร่')) themeName = 'orange';
    else if (province.includes('น่าน')) themeName = 'green';
  }
  
  // สลับธีมสีทั้งหมดโดยการเพิ่มแอตทริบิวต์ในระดับราก (HTML)
  document.documentElement.setAttribute('data-theme', themeName);
  localStorage.setItem('user-selected-theme', themeName);
};
