# 🌐 เอกสารประสานงานระบบ DNS สำหรับเชื่อมต่อชื่อโดเมนสถาบันการศึกษา
**โครงการ:** Web Application สร้างเสริมสมรรถนะรู้เท่าทันสื่อ/สแกม/AI สำหรับผู้สูงอายุ (NAPLAB Media Literacy)  
**เป้าหมาย:** สำหรับประสานงานฝ่าย IT / ผู้ดูแลระบบเครือข่ายของสถาบันศึกษา เพื่อชี้โดเมนย่อย (Subdomain) มายังเซิร์ฟเวอร์ระบบ Vercel

---

## 📋 รายละเอียดการตั้งค่าระเบียน DNS (DNS Records Configuration)

ทางโครงการได้ใช้งานระบบโฮสติ้งบน **Vercel** สำหรับรองรับการใช้งานโปรเจกต์ดังกล่าว หากต้องการให้ระบบทำงานภายใต้ชื่อโดเมนย่อยของสถาบันการศึกษา (เช่น `media-literacy.yourdomain.ac.th`) ขอความอนุเคราะห์ผู้ดูแลระบบในการตั้งค่าระเบียนข้อมูล DNS ดังต่อไปนี้:

### 1. กรณีใช้งานเป็นโดเมนย่อย (Subdomain) — แนะนำ (Recommended)
ให้เพิ่มระเบียนประเภท **CNAME** ในระบบจัดการ DNS ของท่าน:

| ประเภทระเบียน (Type) | ชื่อโฮสต์ย่อย (Name / Host) | ค่าปลายทาง (Value / Points to) | TTL |
| :---: | :---: | :---: | :---: |
| **CNAME** | `media-literacy` *(หรือชื่อย่อยตามตกลง)* | `cname.vercel-dns.com.` | Auto / 3600 (1 ชม.) |

> [!NOTE]  
> ปลายสุดของค่าปลายทาง `cname.vercel-dns.com.` แนะนำให้ใส่จุดทศนิยมปิดท้ายตามมาตรฐานสากล หากระบบจัดการ DNS ของท่านรองรับ

---

### 2. กรณีใช้งานเป็นโดเมนหลัก (Apex / Root Domain - ถ้ามี)
หากต้องการใช้ชื่อโดเมนหลักโดยไม่มีโฮสต์ย่อยนำหน้า (เช่น `yourdomain.ac.th`) ชี้มาที่ระบบโดยตรง ให้เพิ่มระเบียนประเภท **A Record**:

| ประเภทระเบียน (Type) | ชื่อโฮสต์ย่อย (Name / Host) | ค่าปลายทาง (IP Address) | TTL |
| :---: | :---: | :---: | :---: |
| **A** | `@` | `76.76.21.21` | Auto / 3600 (1 ชม.) |

---

## 🔒 ความปลอดภัยและการเข้ารหัส (SSL / HTTPS)
หลังจากระเบียน DNS ถูกสร้างและชี้เป้าหมายมายัง Vercel เรียบร้อยแล้ว:
* ระบบ **Vercel จะดำเนินการขอและสร้างใบรับรองความปลอดภัย SSL/TLS (HTTPS) จาก Let's Encrypt ให้โดยอัตโนมัติ**
* โดเมนย่อยดังกล่าวจะสามารถเข้าใช้งานแบบเข้ารหัสผ่านระบบรักษาความปลอดภัย (`https://`) ได้โดยทันที โดยที่สถาบันศึกษาไม่ต้องเตรียมไฟล์ Certificate (.crt / .key) ให้แต่อย่างใด

---

## 🛠️ ขั้นตอนการดำเนินการร่วมกัน
1. **ผู้พัฒนา:** ทำการเพิ่มชื่อโดเมนที่ต้องการลงในระบบ Vercel Dashboard ของฝั่งโครงการ
2. **ฝ่าย IT สถาบันศึกษา:** นำข้อมูล CNAME / A Record ด้านบนไปติดตั้งในระบบ DNS Nameserver ของสถาบัน
3. **การทดสอบการเชื่อมต่อ:**
   * ตรวจสอบสถานะการเชื่อมโยงของโดเมนผ่าน Command Prompt หรือ Terminal:
     ```bash
     nslookup media-literacy.yourdomain.ac.th
     ```
   * ตรวจสอบว่ามีค่า `cname.vercel-dns.com` หรือไอพีปลายทางตอบกลับมาถูกต้องหรือไม่
4. **ความล่าช้าในการเผยแพร่ข้อมูล (Propagation):** หลังจากตั้งค่าเสร็จสิ้น ข้อมูลใหม่อาจใช้เวลาระหว่าง 15 นาที ถึง 24 ชั่วโมง ในการอัปเดตไปทั่วโลกตามรอบการอัปเดตของเซิร์ฟเวอร์ผู้ให้บริการอินเทอร์เน็ตแต่ละราย
