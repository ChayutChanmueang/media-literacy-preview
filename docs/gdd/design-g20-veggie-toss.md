# G20 — ผักบุ้งลอยฟ้า (Veggie Toss / โยนลงจาน)

> สถานะ: 🔍 In QA — เปิดในโหมดอิสระ หมวด "เกมสนุก" (lesson id `g20`) + Dev Game Hub (`/dev/games`) — ไม่อยู่ในโหมดเนื้อเรื่อง/โหมดวิจัย (เดิมคือ prototype GP9)
> โค้ด: `src/components/G20VeggieToss.tsx`
> ต้นแบบ: ไฟล์ HTML `shootball7.html` ของทีม (เกมโยนผักบุ้งจากกระทะลงจาน แนวชู้ตลูกบอลลงห่วง)

## เป้าหมาย

เกมโยนของลงเป้าเพื่อความสนุกล้วน ๆ — **ไม่มีเนื้อหาบทเรียน**

## Flow

1. `GameIntro` — "ผักบุ้งลอยฟ้า" + วิธีเล่น (แทนหน้าเริ่มเกมของต้นแบบ)
2. หน้าเล่น — พื้นหลังไล่สีน้ำเงิน → แดง → เหลือง แบบเดียวกับต้นแบบ ด้านบนเป็นแถบหัวแบบเดียวกับ G18/G19 (ป้ายเล็ก "เลเวล" ทางซ้าย / "โยนได้อีก" ทางขวา เหนือตัวเลขใหญ่สีส้มเข้ม) ไม่มีแถบข้อความแนะนำบนจอ (ข้อความสถานะมีให้โปรแกรมอ่านหน้าจอเท่านั้น) แล้วจึงเป็นสนาม 9:16 (canvas 540×960 เหมือนต้นแบบ ย่อ/ขยายให้พอดีพื้นที่ที่เหลือ)
   - กระทะอยู่ล่างสุด ผักบุ้ง 🥬 วางในกระทะ ชามมุมมองด้านข้าง (วาดด้วย canvas: ชามขาวคาดแถบน้ำเงิน ปากชามกว้าง 140) อยู่ด้านบน — ในโค้ด/ข้อความยังเรียกว่า "จาน"
   - **แตะครึ่งล่างของสนามแล้วลากนิ้วขึ้น** — มีลูกศรทรงข้าวหลามตัดยาว (ขอบขาว) บอกทิศ/แรง — ยิ่งลากยาว ลูกศรยิ่งยาว สีไล่จากเขียว (ใกล้ผักบุ้ง) → เหลือง → แดง (ที่แรงสูงสุด) → ปล่อยนิ้วเพื่อโยน (ลากขึ้นไม่ถึง 20 หน่วย = ไม่โยน + "ลากขึ้นด้านบนอีกนิด แล้วปล่อยนิ้วนะ" ไม่เสียครั้ง)
   - ผักบุ้งชนกำแพงซ้าย-ขวาแล้ว **ชิ่ง** กลับ (เสียแรง 20%)
   - ตกลงผ่านจานตอนขาลง (ในระยะ ±30 หน่วยจากแนวจาน และอยู่ในความกว้างจาน 140) → "✓ ลงจานแล้ว! เก่งมาก" ผักบุ้งค้างอยู่ในชาม 0.9 วิ (ครึ่งล่างจมหลังขอบชามด้านหน้า) (ไหลไปตามจานถ้าจานเลื่อน) แล้วขึ้น **เลเวลใหม่**
   - หล่นหลุดขอบล่าง → "ยังไม่ลงจาน ลองใหม่นะ 💪 ชิ่งกำแพงข้าง ๆ ก็ได้" ผักบุ้งกลับมาที่กระทะ
3. โยนครบ **15 ครั้ง** (ทั้งลงและไม่ลงจานนับหมด) → แถบสถานะ "โยนครบ 15 ครั้งแล้ว มาดูผลกัน" + ข้อความชมลอยขึ้นกลางสนาม "เก่งมาก! 🎉 / โยนครบ 15 ครั้งแล้ว" (ตัวขาวขอบน้ำตาลเข้ม แบบเดียวกับ G19) → หน้าผลงาน "เก่งมาก! เสิร์ฟลงจานได้ N จาน · ไปถึงเลเวล N" + "สถิติดีที่สุด" / "🎉 สถิติใหม่ของคุณ!" ตั้งแต่รอบที่ 2 → ปุ่มส้ม "เล่นอีกครั้ง" / "จบเกม" → `onFinish(stars)`

## ความยากตามเลเวล (เหมือนต้นแบบ)

| เลเวล | จาน |
|---|---|
| 1 | อยู่กลางจอ นิ่ง |
| 2 | ย้ายไปตำแหน่งสุ่ม นิ่ง |
| 3+ | ตำแหน่งสุ่ม เลื่อนซ้าย-ขวา ความเร็ว 2 + 0.5 × (เลเวล − 3) สูงสุด **6** (ต้นแบบ 8) ชนขอบ (เว้น 40) แล้วกลับทิศ |

ฟิสิกส์ใช้ค่าเดียวกับต้นแบบ: แรงโน้มถ่วง 0.8, แรงโยน = ระยะลาก × 0.08 (แนวตั้ง × 1.5, ขึ้นเร็วสุด 38) — แต่คิดตามเวลาจริง (เทียบ 60 fps) แทนการคิดต่อเฟรม จอ 90/120 Hz จึงไม่เล่นเร็วขึ้น 2 เท่า และตรวจการลงจานตลอดเส้นทางที่ตกในเฟรมนั้น ตกเร็วแค่ไหนก็ไม่ทะลุจาน

## คะแนน / ดาว

- ผลของรอบ = จำนวนจานที่เสิร์ฟได้ (= เลเวลที่ไปถึง − 1)
- สถิติดีที่สุดเก็บไว้ระหว่างเปิดเกมอยู่เท่านั้น
- ดาวคิดจากสถิติดีที่สุดตอนกด "จบเกม": ≥ 8 จาน = 3 ดาว, ≥ 4 จาน = 2 ดาว, น้อยกว่านั้น = 1 ดาว

| ป้ายเวลา/เลเวลลอยทับบนสนาม | แถบหัวแบบ G18/G19 เหนือสนาม | หน้าตาเหมือนเกมอื่น และไม่บังชาม/ไม่ถูกตัดบนจอเตี้ย |

| เส้นประสีขาวบอกทิศ/แรง | ลูกศรทรงข้าวหลามตัด สีไล่เขียว → แดงตามแรง ขอบขาว | เห็นชัดกว่าว่าโยนไปทางไหน แรงแค่ไหน |

## เรื่องที่ยังเปิดอยู่

- ยังไม่ได้ทดสอบกับผู้สูงอายุจริง — จำนวนครั้ง (15), ความเร็วจานสูงสุด (6) และเกณฑ์ดาว (4 / 8 จาน) เป็นค่าประมาณ อาจต้องปรับ
- ยังไม่มีตัวช่วยเล็ง (เช่น จุดแสดงเส้นทางที่ผักบุ้งจะลอยไป) — ถ้าทดสอบแล้วโยนยากเกิน ค่อยเพิ่ม
- ตำแหน่งจานสุ่มด้วย `Math.random` (ไม่ได้ใช้ seed รายวันแบบ G19) — ถ้าจะทำตารางคะแนนเทียบกัน ควรเปลี่ยนเป็น seed ตามวันที่
- ไม่มีเสียงประกอบ (ต้นแบบก็ไม่มี)
- อีโมจิแสดงตามฟอนต์ของเครื่อง หน้าตาจึงต่างกันระหว่าง iOS / Android
- สถิติดีที่สุดหายเมื่อออกจากเกม — ถ้าต้องการเก็บข้ามครั้ง ต้องผ่าน `progressService`
