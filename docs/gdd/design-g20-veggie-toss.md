## Flow

1. `GameIntro` — "ผักบุ้งลอยฟ้า" + วิธีเล่น (แทนหน้าเริ่มเกมของต้นแบบ)
2. หน้าเล่น — ตาม Figma "Scammer Game Prototype" (node `3028:13071`): พื้นหลังไล่สีเขียวอ่อน `#EEFEE9 → #DCF4D4` ด้านบนเป็นการ์ดหัวจอสีขาว (`GameStageHeader` ตัวเดียวกับ G17–G19: ซ้าย "โยนได้อีก n" / ขวา "ด่าน n") ไม่มีแถบข้อความแนะนำบนจอ (ข้อความสถานะมีให้โปรแกรมอ่านหน้าจอเท่านั้น) แล้วจึงเป็นสนาม 9:16 (canvas 540×960 เหมือนต้นแบบ ย่อ/ขยายให้พอดีพื้นที่ที่เหลือ ไม่มีกรอบ/เงา กลืนกับพื้นหลัง)
   - ผักเป็นไอคอนบรอกโคลีจาก Figma (**ภาพชั่วคราว** — ชื่อเกม/ข้อความยังเรียก "ผักบุ้ง" ตามเดิม รอภาพผักบุ้งจริง) (`public/assets/g20/broccoli.svg` กรอบ 108 หน่วย = 80px บนดีไซน์กว้าง 400) วางอยู่ล่างสนาม — **กระทะซ่อนไว้ก่อน**ตาม Figma (โค้ดวาด `drawPan` ยังอยู่ เปิดคืนได้ที่ `SHOW_PAN` ข้อความ "แตะที่ผัก" จะกลับเป็น "แตะที่กระทะ" เอง) ใต้ผักมีป้าย "เหลือ n ต้น" บอกจำนวนผักที่ยังโยนได้ (ค่าเดียวกับ "โยนได้อีก" บนการ์ดหัวจอ) ชามมุมมองด้านข้าง (วาดด้วย canvas: ชามขาวคาดแถบน้ำเงิน ปากชามกว้าง 140) อยู่ด้านบน — **คงชามไว้ ไม่เปลี่ยนเป็นจาน+มีด-ส้อมแบบใน Figma** ตามที่ทีมกำหนด — ในโค้ด/ข้อความยังเรียกว่า "จาน"
   - **แตะครึ่งล่างของสนามแล้วลากนิ้วขึ้น** — มีลูกศรทรงข้าวหลามตัดยาว (ขอบเทาเข้ม `#4B4B4B` ให้เห็นบนพื้นเขียวอ่อน วาดทับชามแต่อยู่ใต้ผัก) บอกทิศ/แรง — ยิ่งลากยาว ลูกศรยิ่งยาว **ปลายลูกศรหยุดก่อนถึงนิ้ว 48 หน่วย (~35px)** (อยู่ใต้นิ้วเล็กน้อยเมื่อลากขึ้น) นิ้วจึงไม่บังปลายลูกศร — แรงโยนยังคิดจากระยะลากเต็มเหมือนเดิม สีไล่จากเขียว (ใกล้ผักบุ้ง) → เหลือง → แดง (ที่แรงสูงสุด) → ปล่อยนิ้วเพื่อโยน (ลากขึ้นไม่ถึง 20 หน่วย = ไม่โยน + "ลากขึ้นด้านบนอีกนิด แล้วปล่อยนิ้วนะ" ไม่เสียครั้ง)
   - ผักบุ้งชนกำแพงซ้าย-ขวาแล้ว **ชิ่ง** กลับ (เสียแรง 20%)
   - ตกลงผ่านจานตอนขาลง (ในระยะ ±30 หน่วยจากแนวจาน และอยู่ในความกว้างจาน 140) → "✓ ลงจานแล้ว! เก่งมาก" ผักบุ้งค้างอยู่ในชาม 0.9 วิ (ครึ่งล่างจมหลังขอบชามด้านหน้า) (ไหลไปตามจานถ้าจานเลื่อน) แล้วขึ้น **เลเวลใหม่**
   - หล่นหลุดขอบล่าง → "ยังไม่ลงจาน ลองใหม่นะ 💪 ชิ่งกำแพงข้าง ๆ ก็ได้" ผักกลับมาที่จุดเริ่ม
3. โยนครบ **15 ครั้ง** (ทั้งลงและไม่ลงจานนับหมด) → แถบสถานะ "โยนครบ 15 ครั้งแล้ว มาดูผลกัน" + ข้อความชมลอยขึ้นกลางสนาม "เก่งมาก! 🎉 / โยนครบ 15 ครั้งแล้ว" (ตัวขาวขอบน้ำตาลเข้ม แบบเดียวกับ G19) → หน้าผลงาน "เก่งมาก! เสิร์ฟลงจานได้ N จาน · ไปถึงเลเวล N" + "สถิติดีที่สุด" / "🎉 สถิติใหม่ของคุณ!" ตั้งแต่รอบที่ 2 → ปุ่มส้ม "เล่นอีกครั้ง" / "จบเกม" → `onFinish(stars)`

## ความยากตามเลเวล (เหมือนต้นแบบ)

| เลเวล | จาน |
|---|---|
| 1 | อยู่กลางจอ นิ่ง |
| 2 | ย้ายไปตำแหน่งสุ่ม นิ่ง |
| 3+ | ตำแหน่งสุ่ม เลื่อนซ้าย-ขวา ความเร็ว 2 + 0.5 × (เลเวล − 3) สูงสุด **6** (ต้นแบบ 8) ชนขอบ (เว้น 40) แล้วกลับทิศ |

ฟิสิกส์ใช้ค่าเดียวกับต้นแบบ: แรงโน้มถ่วง 0.8, แรงโยน = ระยะลาก × 0.08 (แนวตั้ง × 1.5, ขึ้นเร็วสุด 38) — แต่คิดตามเวลาจริง (เทียบ 60 fps) แทนการคิดต่อเฟรม จอ 90/120 Hz จึงไม่เล่นเร็วขึ้น 2 เท่า และตรวจการลงจานตลอดเส้นทางที่ตกในเฟรมนั้น ตกเร็วแค่ไหนก็ไม่ทะลุจาน

## คะแนน / ดาว

- ผลของรอบ = จำนวนจานที่เสิร์ฟได้ (= เลเวลที่ไปถึง − 1)
- สถิติดีที่สุดเก็บไว้ระหว่างเปิดเกมอยู่เท่านั้น
- ดาวคิดจากสถิติดีที่สุดตอนกด "จบเกม": ≥ 8 จาน = 3 ดาว, ≥ 4 จาน = 2 ดาว, น้อยกว่านั้น = 1 ดาว

## เรื่องที่ยังเปิดอยู่

- ยังไม่ได้ทดสอบกับผู้สูงอายุจริง — จำนวนครั้ง (15), ความเร็วจานสูงสุด (6) และเกณฑ์ดาว (4 / 8 จาน) เป็นค่าประมาณ อาจต้องปรับ
- ยังไม่มีตัวช่วยเล็ง (เช่น จุดแสดงเส้นทางที่ผักบุ้งจะลอยไป) — ถ้าทดสอบแล้วโยนยากเกิน ค่อยเพิ่ม
- ตำแหน่งจานสุ่มด้วย `Math.random` (ไม่ได้ใช้ seed รายวันแบบ G19) — ถ้าจะทำตารางคะแนนเทียบกัน ควรเปลี่ยนเป็น seed ตามวันที่
- ไม่มีเสียงประกอบ (ต้นแบบก็ไม่มี)
- อีโมจิแสดงตามฟอนต์ของเครื่อง หน้าตาจึงต่างกันระหว่าง iOS / Android
- สถิติดีที่สุดหายเมื่อออกจากเกม — ถ้าต้องการเก็บข้ามครั้ง ต้องผ่าน `progressService`

**คำถามที่ต้องการตอบ:** ฉากที่มองเห็น "ความสูง" ระหว่างจุดโยนกับชาม ช่วยให้ผู้เล่นเข้าใจว่าต้องโยนเป็นวิถีโค้ง (ไม่ใช่ยิงตรงขึ้น) หรือไม่

กติกา/UI เหมือน G20 ทุกอย่าง (การ์ดหัวจอ, ลูกศรเล็ง, ป้าย "เหลือ n ต้น", ฟิสิกส์, ระยะรับชาม, ความยากตามเลเวล) ต่างกันเฉพาะฉาก (วาดบน canvas ไม่มีไฟล์ภาพ):

- **ด้านบน — ผนังร้าน:** กันสาดลายทางแดง-ขาวขอบหยัก + ชั้นวางขวดโหล (อยู่เหนือแนวที่ชามเลื่อน ไม่บังชาม)
- **ชามวางบนโต๊ะไม้** เต็มความกว้าง (ชามเลื่อนไปมาบนโต๊ะได้) มีเงาชามบนโต๊ะ
- **ตรงกลาง — ผนังกระเบื้อง** คั่นระหว่างโต๊ะกับเตา ให้เห็นระยะความสูง
- **ด้านล่าง — เตา** + กระทะมุมข้าง (ด้ามจับขวา) ผักวางอยู่ในกระทะ (ขอบหน้ากระทะบังโคนผัก) — กระทะแสดงตลอด ข้อความจึงใช้ "แตะที่กระทะ"
- ผักกับกระทะอยู่สูงกว่า G20 เล็กน้อย (ผักที่ y 760 แทน 850 ในสนาม 540×960) เพื่อวางบนเตา → ระยะโยนสั้นลงนิดหน่อย
- ป้าย "เหลือ n ต้น" ย้ายไปอยู่หน้าเตา ใต้กระทะ (ระหว่างปุ่มเตาสองข้าง)
- **จำกัดระยะลูกศร (ค่าเริ่มทดลอง):** ปลายลูกศรไปได้ไกลสุดเป็นรัศมีจากผัก = ระยะจากผัก (y 760) ถึงขอบล่างโต๊ะ (y 352) = 408 หน่วยสนาม — ลากเลยไปลูกศรก็ไม่ยาวขึ้น แค่หมุนตามทิศ; จำกัดที่ระยะลากด้วย (408 + 48 ที่เว้นปลายลูกศรไว้ใต้นิ้ว) แรงโยนจึงตรงกับลูกศรเสมอ — โยนตรงขึ้นไม่ต่างจากเดิม (แรงขึ้นตันที่ระยะลาก ~317 อยู่แล้ว) แต่ลากเฉียง/ด้านข้างไกล ๆ ได้แรงแนวนอนสูงสุดน้อยลง (`AIM_RADIUS` ใน `G20KVeggieTossKitchen.tsx`)
- **จุดวิถีโยน (trajectory dots):** ระหว่างเล็ง จำลองการโยนด้วยฟิสิกส์เดียวกับเกม (แรงโน้มถ่วง ชิ่งกำแพง ทีละเฟรม 60 fps) แล้ววาดจุดขาวขอบเทาเข้ม (รัศมี 6 ทุก 3 เฟรม) เริ่มเมื่อเส้นทางไปได้ไกลเท่าความยาวลูกศร (ต่อจากปลายลูกศร) จนตกกลับต่ำกว่าผิวโต๊ะ จางลงเล็กน้อยไปทางปลาย — ลากสั้นจนไม่โยนจะไม่มีจุด — เปิด/ปิดได้ที่ `SHOW_TRAJECTORY` (true/false) (จอ 90/120 Hz เกมคิดตามเวลาจริงจึงอาจคลาดจากจุดได้เล็กน้อย)
- **ฉากเต็มจอ:** พื้นที่เกมเริ่มเหนือขอบล่างการ์ดหัวจอ 24px (พอดีให้ฉากเติมใต้มุมโค้งของการ์ด) ลงไปถึงขอบล่างจอ — สนาม 540×960 ย่อ/ขยายให้พอดีพื้นที่นี้ทั้งสนาม (ไม่ยืดภาพ) วางชิดขอบล่าง (เตาติดขอบล่างจอ) และกึ่งกลางแนวนอน; กันสาดจึงแขวนอยู่ใต้การ์ดหัวจอพอดี
- พื้นที่ที่เหลือวาดฉากต่อ: จอสูง → เหนือกันสาดเป็นผนังหน้าร้าน + คานไม้ที่กันสาดแขวนอยู่, จอเตี้ย/กว้าง → ด้านข้างวาดกระเบื้อง โต๊ะ เตา กันสาดต่อ (กำแพงชิ่งยังอยู่ที่ขอบสนาม 540 เดิม ซึ่งบนมือถือทั่วไปห่างขอบจอแค่ไม่กี่ px)
