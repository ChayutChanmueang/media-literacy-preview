## 1. Overview (ภาพรวมของเกม)

เกม **G10 — นี้แอปฉัน นั้นแอปใคร?** เป็นเกมจำลอง **หน้าจอรวมแอปในมือถือ** เพื่อฝึกให้ผู้สูงอายุ **สังเกตว่าเครื่องตัวเองมีแอปแปลกปลอมแฝงอยู่หรือไม่ แล้วลบออก** — ภัยจริงคือแอปปลอม (เช่น แอปกู้เงิน แอปจ่ายบิลปลอม หรือแอปรีโมตที่ให้คนร้ายควบคุมเครื่องและดูดเงิน) ที่มักถูกหลอกให้ติดตั้งจากลิงก์นอก Store

หน้าจอเกมเป็น **ตารางไอคอนแอป** ปะปนกันระหว่าง **แอปจริง (ปลอดภัย)** กับ **แอปปลอม (อันตราย)** ผู้เล่นต้อง "สำรวจเครื่องตัวเอง" แตะดูแต่ละแอปเพื่อตรวจ แล้ว **ลบเฉพาะแอปปลอม** โดยเก็บแอปจริงไว้

> 💡 **หลักการออกแบบสำคัญ (ตามที่ทีมกำหนด):** ไอคอนแอปใช้ **ชุดหน้าตาที่คุ้นเคยและซ้ำเดิม** เพื่อให้ผู้สูงอายุจำได้ง่าย ไม่ต้องเพ่งค้นหานานจนเบื่อ — ความยากมาจาก "จำนวนแอป" และ "ความเนียนของชื่อ/ที่มา" ไม่ใช่การเปลี่ยนไอคอนให้จำยาก

> ⚠️ **กติกาโครงการที่ยึดถือ:** ไม่มีจับเวลา ไม่มีจอแพ้ (Game Over) กดพลาด (ลบแอปจริง / เผลอเก็บแอปปลอม) = คำแนะนำนุ่มนวล ไม่ใช่การลงโทษ ([Art Direction](./03-art-direction.md))

## 2. Core Gameplay Loop (วงลูปหลักการเล่น)

มี **2 ทางที่ทำให้ด่านจบ**: (ก) ลบแอปปลอมครบเอง = จบด่านอัตโนมัติ, หรือ (ข) ผู้เล่นกดปุ่ม **"ครบแล้ว ✓"** เมื่อคิดว่าตรวจครบแล้ว — ถ้ายังมีแอปปลอมเหลือ ระบบจะ**เฉลยแอปที่มองข้าม**ก่อนไปด่านต่อไป (ไม่มีทางตัน/ไม่มีจอแพ้)

```mermaid
flowchart TD
    Start[เริ่มด่าน] --> Grid[แสดงตารางไอคอนแอป จริงปนปลอม]
    Grid --> Tap[ผู้เล่นแตะแอป 1 อันเพื่อ \"ตรวจสอบ\"]
    Grid --> Done[กดปุ่ม \"ครบแล้ว ✓\"]
    Tap --> Inspect[การ์ดขยาย: ชื่อแอป + ที่มา Store/ลิงก์ + สิทธิ์ที่ขอ]
    Inspect --> Decide{ตัดสินใจ}
    Decide -- 🗑️ ลบแอปนี้ --> JudgeRemove
    Decide -- ✓ เก็บไว้ แอปดี --> JudgeKeep
    Decide -- ปิด ดูอันอื่นก่อน --> Grid

    JudgeRemove{เป็นแอปปลอมจริงไหม?}
    JudgeRemove -- ใช่ ปลอม --> GoodRemove[✓ ถูก! แอปปลอมหายไป + เสียงชื่นชม]
    JudgeRemove -- ไม่ เป็นแอปจริง --> OopsRemove[การ์ด: อันนี้แอปดีนะคะ อธิบายจุดสังเกต แล้วคืนแอปกลับ]

    JudgeKeep{เป็นแอปจริงไหม?}
    JudgeKeep -- ใช่ จริง --> GoodKeep[✓ ถูก! เก็บแอปดีไว้ถูกแล้ว]
    JudgeKeep -- ไม่ เป็นแอปปลอม --> OopsKeep[การ์ด: อันนี้น่าสงสัยนะคะ ชี้จุดสังเกต แล้วให้ลองใหม่]

    GoodRemove --> Check{ลบแอปปลอมครบหรือยัง?}
    GoodKeep --> Grid
    OopsRemove --> Grid
    OopsKeep --> Grid
    Check -- ยังไม่ครบ --> Grid
    Check -- ครบ --> LevelEnd[ด่านผ่าน: เครื่องสะอาดแล้ว + สรุปข้อคิด]

    Done --> Submit{ยังมีแอปปลอมเหลือไหม?}
    Submit -- ไม่เหลือ ครบแล้ว --> LevelEnd
    Submit -- ยังเหลือ --> Reveal[เฉลย: คุณมองข้ามแอปปลอม N อัน + ชี้จุดสังเกต นับเป็นพลาด]
    Reveal --> LevelEnd

    LevelEnd --> AllDone{ครบ 5 ด่าน?}
    AllDone -- ยัง --> Start
    AllDone -- ครบ --> Complete[หน้าสรุปเชิงบวก + ส่งดาวให้ GameShell ผ่าน onFinish]
```

## 3. Level & Stage Structure (โครงสร้าง 3 เลเวล / 5 ด่าน)

ความยากไล่จากตารางเล็กแอปน้อย ไปตารางใหญ่ที่แอปปลอมซ่อนตัวในหมู่แอปจริงจำนวนมาก:

| เลเวล | ขนาดตาราง | จำนวนช่อง | แอปจริง | แอปปลอม | จำนวนด่าน | โจทย์ที่ฝึก |
|-------|-----------|-----------|---------|---------|-----------|-------------|
| **1** | 2 × 2 | 4 | 2–3 | 1–2 | **2 ด่าน** | เริ่มสังเกต — แอปปลอมเห็นง่าย ชื่อ/ที่มาผิดชัด |
| **2** | 3 × 2 | 6 | 4–5 | 1–2 | **2 ด่าน** | แอปเยอะขึ้น ต้องไล่ตรวจให้ครบ |
| **3** | 3 × 3 | 9 | 8 | **1** | **1 ด่าน** | แอปปลอมเหลือตัวเดียวซ่อนในหมู่แอปจริง 8 ตัว — ต้องค้นหาละเอียด |
| | | | | | **รวม 5 ด่าน** | |

- **จำนวนแอปจริง/ปลอมสุ่มในกรอบที่กำหนด** ต่อด่าน (เช่น เลเวล 1 สุ่มปลอม 1 หรือ 2) — ทำให้เล่นซ้ำได้ไม่จำตำแหน่ง
- **ตำแหน่งในตารางสุ่มทุกครั้ง** ไม่ให้เดาจากตำแหน่งเดิม
- จบด่าน = "เครื่องสะอาดแล้ว 🎉" + การ์ดสรุปข้อคิด 1 ประโยค (เช่น "แอปการเงินให้โหลดจาก Play Store / App Store เท่านั้นนะคะ")
- แอปปลอมและแอปจริง**ดึงจากคลังเดียวกัน** (§7) ที่ใช้ **ชุดไอคอนหน้าตาซ้ำเดิม** เพื่อความคุ้นเคย

## 4. What Makes an App "Fake" — จุดสังเกตที่เกมสอน

เนื่องจากไอคอน "หน้าตาเหมือนกัน" จุดสังเกตหลักจึงอยู่ที่ **ชื่อแอป + ที่มา** (อ่านได้ ตัวใหญ่) ไม่ใช่การเพ่งรูปไอคอน:

| จุดสังเกต | แอปจริง (ตัวอย่าง) | แอปปลอม (ตัวอย่าง) | คำอธิบาย |
|-----------|---------------------|---------------------|----------|
| **ที่มา (Source)** | ติดตั้งจาก Play Store / App Store | "ติดตั้งจากลิงก์" / ไฟล์ `.apk` | แอปการเงินที่ไม่ได้มาจาก Store ทางการมักเป็นมัลแวร์ |
| **ชื่อชวนสงสัย** | "ธนาคาร (แอปทางการ)" | "เงินด่วนทันใจ", "สินเชื่อไวรับเงิน 30 วิ" | แอปกู้เงิน/เงินด่วนนอก Store คือกับดักดูดเงิน |
| **ชื่อเลียนแบบ/สะกดเพี้ยน** | "LINE" | "L1NE", "LINE Official ฟรี" | ปลอมชื่อแอปดังโดยสะกดผิดนิดเดียว |
| **แอปซ้ำผิดปกติ** | แอปธนาคารมีอันเดียว | มีแอปธนาคารชื่อคล้ายกัน 2 อัน | ของจริงไม่ซ้ำ — ตัวปลอมมาแอบวางคู่กัน |
| **ขอสิทธิ์เกินจำเป็น** | แอปกล้องขอใช้กล้อง | "แอปแต่งรูป" ขอสิทธิ์ควบคุมหน้าจอ/อ่าน SMS | แอปรีโมตดูดเงินขอสิทธิ์ Accessibility/อ่าน OTP |
| **หมวดหมู่ล่อใจ** | — | "ดูดวงแจกเงิน", "ลุ้นโชคฟรี", "เกมได้เงินจริง" | ล่อให้ติดตั้งด้วยของฟรี/รางวัล |

> **ข้อคิดหลักที่ผู้เล่นต้องได้กลับบ้าน:** ก่อนเชื่อแอปไหน ให้ดู **"มาจากไหน"** (Store ทางการเท่านั้น) และ **"ขอสิทธิ์อะไร"** — ถ้าแอปแต่งรูปขอคุมหน้าจอหรืออ่าน SMS ให้ลบทันที

## 5. Screen Layout (การจัดหน้าจอ — Portrait เท่านั้น)

```
+---------------------------------------------------+
|  GameShell: progress ● ● ○ ○ ○     🔊 เสียงอ่าน    | -> แถบสถานะ (ไม่มี Timer!)
+---------------------------------------------------+
|  แตะแอปที่ดูแปลก เพื่อตรวจสอบ แล้วลบแอปปลอมออก       | -> คำสั่ง ฟอนต์ ≥ 22px
|  เหลือแอปปลอมต้องหา: 🔎 x2                          | -> ตัวช่วยนับ (ไม่ใช่คะแนน)
|                                                   |
|   +-------------+        +-------------+          |
|   |    💬       |        |    🏦       |          |
|   |  แอปแชท     |        | ธนาคารกรุง.. |          | -> การ์ดแอป: ไอคอน + ชื่อ
|   +-------------+        +-------------+          |
|                                                   |
|   +-------------+        +-------------+          |
|   |    🏦       |        |    📷       |          |
|   | เงินด่วน 30วิ |        |  แอปกล้อง    |          | -> (ตัวปลอมแฝงในตาราง)
|   +-------------+        +-------------+          |
|                                                   |
+---------------------------------------------------+
   (ตัวอย่างเลเวล 1 = ตาราง 2×2)
```

**การ์ดตรวจสอบ (Inspect Card) — เปิดเมื่อแตะแอป:**

```
+-------------------------------+
|          🏦                   |
|      เงินด่วนทันใจ 30 วิ        | -> ชื่อแอป ≥ 22px
|  ─────────────────────────    |
|  ที่มา: ⚠️ ติดตั้งจากลิงก์       | -> ป้ายที่มา
|  ขอสิทธิ์: อ่าน SMS, คุมหน้าจอ  | -> สิทธิ์ที่ขอ
|                               |
|  [ 🗑️ ลบแอปนี้ ]  [ ✓ เก็บไว้ ] | -> 2 ปุ่ม ≥ 56px (ในการ์ด)
+-------------------------------+
        (  X  )  ปิด               -> ปุ่มปิดวงกลม อยู่นอกกรอบ popup บนพื้นมืด
```

จอตาราง (grid) มีปุ่ม **"ครบแล้ว ✓"** ค้างอยู่ล่างสุดของหน้าจอเสมอ (ดู §6)

- **การ์ดแอปในตาราง:** ไอคอนใหญ่ (≥ 64px) + ชื่อแอป 1–2 บรรทัด ฟอนต์ ≥ 20px — Touch target เต็มการ์ด ≥ 48×48px
- **ตัวช่วยนับ "เหลือแอปปลอมต้องหา":** บอกจำนวนแอปปลอมที่ยังเหลือ (ช่วยผู้เล่นรู้ว่าตรวจครบหรือยัง โดยไม่ใช่การจับเวลา/ทำคะแนนกดดัน)
- **การลบ:** แตะ "🗑️ ลบแอปนี้" → อนิเมชันไอคอนหด/จางหายพร้อมเสียงเบาๆ (ไม่ใช่เสียงระเบิดตกใจ)
- **ปุ่มปิดการ์ดตรวจสอบ:** เป็นปุ่มวงกลม X + ข้อความ "ปิด" วางอยู่**นอกกรอบ popup บนพื้นมืด** (เด่นและกดง่าย)
- ปุ่ม ≥ 22px, Contrast ≥ 4.5:1 ตาม [Art Direction](./03-art-direction.md)

## 6. Controls & Interaction (การควบคุม — ตรวจก่อนตัดสิน)

ใช้ **การแตะอย่างเดียว** แบ่ง 2 จังหวะกันกดพลาดจากมือสั่น:

1. **แตะการ์ดแอป = ตรวจสอบ** — เปิดการ์ดขยายแสดงชื่อ, ที่มา, สิทธิ์ที่ขอ, จุดสังเกต (อ่านนานแค่ไหนก็ได้ ไม่มีเวลาจำกัด)
2. **แตะตัดสิน:** `🗑️ ลบแอปนี้` (สำหรับแอปปลอม) หรือ `✓ เก็บไว้` (สำหรับแอปจริง) — หรือกดปุ่มปิด (X) เพื่อดูอันอื่นก่อน

- ตอบถูก (ลบปลอม/เก็บจริง) = ✓ เขียว + เสียงชื่นชม
- ตอบผิด (ลบแอปจริง = การ์ด "อันนี้แอปดีนะคะ" แล้ว**คืนแอปกลับตาราง** ไม่หายถาวร / เก็บแอปปลอม = การ์ด "อันนี้ยังน่าสงสัยนะคะ" แล้วให้ลองใหม่) — ไม่มีการลงโทษ
- **ไม่มีการจับเวลา** — สำรวจได้เรื่อยๆ

### ปุ่ม "ครบแล้ว ✓" (Submit) — จบด่านเมื่อผู้เล่นมั่นใจ

จอตารางมีปุ่ม **"ครบแล้ว ✓"** ค้างอยู่ล่างจอเสมอ ทำหน้าที่คล้าย "ส่งคำตอบ" — ผู้เล่นกดเมื่อคิดว่าตรวจครบแล้ว (แม้จะยังไม่ได้ลบ หรือลบไปแค่บางอัน):

- **ถ้าลบแอปปลอมครบทุกอันแล้ว** → ไปด่านต่อไปทันที (เหมือนกรณีลบครบเองแบบอัตโนมัติ)
- **ถ้ายังมีแอปปลอมเหลือ** → แสดง **popup เฉลย** ว่า "คุณยังมีแอปปลอมที่มองข้ามไป N อัน" พร้อมโชว์ไอคอน+ชื่อ+จุดสังเกตของแอปที่พลาด แล้วให้กด "เข้าใจแล้ว ไปด่านต่อไป" — แอปที่มองข้ามถูก**นับเป็นตอบพลาด**ในการคิดดาว (ดู §9) แต่**ไม่มีการลงโทษ/ไม่มีจอแพ้** เป็นช่วงเวลาสอนแทน

> เหตุผล: ในชีวิตจริงผู้สูงอายุอาจ "คิดว่าเครื่องสะอาดแล้ว" ทั้งที่ยังมีแอปอันตรายแฝง ปุ่มนี้จำลองจังหวะนั้นและเปลี่ยนการมองข้ามให้เป็นบทเรียน
- รองรับปุ่มเสียงอ่านชื่อแอป/จุดสังเกต/การ์ดเฉลย (TTS/เสียงอัด ตาม Open Decision โครงการ)

## 7. Content Data Design (คลังแอปแบบ data-driven)

ข้อมูลแอปเป็น data-driven (JSON ใน `src/data/`) เพื่อให้ทีมเนื้อหาเพิ่ม/แก้ได้โดยไม่แตะโค้ดเกม

### 7.1 โครงสร้างข้อมูลแอป (`src/data/g10-app-items.json`)

```json
{
  "id": "g10-fake-loan-01",
  "icon": "🏦",                              // ใช้ชุดไอคอนซ้ำเดิมให้คุ้นตา
  "name": "เงินด่วนทันใจ 30 วิ",
  "is_fake": true,
  "category": "loan",                         // chat | bank | camera | weather | phone | loan | lucky | tool
  "source": "link",                           // "store" (จริง) | "link" (น่าสงสัย)
  "permissions": ["อ่าน SMS", "ควบคุมหน้าจอ"],
  "red_flags": ["ติดตั้งจากลิงก์ ไม่ใช่ Store", "แอปกู้เงินขอสิทธิ์อ่าน SMS เพื่อดูดรหัส OTP"],
  "explain": "แอปกู้เงินที่ให้โหลดจากลิงก์และขอสิทธิ์อ่าน SMS มักเป็นมัลแวร์ที่ขโมยรหัส OTP เพื่อดูดเงินในบัญชี แอปการเงินจริงต้องโหลดจาก Play Store หรือ App Store เท่านั้นค่ะ",
  "ai_disclosure": false
}
```

- ต้องมี **แอปจริง (`is_fake: false`)** หลากหลาย (แชท/ธนาคาร/กล้อง/สภาพอากาศ/โทรศัพท์) ที่ `source: "store"` และสิทธิ์สมเหตุสมผล เพื่อไม่สอนให้ผู้สูงอายุกลัวจนลบแอปดีทิ้ง
- แอปปลอมมีหลายชนิด: เลียนแบบชื่อ (`L1NE`), แอปกู้เงิน/เงินด่วน, แอปรีโมต/แต่งรูปขอสิทธิ์เกิน, แอปล่อรางวัล
- ระบบจั่วแอปตามโควตาแต่ละด่าน (§3) จากคลังแบบ **ไม่ซ้ำในด่านเดียว** (deck without replacement)
- คลังเป้าหมายเวอร์ชันแรก: **แอปจริง 12 ชนิด + แอปปลอม 12 ชนิด** — ต้องส่งทีมวิชาการ NAPLAB ตรวจก่อนใช้จริง
- ทุกการ์ดเฉลยของแอปปลอมปิดท้ายด้วย: วิธีลบแอปจริงบนเครื่อง (กดค้างไอคอน → ถอนการติดตั้ง) และสายด่วน **1441 (ตำรวจไซเบอร์)** หากถูกดูดเงิน
- ภาพ/ไอคอนที่สร้างด้วย AI ต้องตั้ง `ai_disclosure: true` ตาม[นโยบาย AI Content](./00-concept.md#5-นโยบายการนำเสนอเนื้อหาที่สร้างจาก-ai-⚠️)

## 8. Art Direction & Motion (ทิศทางภาพและการเคลื่อนไหว)

- คงสไตล์ **การ์ดไอคอนโค้งมนบนตารางพื้นสว่าง** ตามภาพอ้างอิง แต่ใช้ token โครงการ (teal `--primary`) และ**ไม่มีแถบตัวจับเวลา**
- ไอคอนแอปใช้ **ชุดหน้าตาซ้ำเดิม** (อีโมจิ/ภาพเวคเตอร์เรียบง่าย) — ตัวจริงกับตัวปลอมใช้ไอคอนกลุ่มเดียวกัน ต่างกันที่ชื่อ/ที่มา
- การเคลื่อนไหวช้า คาดเดาได้: การ์ดตรวจสอบ scale-up ~300ms, ลบแอป = ไอคอนหดจางหาย ~400ms, ไม่มีเอฟเฟกต์กะพริบถี่
- `prefers-reduced-motion`: เปลี่ยนทุก transition เป็น fade, การลบเป็นการหายทันทีแบบ fade
- ตัวหนังสือ ≥ 20px, ปุ่ม ≥ 22px, Contrast ≥ 4.5:1

## 9. Reward & Positive Reinforcement (ระบบรางวัล)

- **จบครบ 5 ด่าน = ผ่านเสมอ** ไม่มีเงื่อนไขแพ้
- หน้าสรุปแสดง: จำนวนแอปปลอมที่ลบได้ + คำชม + ย้ำกฎ "โหลดแอปจาก Store ทางการเท่านั้น"
  > "เยี่ยมมากค่ะ! ทีนี้ถ้ามีแอปแปลกๆ โผล่มาในเครื่อง ก็ดูออกและลบเป็นแล้ว มิจฉาชีพแอบฝังแอปดูดเงินยากขึ้นเยอะเลย"
- **ดาวส่งให้ `GameShell` ผ่าน `onFinish(stars)`:** คำนวณจากสัดส่วนตัดสินถูกครั้งแรก (first-try accuracy — ลบปลอม/เก็บจริงถูกตั้งแต่ครั้งแรก) — ≥80% = 3 ดาว, ≥50% = 2 ดาว, ต่ำกว่า = 1 ดาว (ขั้นต่ำ 1 ดาว)
- **แอปปลอมที่ถูกมองข้าม** (กด "ครบแล้ว" ทั้งที่ยังไม่ได้ลบ) นับเป็น**ตัดสินพลาด**ในสูตรดาว เพื่อสะท้อนว่ายังตรวจไม่ครบ — แต่ไม่มีการลงโทษบนหน้าจอ ใช้เป็นข้อมูลคิดดาวเบื้องหลังเท่านั้น
- หน้าสรุปโชว์เฉพาะดาว+คำชม ไม่โชว์เปอร์เซ็นต์/จำนวนพลาด
- เชื่อมระบบดาวประจำบทและใบประกาศตาม [Progression & Reward System](./01-mechanics.md#progression--reward-system)

## 10. Technical Implementation Details (สเปกทางเทคนิค)

### Component & Integration
- Component: **`G10WhoseApp`** วางใน `src/components/` ตามแบบแผน G-number เดิม — คุยกับ `GameShell` ผ่าน props มาตรฐาน `onFinish(stars)` + `logEvent` ไม่สร้าง layout/progress dots เอง
- เขียนเป็น **`.tsx`** ตั้งแต่ต้น (แนวเดียวกับ `G8RaftCrossing.tsx`, `G4ShareOrNot.tsx`)
- Grid ใช้ CSS Grid ปรับ `grid-template-columns` ตามเลเวล (2/3 คอลัมน์) — React state ล้วน + CSS transitions สำหรับลบแอป/เปิดการ์ด ไม่ต้องใช้ physics/timer
- คลังแอป: `src/data/g10-app-items.json` (อนาคตอาจย้ายเข้า Supabase ร่วมกับ US-MIGRATE-03)
- **ลงทะเบียนใน Dev Game Hub** (`src/app/dev/games/page.tsx`): เพิ่ม entry G10 (`component: G10WhoseApp`, `status: "prototype"`, `designDoc: "docs/gdd/design-g10.md"`)

### Event Logging (ทุก action สำคัญต้องยิง log)

```javascript
logEvent('game_start',    { game_id: 'g10', level: 1 });
logEvent('app_inspect',   { game_id: 'g10', item_id: 'g10-fake-loan-01' });                  // เปิดการ์ดตรวจสอบ
logEvent('decide_correct',{ game_id: 'g10', item_id: '...', action: 'remove', first_try: true });
logEvent('decide_wrong',  { game_id: 'g10', item_id: '...', action: 'keep', is_fake: true }); // เผลอเก็บแอปปลอม
logEvent('stage_submit',  { game_id: 'g10', level: 2, missed: 1 });                            // กด "ครบแล้ว" (missed = แอปปลอมที่เหลือ)
logEvent('level_complete',{ game_id: 'g10', level: 2, grid: '3x2' });
logEvent('game_complete', { game_id: 'g10', stars: 3, fakes_removed: 7 });
```

ข้อมูล `decide_wrong` และ `stage_submit` (`missed > 0`) แยกตาม `item_id` + `category` มีค่าต่อทีมวิชาการ — ใช้วิเคราะห์ว่าแอปปลอมชนิดไหน (เลียนแบบชื่อ / เงินด่วน / ขอสิทธิ์เกิน) ที่ผู้สูงอายุแยกไม่ออกหรือมองข้ามบ่อยที่สุด

## 11. Open Questions (คำถามเปิดรอทีมตัดสินใจ)

1. **ตัดตัวจับเวลาออก:** ภาพอ้างอิงมี Timer "03:00" แต่กติกาโครงการ ([Art Direction](./03-art-direction.md)) ห้ามจับเวลากดดัน — ยืนยันดีไซน์นี้ที่**ไม่มี Timer** และใช้ตัวนับ "เหลือแอปปลอมต้องหา" แทนเพื่อบอกความคืบหน้า
2. **ลิขสิทธิ์ไอคอน:** ใช้ไอคอนแอปดัง (LINE/ธนาคาร) เลียนแบบแค่ไหนถึงปลอดภัย — สรุปเป็นไอคอน/ชื่อ "กลางๆ" (เช่น "แอปแชท", "ธนาคาร A") ไม่ใช้โลโก้จริง
3. **กลไกการลบ:** ใช้แตะ 2 จังหวะ (ตรวจ → ปุ่มลบ) ตามร่างนี้ หรืออยากได้แบบ **ลากไอคอนไปถังขยะ** (drag-to-trash) ให้เหมือนการลบแอปจริงบนมือถือ? — drag อาจยากสำหรับมือสั่น ควร playtest ก่อน
4. **ความลึกของเนื้อหาสิทธิ์ (permissions):** จะสอนเรื่อง "สิทธิ์ Accessibility / อ่าน SMS" ลึกแค่ไหนโดยไม่ทำให้ผู้สูงอายุสับสน
5. **ต้องสร้าง User Story `US-GAME-10`** ใน `docs/agile/user-stories/` และจดเข้า Product Backlog เมื่อทีมยืนยันลำดับความสำคัญแล้ว
