# รู้ทันสื่อ Interactive — Art Direction & UI/UX Guidelines

**Version:** 1.0 | **Last Updated:** 2026-07-03

## Visual Style

- **โทน:** อบอุ่น เป็นมิตร สดใสแต่ไม่ฉูดฉาด — ให้ความรู้สึก "กิจกรรมชุมชน" ไม่ใช่ "แอปธนาคาร" หรือ "เกมเด็ก"
- **ภาพประกอบ:** ตัวละคร/ไอคอนสไตล์ illustration เรียบง่าย สื่อบริบทไทย (ตลาด วัด บ้านในชุมชน) — ผลิตโดยทีมงาน; หากใช้เครื่องมือ AI ช่วยผลิต ต้องเปิดเผยตาม[นโยบาย AI Content](./00-concept.md#5-นโยบายการนำเสนอเนื้อหาที่สร้างจาก-ai-⚠️)
- **แนวตั้งเสมอ (Portrait-first):** ทั้งวิดีโอและเกมออกแบบสำหรับถือมือถือแนวตั้งมือเดียว

## Accessibility สำหรับผู้สูงวัย (ข้อบังคับ ไม่ใช่ทางเลือก)

| ด้าน | ข้อกำหนด |
|------|----------|
| ขนาดตัวอักษร | เนื้อหาหลัก ≥ 20px, ปุ่ม ≥ 22px; มีปุ่มขยายตัวอักษร |
| Contrast | อัตราส่วน ≥ 4.5:1 ทุกข้อความ (ตาม WCAG AA) |
| Touch Target | ปุ่ม/พื้นที่แตะ ≥ 48×48px เว้นระยะห่างกันชัดเจน |
| สี | ไม่ใช้สีเป็นตัวสื่อความหมายเดียว (ถูก/ผิดต้องมีไอคอน ✓ ✗ กำกับ) |
| เสียง | ทุกโจทย์/เฉลยมีเสียงอ่านประกอบ (หรืออย่างน้อยในเกม Must-have) — ผู้สูงวัยบางส่วนอ่านหนังสือไม่ถนัด |
| Animation | ช้า ชัดเจน ไม่กะพริบเร็ว; ไม่มีการจับเวลาบังคับ |
| Navigation | เส้นทางเดียวเป็นเส้นตรง ปุ่ม "ถัดไป" ใหญ่ชัด ไม่มีเมนูซ้อน ไม่มี hamburger menu |
| ข้อความ | ประโยคสั้น ภาษาพูด หลีกเลี่ยงศัพท์อังกฤษ |

## UI Patterns หลัก

- **การ์ดบทเรียน:** รูปใหญ่ + ชื่อบท + ดาวที่ได้ — แตะที่ไหนก็ได้ทั้งการ์ด
- **หน้าเกม:** โจทย์ 1 ข้อต่อ 1 หน้าจอ ตัวเลือกไม่เกิน 2–3 ปุ่มใหญ่
- **เฉลย:** สีเขียวอ่อน/ส้มอ่อน (ไม่ใช้แดงจัด) + ไอคอน + คำอธิบาย 1–2 ประโยค + เสียงอ่าน
- **Progress:** จุดแสดงข้อที่ (เช่น ● ● ○ ○ ○) ใหญ่พอมองเห็น

## ข้อจำกัดทางเทคนิคที่กระทบ UX

- ต้องทดสอบใน **LINE in-app browser** เป็นหลัก (กลุ่มเป้าหมายเปิดจากลิงก์ใน LINE)
- YouTube embed บนแนวตั้ง: ใช้ขนาด 9:16 และซ่อน UI ที่ไม่จำเป็น; เตรียม fallback ปุ่ม "เปิดใน YouTube" หากอุปกรณ์เก่าเล่น embed ไม่ได้
- รองรับมือถือ Android รุ่นเก่า/ราคาประหยัด และเน็ตช้าในพื้นที่ชนบท — asset เบา โหลดแบบ progressive

## Audio Direction (ย่อ)

- เพลงประกอบเบา ๆ ปิดได้ง่าย (ปุ่มชัดเจน)
- เสียง feedback ถูก/ผิด นุ่มนวล ไม่ประจาน
- เสียงอ่านโจทย์/เฉลย: เสียงคนไทยชัดเจน จังหวะช้า — หากใช้ TTS/AI voice ต้องเปิดเผยตามนโยบาย AI Content
