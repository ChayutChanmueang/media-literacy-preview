# G15 — ลองถาม AI (Generative AI Chat Simulator)

> สถานะ: 🔍 In QA — เปิดในโหมดอิสระ หมวด "เกมเพื่อการเรียนรู้" (lesson id `g15`) + Dev Game Hub (`/dev/games`) — ไม่อยู่ในโหมดเนื้อเรื่อง/โหมดวิจัย (เดิมคือ prototype GP3)
> โค้ด: `src/components/G15AIChatSimulator.tsx` | เนื้อหา: `src/data/g15-chat-items.json` | ภาพ: `public/assets/g15-images/`

## เป้าหมาย

ให้ผู้เล่นได้ลอง "ใช้" แชทบอท Generative AI (เช่น Claude, Gemini, ChatGPT) แบบปลอดภัยในหน้าจอจำลอง และเห็นว่า AI ตอบคำถามแต่ละประเภทต่างกันอย่างไร:

คลังคำถาม 12 ข้อ (`g15-chat-items.json`, id `g15-01`…`g15-12`) — แต่ละรอบสุ่มลำดับ แสดงให้เลือกทีละ 3 ข้อ ภาพแนบชื่อตามเลขข้อ (`public/assets/g15-images/NN.jpg`, ข้อ 12 เป็น `.png`); ข้อ 01 และ 09 ไม่มีภาพ, ข้อ 06 แนบ **SMS จำลอง** (field `sms` — ผู้ส่ง/ข้อความ/ลิงก์สมมติ แสดงเป็นกล่องข้อความในฝั่งผู้ใช้) แทนภาพ

| ข้อ | สิ่งที่ผู้เล่นถาม | สิ่งที่อยากให้เห็น |
|---|---|---|
| 01 | มีไข่ ผักกาดขาว เต้าหู้ ทำอะไรกินดี | AI ช่วยคิดเมนูจากวัตถุดิบที่มี |
| 02 | รูปต้นไม้ใบเหลือง | บอกสาเหตุที่เป็นไปได้ แต่ระบุแน่นอนจากรูปเดียวไม่ได้ |
| 03 | รูปยาที่ฉลากอ่านไม่ออก ถามกินกี่เม็ด | AI ไม่ควรเดาชนิด/ขนาดยา — ถามแพทย์/เภสัชกร |
| 04 | รูปชวนชม ถามชื่อและการรดน้ำ | ระบุจากรูปได้ แต่อาจผิด + ข้อควรระวังน้ำยางพิษ |
| 05 | รูปป้าย "Please Keep Off The Grass" | AI ช่วยแปลได้ แต่ควรตรวจข้อความจริง |
| 06 | SMS พัสดุขอค่าดำเนินการ 9 บาท | ชี้สัญญาณหลอกลวง ไม่กดลิงก์ ตรวจกับบริษัทขนส่ง |
| 07 | รูปแกงเลียงกุ้งสด ถามชื่อและวิธีทำ | ยืนยันส่วนผสมทั้งหมดจากรูปไม่ได้ (คนแพ้อาหาร) |
| 08 | รูปวัดอรุณ ถามที่เที่ยว | ระบุสถานที่อาจผิด ตรวจเส้นทาง/เวลาเปิดก่อนไป |
| 09 | ร้านอาหารอร่อยในเชียงใหม่ | ข้อมูลร้านเปลี่ยนได้ อย่าเชื่อว่าร้านไหนดีที่สุดจาก AI อย่างเดียว |
| 10 | รูปขมิ้นชัน ถามประโยชน์ | อาจจำแนกผิด สารสกัดเข้มข้นมีความเสี่ยง ปรึกษาแพทย์ |
| 11 | รูปมะม่วงสุก ถามเรื่องเบาหวาน | ข้อมูลทั่วไปได้ แต่ปริมาณน้ำตาลแน่นอนดูจากรูปไม่ได้ |
| 12 | รูปฉลากพาราเซตามอล ให้ช่วยอ่าน | AI ช่วยอ่านฉลากได้ แต่ไม่ควรตัดสินใจแทนแพทย์/เภสัชกร |

## Flow

0. หน้าแนะนำเกม (`GameIntro` แบบเดียวกับ G16) — ชื่อเกม + วัตถุประสงค์ + "เลือกถาม 3 เรื่อง" → กด "กดเพื่อเริ่ม" เข้าหน้าแชท
1. หน้าแชทว่าง ("สวัสดีค่ะ วันนี้อยากรู้อะไรคะ?") + ปุ่มคำถามแนะนำ 3 ข้อเหนือช่องพิมพ์ (ช่องพิมพ์เป็นของตกแต่ง กดไม่ได้)
2. แตะคำถาม → ข้อความผู้ใช้ (พร้อมรูปแนบ ถ้ามี, แตะรูปเพื่อดูเต็มจอ) → AI "กำลังคิด/กำลังดูรูป/กำลังค้นหา" → พิมพ์คำตอบทีละตัว
3. ตอบจบ → ปุ่มคำถามที่เหลือกลับมา เลือกต่อได้ตามลำดับที่ชอบ
4. ครบ 3 ข้อ → ให้เวลาอ่าน 15 วินาที (แถบค่อยๆ เต็ม ไม่มีตัวเลขนับถอยหลัง) → หน้าจบ สรุป 3 ข้อคิด
5. ปุ่ม "กลับหน้ารวมเกม" → เรียก `onExit` (Dev Hub ส่งมาให้) ถ้าไม่มีจะเรียก `onFinish(3)` แทน

## ที่มาของเนื้อหา

คำถาม/คำตอบทั้ง 12 ข้อมาจากทีมเนื้อหา (ใส่ตามต้นฉบับ จัดรูปแบบหัวข้อ/bullet ให้เข้ากับตัวแสดงผล) — ส่วนที่ dev เขียนเพิ่มเอง: `chip_label`, `thinking_steps`, `takeaway_*` (หน้าสรุป), alt ของภาพ และคำถามของข้อ 06 ("ได้รับ SMS แบบนี้มา เชื่อได้ไหมคะ?") — takeaway ข้อ 12 ใช้ "ข้อคิดท้ายเกม" ของทีม

## Event log

`game_start`, `question_select {topic_id, order}`, `answer_complete {topic_id, order}`, `reading_start {reading_ms}`, `game_complete {topics_asked}`
