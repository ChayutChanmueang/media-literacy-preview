## 1. Overview (ภาพรวมของเกม)

เกม **G9 — ลิงก์จี้หรือลิงก์จริง** เป็นเกมจำลองสถานการณ์ฝึกทักษะ **การตรวจสอบลิงก์ก่อนกด** บนโซเชียลมีเดีย โดยจำลองหน้าฟีดและช่องคอมเมนต์คล้าย Facebook ที่ผู้สูงอายุคุ้นเคย — ในแต่ละโพสต์/คอมเมนต์จะมีลิงก์แปะมาด้วย ผู้เล่นต้อง **"สืบ" จุดสังเกตของ URL** แล้วตัดสินว่าเป็น **ลิงก์ทางการจริง** หรือ **ลิงก์ปลอมที่อันตราย**

หัวใจของเกมคือกฎง่ายๆ ที่ผู้สูงอายุจดจำและใช้ได้จริง:

> 🏛️ **หน่วยงานรัฐไทยต้องลงท้ายด้วย `.go.th` เท่านั้น** — ไม่มีขีดกลางมั่วๆ ไม่ใช่ `.com`/`.net`/`.xyz` และไม่ใช่โดเมนภาษาไทย

เกมสอนให้แยกเคสอย่าง กรมสรรพากรของจริง `rd.go.th` ออกจากของปลอม `rd-go-th.com` หรือ `สรรพากร.net` และครอบคลุมภัยลิงก์ยอดฮิตที่หลอกให้ **โหลดแอปกู้เงิน / แอปจ่ายบิลปลอม / แอปรีโมตควบคุมเครื่องเพื่อดูดเงิน** รวมถึงลิงก์ล่อในคอมเมนต์ เช่น "เฮ้ย! แกอยู่ในคลิปนี้รึเปล่า?" หรือ "เช็กสิว่าใครเข้ามาส่องโปรไฟล์คุณ"

> ⚠️ **กติกาโครงการที่ยึดถือ:** ไม่มีการจับเวลา ไม่มีหน้าจอแพ้ (Game Over) กดพลาด = การ์ดเฉลยนุ่มนวลชี้จุดสังเกต ไม่ใช่การลงโทษ ([Art Direction](./03-art-direction.md))

## 2. Core Gameplay Loop (วงลูปหลักการเล่น)

```mermaid
flowchart TD
    Start[เริ่มด่าน] --> Show[แสดงโพสต์/คอมเมนต์ 1 รายการ พร้อมลิงก์แปะมา]
    Show --> Inspect[ผู้เล่นแตะ \"🔍 ส่องลิงก์\" — ขยาย URL เต็ม + ไฮไลต์โดเมนจริง]
    Inspect --> Decide{ตัดสินใจ}
    Decide -- ✓ ลิงก์ทางการ ปลอดภัย --> Judge
    Decide -- ✗ ลิงก์ปลอม ไม่กด --> Judge

    Judge{ตอบตรงไหม?}
    Judge -- ถูก --> Correct[✓ เขียว + เสียงชื่นชม]
    Judge -- ผิด --> Wrong[✗ ส้มอ่อน ไม่ตกใจ]

    Correct --> Card[การ์ดเฉลย: ตีกรอบจุดสังเกตของ URL + กฎ .go.th + เว็บทางการที่ถูกต้อง]
    Wrong --> Card
    Card --> Disclose{สื่อประกอบสร้างด้วย AI?}
    Disclose -- ใช่ --> Badge[แสดงป้าย ai_disclosure]
    Disclose -- ไม่ --> Next
    Badge --> Next{หมดรายการในด่าน?}

    Next -- ยัง --> Show
    Next -- หมด --> LevelEnd[สรุปข้อคิดประจำด่าน]
    LevelEnd --> AllDone{ครบทุกด่าน?}
    AllDone -- ยัง --> Start
    AllDone -- ครบ --> Complete[หน้าสรุปเชิงบวก + ส่งดาวให้ GameShell ผ่าน onFinish]
```

## 3. Level Structure (โครงสร้างด่าน — ไล่จากโพสต์ไปคอมเมนต์)

เกมไล่ระดับด้วย **2 โหมด UI** ตามไอเดียหลัก — เริ่มจากฟีดโพสต์ (ชัดเจน) แล้วเปลี่ยนเป็นช่องคอมเมนต์ (เนียนขึ้น มีตัวลวงเยอะขึ้น):

| ด่าน | โหมด UI | เนื้อหา | ระดับความเนียน |
|------|---------|---------|-----------------|
| 1 | 📰 **ฟีดโพสต์** (Post Feed) | โพสต์ประกาศทั่วไป (ปลอดภัย) ปนกับโพสต์โฆษณาแปะลิงก์อันตราย เช่น แอปกู้เงิน/แอปจ่ายบิลปลอม/แอปรีโมตดูดเงิน | ชัดเจน — โดเมนผิดเห็นง่าย (`.com`, ขีดกลาง) |
| 2 | 💬 **ช่องคอมเมนต์** (Comment Thread) | ใต้โพสต์ปกติ มีคอมเมนต์แปะลิงก์พนัน/แอปกู้เงิน/ลิงก์ล่อ "อยู่ในคลิปนี้รึเปล่า?" | ปานกลาง — ต้องแยกคอมเมนต์คนจริง vs คอมเมนต์หลอก |
| 3 | 💬 **ช่องคอมเมนต์** (เนียนสุด) | ลิงก์ล่อ "ใครเข้ามาส่องโปรไฟล์คุณ", ลิงก์หลอกสมัครบัญชีเพื่อดูดข้อมูล, โดเมนหลอกตาแบบ subdomain (`rd.go.th.verify-login.com`) และโดเมนภาษาไทย (`สรรพากร.net`) | เนียนที่สุด — ต้องอ่านโดเมนท้ายสุดให้ขาด |

- แต่ละด่านมี **5 รายการ** (5 โพสต์ หรือ 5 คอมเมนต์) — กด "สืบ" และตัดสินทีละรายการ
- จบด่าน = การ์ดสรุปข้อคิด 1 ประโยค (เช่น "รัฐไทย = .go.th เท่านั้น จำง่ายๆ แค่นี้")
- ลำดับรายการภายในด่าน**สุ่มจากคลัง** (Pool ตาม §7) เพื่อเล่นซ้ำได้ไม่จำเฉลย

## 4. The Core Rule — จุดสังเกต URL ที่เกมสอน

ตารางกฎที่ใช้ออกแบบโจทย์ทั้งหมด (และใช้เป็นเนื้อหาในการ์ดเฉลย):

| จุดสังเกต | ลิงก์จริง (ตัวอย่าง) | ลิงก์ปลอม (ตัวอย่าง) | คำอธิบาย |
|-----------|----------------------|-----------------------|----------|
| **นามสกุลโดเมนรัฐ** | `rd.go.th` | `rd-go-th.com` | รัฐไทยต้อง `.go.th` เท่านั้น — `.com` คือของปลอม |
| **ขีดกลางหลอกตา** | `dopa.go.th` | `dopa-go-th.net` | ของจริงใช้ **จุด** คั่น ของปลอมเอา **ขีดกลาง** มาต่อให้ดูคล้าย |
| **โดเมนภาษาไทย** | `rd.go.th` | `สรรพากร.net` | หน่วยงานทางการไม่ใช้โดเมนภาษาไทยลงท้าย `.net` |
| **subdomain ลวง** | `www.rd.go.th` | `rd.go.th.verify-login.com` | โดเมนจริงคือ **ส่วนท้ายสุดก่อน `/`** — ตัวจริงคือ `verify-login.com` (ปลอม) |
| **TLD แปลก** | `ktb.co.th` (ธนาคาร) | `ktb-secure.xyz` | `.xyz` `.top` `.info` มักเป็นเว็บหลอก |
| **แอปนอก Store** | โหลดจาก App Store/Play Store | ลิงก์ให้โหลด `.apk` ตรง | แอปที่ให้โหลดไฟล์ตรงมักเป็นมัลแวร์รีโมตดูดเงิน |
| **ลิงก์ล่อความอยากรู้** | — | "ใครมาส่องโปรไฟล์คุณ", "อยู่ในคลิปนี้รึเปล่า?" | ไม่มีฟีเจอร์ดู Stalker จริง — เป็นกับดักหลอกสมัคร/ดูดข้อมูล |
| **URL ยาว/มี path** | `sabuyservice.pea.co.th/sub-menu/4fc04d8e-...` (จริง) | `gov-support.rd-go-th.com/verify/session/...` (ปลอม) | **ความยาว/รหัสท้าย ไม่ใช่จุดตัดสิน** — ดูที่โดเมนหลักว่าลงท้ายถูกต้องไหม |

> **ข้อคิดหลักที่ผู้เล่นต้องได้กลับบ้าน:** ดูที่ **"โดเมนหลัก"** (registrable domain) — คือส่วนท้ายสุดของชื่อเว็บก่อนเครื่องหมาย `/` แรก ว่าลงท้ายด้วยอะไร: **รัฐไทย = `.go.th`**, **บริษัท/รัฐวิสาหกิจไทย = `.co.th`** — URL ที่ยาวหรือมีรหัสยาวๆ ต่อท้ายไม่ได้แปลว่าปลอม และการเอา `rd.go.th` มาวางไว้ข้างหน้าก็ไม่ได้แปลว่าจริง

## 5. Screen Layout (การจัดหน้าจอ — Portrait เท่านั้น)

> เลย์เอาต์จำลองโครง Facebook จริง (อ้างอิงภาพที่ทีมส่งมา): หัวโพสต์มี avatar + ชื่อเพจ + **เครื่องหมายยืนยัน (verified badge)** + บรรทัด "ได้รับการสนับสนุน"/เวลา + ไอคอนโลก, เนื้อโพสต์, URL สีน้ำเงินในเนื้อ, และ **การ์ดพรีวิวลิงก์แบบ FB** (แถบโดเมนตัวใหญ่ + หัวข้อ)

### 5.1 โหมดฟีดโพสต์ (ด่าน 1)

```
+---------------------------------------------------+
|  ด่าน 1 · ฟีดโพสต์ · ข้อ 1/5        🔊 เสียงอ่าน    |
+---------------------------------------------------+
|  (📢) กรมสรรพากรออนไลน์  ✔                          | -> avatar + ชื่อเพจ + verified badge (จริง/ปลอม)
|       ได้รับการสนับสนุน · 🌐                        | -> ป้ายสปอนเซอร์ + ไอคอนโลก
|  ยื่นภาษีรับเงินคืนด่วน! ลงทะเบียนรับสิทธิ์          | -> เนื้อโพสต์
|  https://rd-go-th.com/refund                       | -> URL สีน้ำเงิน (ตามที่โพสต์)
|  +---------------------------------------------+  |
|  |  [ 🔗 แบนเนอร์ ]                             |  | -> การ์ดพรีวิวลิงก์แบบ FB
|  |  RD-GO-TH.COM                               |  |    · โดเมน (ตัวใหญ่)
|  |  ลงทะเบียนขอคืนภาษีออนไลน์                    |  |    · หัวข้อลิงก์

+---------------------------------------------------+
```

### 5.2 โหมดช่องคอมเมนต์ (ด่าน 2–3)

```
+---------------------------------------------------+
|  ด่าน 2 · ช่องคอมเมนต์ · ข้อ 1/5   🔊 เสียงอ่าน    |
+---------------------------------------------------+
|  (🧑) เพื่อนบ้านเรา · โพสต์ · 🌐                     | -> โพสต์ต้นเรื่อง (หัว + บริบท)
|  คลิปงานวัดประจำปีปีนี้สนุกมาก ดูคลิปได้เลย 🎉        |
|  👍❤️😆 1.2 พัน            ความคิดเห็น · แชร์          | -> แถบ engagement (ตกแต่ง)
|  👍 ถูกใจ   💬 แสดงความคิดเห็น   ↗ แชร์             | -> แถบปุ่ม (ตกแต่ง)
|  ── ความคิดเห็นทั้งหมด ▾ ──                         |
|  (👤) บัญชีไม่รู้จัก · 2 ชม.                         | -> คอมเมนต์เป้าหมาย (avatar + ชื่อ + เวลา)
|      เฮ้ย! แกอยู่ในคลิปนี้รึเปล่า? ดูเลย 👉           |
|      https://clip-view.top/watch                   |
|      +----------------------------------------+   | -> การ์ดพรีวิวลิงก์ในคอมเมนต์
|      | CLIP-VIEW.TOP · ดูคลิปที่คุณถูกแท็ก      |   |
|      +----------------------------------------+   |
|      ถูกใจ · ตอบกลับ                               |
|  [ 🔍 ส่องลิงก์ก่อน ]                              |
|  [ ✓ ลิงก์ทางการ ]      [ ✗ ลิงก์ปลอม ]          |
+---------------------------------------------------+
```

- **การ์ดพรีวิวลิงก์:** แสดงแถบโดเมน (hostname ตัวใหญ่) + หัวข้อลิงก์ (link_headline) แบบการ์ด FB — เมื่อกด "🔍 ส่องลิงก์" จะเผยแสดง **URL เต็ม** พร้อม**ไฮไลต์โดเมนหลัก (owner_domain) แบบ registrable** เป็นสีเด่น + คำอธิบายกฎ `.go.th`/`.co.th` เพื่อสอนให้อ่านถูกจุด
- **ปุ่มตัดสิน 2 ปุ่ม:** ✓ ลิงก์ทางการ (เขียว) / ✗ ลิงก์ปลอม (ส้ม) — มีทั้งไอคอน+สี+ข้อความ ไม่พึ่งสีเดี่ยว
- ทุกข้อความ ≥ 20px, ปุ่ม ≥ 22px, Contrast ≥ 4.5:1, Touch target ≥ 48×48px ตาม [Art Direction](./03-art-direction.md)
- **จำลองเท่านั้น ไม่ลิงก์ออกจริง:** URL ทุกอันเป็นข้อความจำลอง กด "ส่องลิงก์" ไม่เปิดเบราว์เซอร์ออกนอกแอป (ป้องกันผู้เล่นกดลิงก์อันตรายจริงโดยไม่ตั้งใจ)

## 6. Controls & Interaction (การควบคุม — สืบก่อนตัดสิน)

ใช้ **การแตะอย่างเดียว** ไม่มีปัด/ลาก แบ่งเป็น 2 จังหวะเพื่อให้ได้ "สืบ" ก่อนตัดสิน:

1. **แตะ "🔍 ส่องลิงก์ก่อน"** — เปิดการ์ดขยาย URL เต็ม ไฮไลต์โดเมนเจ้าของจริง (สนับสนุนแนวคิด "ให้ผู้เล่นสืบจุดสังเกต") — แตะได้ไม่จำกัดครั้ง อ่านนานแค่ไหนก็ได้
2. **แตะปุ่มตัดสิน** — `✓ ลิงก์ทางการ` หรือ `✗ ลิงก์ปลอม`

- **ไม่มีการจับเวลา** — โพสต์/คอมเมนต์รอตลอด
- รองรับปุ่มเสียงอ่านเนื้อโพสต์/คอมเมนต์และการ์ดเฉลย (TTS/เสียงอัด ตาม Open Decision โครงการ)
- ถูก/ผิดมีไอคอนกำกับเสมอ: ✓ เขียว + เสียงชื่นชม, ✗ ส้มอ่อน (ไม่ใช้แดงจัด/เสียงตกใจ)

## 7. Content Data Design (คลังโจทย์แบบ data-driven)

โจทย์ทุกข้อเป็น data-driven (JSON ใน `src/data/`) เพื่อให้ทีมเนื้อหาเพิ่ม/แก้ได้โดยไม่แตะโค้ดเกม — แนวเดียวกับ `g8-raft-items.json`

### 7.1 โครงสร้างข้อมูลโจทย์ (`src/data/g9-link-items.json`)

```json
{
  "id": "g9-l1-01",
  "context": "post",                         // "post" | "comment"
  "level": 1,
  "author": "กรมสรรพากรออนไลน์",
  "verified": false,                          // เครื่องหมายยืนยันเพจ (จริง/ปลอม)
  "sponsored": true,                          // true = แสดง "ได้รับการสนับสนุน"
  "time_ago": "2 ชม.",                        // ใช้เมื่อไม่ใช่โพสต์สปอนเซอร์ / ในคอมเมนต์
  "parent_author": null,                      // ชื่อเจ้าของโพสต์ต้นเรื่อง (เฉพาะ context=comment)
  "parent_verified": false,                   // (เฉพาะ comment)
  "parent_post": null,                        // ข้อความโพสต์ต้นเรื่อง (เฉพาะ comment)
  "author_badge": null,                       // ป้ายคอมเมนต์ เช่น "ผู้เขียน" (เฉพาะ comment)
  "body": "ยื่นภาษีรับเงินคืนด่วน! ลงทะเบียนรับสิทธิ์ก่อนหมดเขต",
  "link_display": "rd-go-th.com/refund",      // URL ที่ตาเห็น (แถบน้ำเงิน + hostname บนการ์ด)
  "link_full": "https://rd-go-th.com/refund?ref=fb",  // URL เต็มตอนกด "ส่องลิงก์"
  "link_headline": "ลงทะเบียนขอคืนภาษีออนไลน์",  // หัวข้อบนการ์ดพรีวิวลิงก์แบบ FB
  "owner_domain": "rd-go-th.com",             // โดเมนหลัก (registrable) — ส่วนที่ไฮไลต์ตอนส่องลิงก์
  "is_safe": false,
  "official_ref": "เว็บไซต์จริงของกรมสรรพากรคือ rd.go.th (ลงท้าย .go.th)",
  "red_flags": ["ใช้ขีดกลาง rd-go-th แทนจุด", "ลงท้าย .com ไม่ใช่ .go.th"],
  "explain": "หน่วยงานรัฐไทยใช้โดเมน .go.th เท่านั้น ลิงก์นี้เอาชื่อ rd มาต่อด้วยขีดกลางแล้วลงท้าย .com เพื่อหลอกให้ดูเหมือนของจริง อย่ากดค่ะ ถ้าจะยื่นภาษีให้พิมพ์ rd.go.th เองในเบราว์เซอร์",
  "ai_disclosure": false
}
```

- โจทย์ `is_safe: true` ก็ต้องมีจริง (เช่นลิงก์ `rd.go.th`, ลิงก์ธนาคาร `.co.th`, โพสต์ทั่วไปไม่มีลิงก์) เพื่อไม่สอนให้ระแวงทุกลิงก์จนไม่กล้าใช้บริการออนไลน์ที่ถูกต้อง
- โจทย์ประเภทลิงก์ล่อ (stalker/คลิป) ตั้ง `owner_domain` เป็นโดเมนแปลกและใส่ `red_flags` เรื่องกลลวงจิตวิทยา ("ไม่มีฟีเจอร์ดูคนส่องโปรไฟล์จริง")
- **ด่าน 3 ต้องมีเคส "URL ยาวมี path แต่เป็นของจริง"** เช่น `sabuyservice.pea.co.th/sub-menu/4fc04d8e-...` (โดเมนหลัก `pea.co.th`) คู่กับเคส "URL ยาวแต่ปลอม" เช่น `gov-support.rd-go-th.com/verify/...` เพื่อสอนว่า **ความยาว/รหัสท้ายไม่ใช่จุดตัดสิน** — `owner_domain` ต้องเป็นโดเมนหลัก (registrable) ที่ระบบไฮไลต์
- คลังโจทย์เป้าหมายเวอร์ชันแรก: **โพสต์ 12 ข้อ + คอมเมนต์ 12 ข้อ** (ปลอม ~65% / ปลอดภัย ~35%) — ต้องส่งทีมวิชาการ NAPLAB ตรวจก่อนใช้จริง
- ทุกการ์ดเฉลยกลุ่ม "ปลอม" ปิดท้ายด้วยช่องทางแจ้งเหตุ: **สายด่วน 1441 (ตำรวจไซเบอร์)** และวิธีที่ปลอดภัยที่สุด — **พิมพ์ชื่อเว็บทางการเองในเบราว์เซอร์ อย่ากดลิงก์จากโพสต์/คอมเมนต์**
- หากมีภาพ/โลโก้ประกอบที่สร้างด้วย AI ต้องตั้ง `ai_disclosure: true` และแสดงป้ายตาม[นโยบาย AI Content](./00-concept.md#5-นโยบายการนำเสนอเนื้อหาที่สร้างจาก-ai-⚠️)

## 8. Art Direction & Motion (ทิศทางภาพและการเคลื่อนไหว)

- จำลอง UI โซเชียลให้ **"คล้ายแต่ไม่ก๊อป"** แบรนด์จริง — ใช้โทน token โครงการ (teal `--primary`) ไม่ใช้โลโก้ Facebook จริงหรือสีน้ำเงินเฉพาะแบรนด์ เพื่อเลี่ยงปัญหาเครื่องหมายการค้า (ทำเป็น "โซเชียลจำลอง" กลางๆ)
- การ์ดพรีวิวลิงก์เด่นชัด โดเมนเจ้าของจริงไฮไลต์เมื่อ "ส่องลิงก์"
- การเคลื่อนไหวช้า คาดเดาได้: การ์ดขยาย slide-up ~300ms, เปลี่ยนรายการ fade เบาๆ ไม่มีเอฟเฟกต์กะพริบถี่
- `prefers-reduced-motion`: เปลี่ยน transition เป็น fade ทันที
- ตัวหนังสือ ≥ 20px, ปุ่ม ≥ 22px, Contrast ≥ 4.5:1 ตาม [Art Direction](./03-art-direction.md)

## 9. Reward & Positive Reinforcement (ระบบรางวัล)

- **จบครบทุกด่าน = ผ่านเสมอ** ไม่มีเงื่อนไขแพ้
- หน้าสรุปแสดง: จำนวนลิงก์ที่ตรวจถูก + คำชม + ย้ำกฎ ".go.th เท่านั้น"
  > "เยี่ยมมากค่ะ! ทีนี้เห็นลิงก์แปลกๆ ในโพสต์หรือคอมเมนต์ ก็ส่องเป็นแล้ว มิจฉาชีพหลอกให้กดยากขึ้นเยอะเลย"
- **ดาวส่งให้ `GameShell` ผ่าน `onFinish(stars)`:** คำนวณจากสัดส่วนตอบถูกครั้งแรก (first-try accuracy) — ≥80% = 3 ดาว, ≥50% = 2 ดาว, ต่ำกว่า = 1 ดาว (ขั้นต่ำ 1 ดาวเสมอ) — หน้าสรุปโชว์เฉพาะดาว+คำชม ไม่โชว์เปอร์เซ็นต์/จำนวนพลาด
- เชื่อมระบบดาวประจำบทและใบประกาศตาม [Progression & Reward System](./01-mechanics.md#progression--reward-system)

## 10. Technical Implementation Details (สเปกทางเทคนิค)

### Component & Integration
- Component: **`G9LinkInspector`** วางใน `src/components/` ตามแบบแผน G-number เดิม — คุยกับ `GameShell` ผ่าน props มาตรฐาน `onFinish(stars)` + `logEvent` ไม่สร้าง layout/progress dots เอง
- เขียนเป็น **`.tsx`** ตั้งแต่ต้น (พัฒนาหลัง migration Next.js + TypeScript — แนวเดียวกับ `G8RaftCrossing.tsx`, `G4ShareOrNot.tsx`)
- React state ล้วน + CSS transitions สำหรับการ์ดขยาย/เปลี่ยนรายการ — ไม่ต้องใช้ physics/timer
- คลังโจทย์: `src/data/g9-link-items.json` (อนาคตอาจย้ายเข้า Supabase ร่วมกับ US-MIGRATE-03)
- **ลงทะเบียนใน Dev Game Hub** (`src/app/dev/games/page.tsx`): เพิ่ม entry G9 (`component: G9LinkInspector`, `status: "prototype"`, `designDoc: "docs/gdd/design-g9.md"`)
- **จำลองลิงก์เท่านั้น** — ห้าม render `<a href>` ที่กดออกเว็บจริงได้ ทุก URL เป็น string ในการ์ดจำลอง

### Event Logging (ทุก action สำคัญต้องยิง log)

```javascript
logEvent('game_start',    { game_id: 'g9', level: 1 });
logEvent('link_inspect',  { game_id: 'g9', item_id: 'g9-post-001' });          // กด "ส่องลิงก์"
logEvent('judge_correct', { game_id: 'g9', item_id: '...', context: 'post', first_try: true });
logEvent('judge_wrong',   { game_id: 'g9', item_id: '...', context: 'comment' });
logEvent('level_complete',{ game_id: 'g9', level: 2 });
logEvent('game_complete', { game_id: 'g9', stars: 3, total_items: 15 });
```

ข้อมูล `judge_wrong` แยกตาม `item_id` + `context` มีค่าต่อทีมวิชาการ — ใช้วิเคราะห์ว่าลิงก์ปลอมแบบไหน (โดเมนขีดกลาง / subdomain ลวง / ลิงก์ล่อจิตวิทยา) หลอกผู้สูงอายุได้ผลที่สุด

## 11. Open Questions (คำถามเปิดรอทีมตัดสินใจ)

1. **ลำดับความสำคัญ / Sprint:** เสนอเป็น Should (Topic 2: Scams) — เนื้อหาทับซ้อน/เสริมกับ G2 (จับสัญญาณมิจ) และ G6 (แชท LINE) ควรจัดเข้า Sprint ใด และไม่แนะนำให้แซงงานเชียงใหม่ 6–7 ส.ค.
2. **ลิขสิทธิ์ UI:** จำลองหน้าตา Facebook แค่ไหนถึงปลอดภัยเรื่องเครื่องหมายการค้า — สรุปเป็น "โซเชียลจำลอง" กลางๆ ไม่ใช้โลโก้/สีแบรนด์จริง
3. **คลังโจทย์:** ต้องการทีมวิชาการช่วยรวบรวมคู่ "โดเมนจริง vs โดเมนปลอม" ของหน่วยงานรัฐ/ธนาคารที่ผู้สูงอายุเจอบ่อย และตรวจความถูกต้อง (โดยเฉพาะรายชื่อ `.go.th` / `.or.th` / `.co.th` ที่ถูกต้อง)
4. **โหมด UI ที่ 3:** ควรมีโหมด "ข้อความ SMS แปะลิงก์" เพิ่มไหม หรือปล่อยให้ G2/G8 ดูแลฝั่ง SMS แล้ว G9 โฟกัสเฉพาะโซเชียลฟีด/คอมเมนต์
5. **ต้องสร้าง User Story `US-GAME-09`** ใน `docs/agile/user-stories/` และจดเข้า Product Backlog เมื่อทีมยืนยันลำดับความสำคัญแล้ว
