# G18 — จำให้ขึ้นใจ (Memory Pads / Simon)

> สถานะ: 🔍 In QA — เปิดในโหมดอิสระ หมวด "เกมสนุก" (lesson id `g18`) + Dev Game Hub (`/dev/games`) — ไม่อยู่ในโหมดเนื้อเรื่อง/โหมดวิจัย (เดิมคือ prototype GP7)
> โค้ด: `src/components/G18MemoryPads.tsx` | สี/เสียงของปุ่ม: `src/data/g18-simon-pads.json`
> ต้นแบบ: ไฟล์ HTML `simon10.html` ของทีม (เกมจำสี Simon 4 ปุ่ม)

## เป้าหมาย

เกมฝึกความจำเพื่อความสนุกล้วน ๆ แบบ Simon — **ไม่มีเนื้อหาบทเรียน** เล่นได้ไม่สิ้นสุด คะแนนคือไปได้ไกลแค่ไหน

## Flow

1. `GameIntro` — "จำให้ขึ้นใจ" + วิธีเล่น
2. หน้าเล่นตาม Figma "Scammer Game Prototype" (node `3028:13081`): พื้นหลังไล่สีฟ้าอ่อน `#E6F6FC → #C4CFE1`, การ์ดหัวจอสีขาว (`GameStageHeader` ตัวเดียวกับ G17) ขวาแสดง "ด่าน n" ช่องซ้ายว่างตาม Figma, กระดาน `#23233A` 352px มุมโค้ง 20px ปุ่มสี่สี (แดง/เหลือง บน · เขียว/น้ำเงิน ล่าง) ยกขึ้น 8px เหนือฐานสีเข้ม, วงกลมกลาง (`public/assets/g18/center-*.svg`) และป้ายสถานะสีขาวใต้กระดาน
   - วงกลมกลางเป็น**วงกลมดำ** และสว่างขาวเฉพาะช่วงที่ไฟกำลังเล่นลำดับ (ช่วงดู)
   - ปุ่มสียุบ/เด้งแบบเดียวกับปุ่มตอบของเกมบทเรียน (`GameAnswerButton`): หน้าปุ่มเลื่อนลงทับฐานใน 90 ms ขณะนิ้วกดค้าง (หรือปุ่มติดไฟ) แล้วเด้งกลับเมื่อปล่อย — แสงเรืองติดที่หน้าปุ่ม ไม่มีเงาดำโผล่ด้านหลัง
   เล่นต่อเนื่องไม่จำกัดด่าน — **ด่าน n มีไฟ n ดวง** (เหมือนต้นแบบ: เพิ่มไฟสุ่ม 1 ดวงต่อท้ายลำดับเดิมทุกด่าน ไม่มีปุ่มเดิมติดกัน 3 ครั้ง)
   - **ช่วงดู:** ป้ายสถานะ "จำปุ่มสีให้ดี" → รอ 0.9 วิ แล้วไฟกะพริบทีละปุ่ม (ติด 650 ms / ดับ 300 ms) พร้อมเสียงโทนประจำปุ่ม (ปุ่มที่ติดไฟยุบลงบนฐาน สว่างขึ้น และเรืองแสง)
   - **ช่วงกด:** ป้ายสถานะ "กดปุ่มสีตามที่เห็น" — ปุ่ม "ดูอีกครั้ง" (เล่นลำดับซ้ำ) **ปิดไว้ก่อน** เพราะ Figma ไม่มีปุ่มนี้ เปิดคืนได้ที่ `SHOW_REPLAY_BUTTON` ถ้าดีไซน์สุดท้ายต้องการ
   - **กดถูกครบ:** กระดานสว่างขาว + "✓ ถูกต้อง! เก่งมาก" แล้วไปด่านต่อไปเอง
   - **กดผิด (ครั้งเดียวก็จบ — มี 1 ชีวิตต่อรอบ):** ป้ายสถานะ "กดผิดปุ่ม — มาดูคะแนนกัน" 1.6 วิ แล้วจบรอบไปหน้าคะแนน — **ไม่เฉลยว่าปุ่มที่ถูกคือปุ่มไหน**
   - **บทฝึก (3 ด่านฝึกก่อนรอบแรก ทุกครั้งที่เปิดเกม):** การ์ดหัวจอแสดง "โหมด ฝึกเล่น" แทน "ด่าน n" (แบบ G13) · **แถบสถานะสีเทาใต้กระดานบอกสถานะเกมเท่านั้น** ("จำปุ่มสีให้ดี" / "กดปุ่มสีตามที่เห็น" / "✓ ถูกต้อง! เก่งมาก" / "กดผิดปุ่ม — ดูไฟอีกครั้ง") ส่วน**คำแนะนำบทฝึกอยู่ในกล่องบทสอนแยก**เหนือกระดาน (แบบกล่องของ G13: พื้นขาว ขอบ 2px มุมโค้ง 16px ตัวหนา 22px — ขอบเหลืองอำพัน = บอกว่าต้องทำอะไร, ขอบเขียว + ✓ = ทำถูก, ขอบเทา = ลองใหม่) ช่องของกล่องจองที่ 2 บรรทัดตลอดบทฝึก กระดานจึงไม่ขยับระหว่างขั้น และหายไปเมื่อเริ่มเล่นจริง · ด่าน 1 มีคำแนะนำเพิ่ม: ช่วงดู "ดูให้ดีว่าปุ่มไหนกะพริบ" ช่วงกด "กดปุ่มที่มือชี้" · กดผิดไม่จบรอบ — ขึ้น "ยังไม่ใช่ปุ่มนี้ มาดูไฟอีกครั้งนะ" แล้วเล่นไฟชุดเดิมซ้ำ; หลังผ่านแต่ละด่านค้างข้อความนานขึ้น (2.4 วิ) ให้อ่านทัน
     1. **ด่าน 1 (ตามต้นแบบ):** ไฟเล่นจบแล้วจอมืดลง เจาะช่องสว่างรอบปุ่มที่ต้องกด + มือ 👆 แตะปุ่ม (มือแบบเดียวกับ G19/G13: ปลายนิ้วอยู่กลางปุ่ม กดลง = เล็กลง + วงกลมเหลืองอำพัน แล้วยกขึ้น วนรอบละ 1.8 วิ — แทนมือเด้งของต้นแบบ) → ผ่านแล้วขึ้น "ด่านต่อไปไฟจะเพิ่มอีก 1 ดวง"
     2. **ด่าน 2 (สอนว่าลำดับทำงานยังไง):** ช่วงดูขึ้น "ไฟดวงเดิมจะมาก่อน แล้วตามด้วยดวงใหม่อีก 1 ดวง" ช่วงกดช่องสว่าง + 👆 พาไล่ทีละปุ่ม ("กดดวงเดิมก่อน" → "แล้วกดดวงใหม่ต่อ" หรือ "กดปุ่มเดิมอีกครั้ง" ถ้าดวงใหม่เป็นปุ่มเดิม) — ระหว่างสองปุ่มหยุด 1.2 วิ ซ่อนมือ/จอมืดแล้วขึ้น "✓ ถูกต้อง!" ให้รู้ว่ากดติดแล้ว
     3. **ด่าน 3 (ลองเอง):** ไม่มีมือ/จอมืด ขึ้น "ลองเองเลย! จำไฟให้ครบ 3 ดวง" → ผ่านแล้วขึ้น "ต่อไปเล่นจริงเริ่มด่าน 1 กดผิดจะจบรอบนะ"
     - **บทฝึกไม่นับคะแนน:** จบบทฝึกแล้วเริ่มรอบจริงใหม่ที่ด่าน 1 (ไฟชุดใหม่ 1 ดวง, 1 ชีวิต) — บทฝึกไม่นับเป็นรอบ (`run` เริ่มที่ 1 ตอนเล่นจริง) · "เล่นอีกครั้ง" ไม่มีบทฝึกซ้ำ
3. หน้าคะแนน "เก่งมาก! ผ่านมาได้ N ด่าน · จำไฟได้ยาวถึง N ดวง" (ไม่ผ่านสักด่าน = "มาลองอีกรอบกัน!") แสดง "สถิติดีที่สุด" และ "🎉 สถิติใหม่ของคุณ!" ตั้งแต่รอบที่ 2 → ปุ่ม "เล่นอีกครั้ง" (เริ่มด่าน 1 ใหม่) / "จบเกม" → `onFinish(stars)`

## คะแนน / ดาว

- คะแนนของรอบ = จำนวนด่านที่ผ่าน (= ลำดับไฟยาวสุดที่จำได้)
- สถิติดีที่สุดเก็บไว้ระหว่างเปิดเกมอยู่เท่านั้น (ยังไม่บันทึกข้ามครั้ง)
- ดาวคิดจากสถิติดีที่สุดตอนกด "จบเกม": ≥ 7 ด่าน = 3 ดาว, ≥ 4 = 2 ดาว, น้อยกว่านั้น = 1 ดาว

## ส่วนที่เปลี่ยนจากต้นแบบ HTML (ตามกติกา AGENT.md)

| ต้นแบบ HTML | G18 | เหตุผล |
|---|---|---|
| กดผิดครั้งเดียว = หน้า "จบเกม" | กดผิดครั้งเดียวจบรอบเหมือนกัน (ไม่เฉลยปุ่มที่ถูก) แต่ไปหน้าคะแนนเชิงบวก | ทีมต้องการให้มี 1 ชีวิต / ห้ามหน้าจอแพ้ ต้อง positive reinforcement |
| หน้าจบแสดงเลเวลที่กดผิด | แสดงจำนวนด่านที่ผ่าน + สถิติดีที่สุด | คะแนน = ไปได้ไกลแค่ไหน |
| กระดาน/ปุ่มสีล้วน + วงกลมกลาง | ปรับตาม Figma (กระดานเข้ม ปุ่มยกนูน) วงกลมกลางดำ สว่างเฉพาะตอนไฟเล่นลำดับ | ดีไซน์ใหม่ของทีม |
| บทฝึกเฉพาะด่าน 1 (จอมืด + มือชี้) ทุกรอบ | บทฝึก 3 ด่าน (มือชี้ / สอนลำดับ / ลองเอง) เฉพาะรอบแรก กดผิดในบทฝึกได้ลองใหม่ | ผู้สูงอายุต้องเข้าใจกติกา "ดวงเดิม + ดวงใหม่" ก่อนเล่นจริง |
| วงกลมกลาง ขาว = รอ / ดำ = กดได้ (ต้องจำเอง) | ป้ายสถานะเป็นข้อความบอกช่วง ("จำปุ่มสีให้ดี" / "กดปุ่มสีตามที่เห็น") | ไม่ให้สีเป็นสัญญาณเดียว |
| ไม่มีเสียง | เสียงโทนต่างกันแต่ละปุ่ม (Web Audio) เปิดตลอด ไม่มีปุ่มปิดเสียง | ช่วยจำด้วยหู |
| ดูลำดับได้ครั้งเดียว | ปุ่ม "ดูอีกครั้ง" — มีในโค้ดแต่ปิดไว้ตาม Figma (`SHOW_REPLAY_BUTTON = false`) | รอดีไซน์สุดท้ายตัดสิน |
| ไม่มี | ไม่มีจับเวลาตอนกด | ห้ามจับเวลากดดัน |

ปุ่มไม่มีข้อความ/ไอคอน (ตามต้นแบบ) — ผู้เล่นแยกปุ่มด้วยสีและตำแหน่ง ถ้าทดสอบแล้วผู้ที่ตาบอดสีแยกเขียว/แดงไม่ออก อาจต้องเพิ่มสัญลักษณ์บนปุ่ม

## Event log

`game_intro_start`, `tutorial_start`, `run_start {run}`, `enter_level {run, level, tutorial}`, `wrong_press {run, level, step, expected, pressed, tutorial}`, `tutorial_complete`, `replay_request {run, level, step}` (ยิงเฉพาะตอนเปิดปุ่ม "ดูอีกครั้ง"), `level_complete {run, level, tutorial}` (ช่วงบทฝึก `run` = 0), `run_end {run, score, best_score}`, `game_complete {runs, best_score, stars}`, `g18_dev_skip_level {run, level}` (ปุ่ม "ข้ามด่าน" แสดงเฉพาะตอน `npm run dev` สำหรับ QA)

## เรื่องที่ยังเปิดอยู่

- ยังไม่ได้ทดสอบกับผู้สูงอายุจริง — ความเร็วไฟ (650/300 ms), เกณฑ์ดาว (4 / 7 ด่าน) และกติกา 1 ชีวิต (ผิดครั้งเดียวจบ) อาจต้องปรับ
- ความเร็วไฟคงที่ทุกด่าน (ต้นแบบก็คงที่) — ถ้าอยากให้ท้าทายขึ้นในด่านสูง ๆ ค่อยเพิ่มทีหลัง
- สถิติดีที่สุดหายเมื่อออกจากเกม — ถ้าต้องการเก็บข้ามครั้ง ต้องผ่าน `progressService`
- เสียงเป็นโทนสังเคราะห์
- ไฟกะพริบเป็นแกนของเกม จึงไม่ได้ปิดตาม `prefers-reduced-motion` (ใช้แค่ความสว่าง/เงา ไม่มีการเคลื่อนที่ไกล)
