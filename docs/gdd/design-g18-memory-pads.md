# G18 — จำให้ขึ้นใจ (Memory Pads / Simon)

> สถานะ: 🔍 In QA — เปิดในโหมดอิสระ หมวด "เกมสนุก" (lesson id `g18`) + Dev Game Hub (`/dev/games`) — ไม่อยู่ในโหมดเนื้อเรื่อง/โหมดวิจัย (เดิมคือ prototype GP7)
> โค้ด: `src/components/G18MemoryPads.tsx` | สี/เสียงของปุ่ม: `src/data/g18-simon-pads.json`
> ต้นแบบ: ไฟล์ HTML `simon10.html` ของทีม (เกมจำสี Simon 4 ปุ่ม)

## เป้าหมาย

เกมฝึกความจำเพื่อความสนุกล้วน ๆ แบบ Simon — **ไม่มีเนื้อหาบทเรียน** เล่นได้ไม่สิ้นสุด คะแนนคือไปได้ไกลแค่ไหน

## Flow

1. `GameIntro` — "จำให้ขึ้นใจ" + วิธีเล่น
2. เล่นต่อเนื่องไม่จำกัดด่าน — **ด่าน n มีไฟ n ดวง** (เหมือนต้นแบบ: เพิ่มไฟสุ่ม 1 ดวงต่อท้ายลำดับเดิมทุกด่าน ไม่มีปุ่มเดิมติดกัน 3 ครั้ง)
   - **ช่วงดู:** แถบสถานะ "👀 ดูไฟให้จบก่อนนะ" + วงกลมกลางสีขาว → รอ 0.9 วิ แล้วไฟกะพริบทีละปุ่ม (ติด 650 ms / ดับ 300 ms) พร้อมเสียงโทนประจำปุ่ม
   - **ช่วงกด:** แถบสถานะ "👆 ถึงตาคุณแล้ว กดตามได้เลย" + วงกลมกลางสีดำ — ปุ่ม "ดูอีกครั้ง" เล่นลำดับซ้ำได้ไม่จำกัด
   - **กดถูกครบ:** กระดานสว่างขาว + "✓ ถูกต้อง! เก่งมาก" แล้วไปด่านต่อไปเอง
   - **กดผิด (ครั้งเดียวก็จบ — มี 1 ชีวิตต่อรอบ):** แถบสีเหลือง "กดผิดปุ่ม — มาดูคะแนนกัน" 1.6 วิ แล้วจบรอบไปหน้าคะแนน — **ไม่เฉลยว่าปุ่มที่ถูกคือปุ่มไหน**
3. หน้าคะแนน "เก่งมาก! ผ่านมาได้ N ด่าน · จำไฟได้ยาวถึง N ดวง" (ไม่ผ่านสักด่าน = "มาลองอีกรอบกัน!") แสดง "สถิติดีที่สุด" และ "🎉 สถิติใหม่ของคุณ!" ตั้งแต่รอบที่ 2 → ปุ่ม "เล่นอีกครั้ง" (เริ่มด่าน 1 ใหม่) / "จบเกม" → `onFinish(stars)`

## คะแนน / ดาว

- คะแนนของรอบ = จำนวนด่านที่ผ่าน (= ลำดับไฟยาวสุดที่จำได้)
- สถิติดีที่สุดเก็บไว้ระหว่างเปิดเกมอยู่เท่านั้น (ยังไม่บันทึกข้ามครั้ง)
- ดาวคิดจากสถิติดีที่สุดตอนกด "จบเกม": ≥ 7 ด่าน = 3 ดาว, ≥ 4 = 2 ดาว, น้อยกว่านั้น = 1 ดาว

## ส่วนที่เปลี่ยนจากต้นแบบ HTML (ตามกติกา AGENT.md)

| ต้นแบบ HTML | G18 | เหตุผล |
|---|---|---|
| กดผิดครั้งเดียว = หน้า "จบเกม" | กดผิดครั้งเดียวจบรอบเหมือนกัน (ไม่เฉลยปุ่มที่ถูก) แต่ไปหน้าคะแนนเชิงบวก | ทีมต้องการให้มี 1 ชีวิต / ห้ามหน้าจอแพ้ ต้อง positive reinforcement |
| หน้าจบแสดงเลเวลที่กดผิด | แสดงจำนวนด่านที่ผ่าน + สถิติดีที่สุด | คะแนน = ไปได้ไกลแค่ไหน |
| กระดาน/ปุ่มสีล้วน + วงกลมกลาง | **คงดีไซน์เดิม** (สี เงา 3D แสงเรือง วงกลมกลาง) | ทีมต้องการหน้าตาเหมือนต้นแบบ |
| วงกลมกลาง ขาว = รอ / ดำ = กดได้ (ต้องจำเอง) | คงวงกลมไว้ + แถบสถานะเป็นข้อความ | ไม่ให้สีเป็นสัญญาณเดียว |
| ไม่มีเสียง | เสียงโทนต่างกันแต่ละปุ่ม (Web Audio) เปิดตลอด ไม่มีปุ่มปิดเสียง | ช่วยจำด้วยหู |
| ดูลำดับได้ครั้งเดียว | ปุ่ม "ดูอีกครั้ง" | ลดความกดดัน |
| ไม่มี | ไม่มีจับเวลาตอนกด | ห้ามจับเวลากดดัน |

ปุ่มไม่มีข้อความ/ไอคอน (ตามต้นแบบ) — ผู้เล่นแยกปุ่มด้วยสีและตำแหน่ง ถ้าทดสอบแล้วผู้ที่ตาบอดสีแยกเขียว/แดงไม่ออก อาจต้องเพิ่มสัญลักษณ์บนปุ่ม

## Event log

`game_intro_start`, `run_start {run}`, `enter_level {run, level}`, `wrong_press {run, level, step, expected, pressed}`, `replay_request {run, level, step}`, `level_complete {run, level}`, `run_end {run, score, best_score}`, `game_complete {runs, best_score, stars}`, `g18_dev_skip_level {run, level}` (ปุ่ม "ข้ามด่าน" แสดงเฉพาะตอน `npm run dev` สำหรับ QA)

## เรื่องที่ยังเปิดอยู่

- ยังไม่ได้ทดสอบกับผู้สูงอายุจริง — ความเร็วไฟ (650/300 ms), เกณฑ์ดาว (4 / 7 ด่าน) และกติกา 1 ชีวิต (ผิดครั้งเดียวจบ) อาจต้องปรับ
- ความเร็วไฟคงที่ทุกด่าน (ต้นแบบก็คงที่) — ถ้าอยากให้ท้าทายขึ้นในด่านสูง ๆ ค่อยเพิ่มทีหลัง
- สถิติดีที่สุดหายเมื่อออกจากเกม — ถ้าต้องการเก็บข้ามครั้ง ต้องผ่าน `progressService`
- เสียงเป็นโทนสังเคราะห์
- ไฟกะพริบเป็นแกนของเกม จึงไม่ได้ปิดตาม `prefers-reduced-motion` (ใช้แค่ความสว่าง/เงา ไม่มีการเคลื่อนที่ไกล)
