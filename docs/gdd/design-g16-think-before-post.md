# G16 — คิดก่อนโพสต์ (Think Before You Post)

> สถานะ: 🔍 In QA — เปิดในโหมดอิสระ หมวด "เกมเพื่อการเรียนรู้" (lesson id `g16`) + Dev Game Hub (`/dev/games`) — ไม่อยู่ในโหมดเนื้อเรื่อง/โหมดวิจัย (เดิมคือ prototype GP4)
> โค้ด: `src/components/G16ThinkBeforePost.tsx` | เนื้อหา: `src/data/g16-post-items.json`

## เป้าหมาย

ฝึกให้ผู้เล่น "หยุดอ่านโพสต์ของตัวเองก่อนกดโพสต์" และมองออกว่าข้อมูลส่วนไหนเปิดช่องให้มิจฉาชีพ:

- ชื่อ-นามสกุลจริงของตัวเอง ครอบครัว และลูกหลาน (รวมถึงการพิมพ์ชื่อจริง/เบอร์/ที่อยู่ในคอมเมนต์)
- รูปครอบครัวและรูปลูกหลาน โดยเฉพาะรูปที่เห็นชื่อ โรงเรียน หรือเอกสาร
- ที่อยู่ เวลา และช่วงที่บ้านว่าง ซึ่งมิจฉาชีพใช้ประกอบเรื่องหลอกให้ดูน่าเชื่อ

มีโพสต์ที่ **ปลอดภัยจริง** ปนอยู่ด้วย (ดอกไม้ อาหาร) เพื่อไม่ให้สอนว่า "ห้ามโพสต์อะไรเลย" แต่สอนว่าโพสต์เรื่องทั่วไปได้ ถ้าไม่มีข้อมูลส่วนตัว

## Flow

1. `GameIntro` — "คิดก่อนโพสต์" ตัวเลือก "โพสต์เลย · ไม่โพสต์"
2. หน้าสร้างโพสต์จำลอง (แอปโซเชียลทั่วไป ไม่อิงแบรนด์จริง): หัว "สร้างโพสต์"/"แสดงความคิดเห็น", ชื่อบัญชี + ป้าย 🌐 สาธารณะ, ข้อความที่พิมพ์ไว้แล้ว (มีเคอร์เซอร์กะพริบ), รูปแนบ (emoji + คำบรรยายรูป), เช็กอินสถานที่ (ถ้ามี) — โจทย์แบบคอมเมนต์แสดงโพสต์ต้นทางไว้ด้านบน
   - ปุ่ม "โพสต์" มุมขวาบนเป็นของตกแต่ง กดไม่ได้ ไม่มีปุ่มปิด/ย้อนกลับ (แนวเดียวกับ G6)
3. เลือกด้วยปุ่มคู่เดียวกับ G6 (`GameAnswerButton` เขียว/เหลือง) เปลี่ยนข้อความเป็น **โพสต์เลย / ไม่โพสต์** และปุ่ม "ไม่โพสต์" ใช้ไอคอน ✗ (`answer-fake.svg`) แทน ❓ ของ G6 ให้ตรงกับการกระทำ
4. `GameSolutionCard` เฉลย: โพสต์เสี่ยง → ยกข้อความที่เป็นปัญหามาไฮไลต์พร้อมเหตุผลทีละข้อ, โพสต์ปลอดภัย → เหตุผลว่าทำไมโพสต์ได้ ปิดท้ายด้วยคำแนะนำ "คิดก่อนโพสต์"
5. ปุ่ม "กดเพื่อไปต่อ" (`Button3D` auto-advance 30 วิ หยุดนับระหว่างเลื่อนอ่าน) → ครบ 6 โพสต์ → `onFinish(stars)`

## การให้คะแนน / ดาว

| โพสต์ | เลือก | การ์ด | นับคะแนน |
|---|---|---|---|
| เสี่ยง | ไม่โพสต์ | เขียว "ปลอดภัย" | ✓ |
| เสี่ยง | โพสต์เลย | แดง "ไม่ปลอดภัย" | — |
| ปลอดภัย | โพสต์เลย | เขียว "โพสต์ได้" | ✓ |
| ปลอดภัย | ไม่โพสต์ | เขียว "รอบคอบดี" + บอกว่าโพสต์ได้ | — (ไม่ลงโทษ แต่ไม่ใช่คำตอบที่ดีที่สุด) |

ดาวใช้เกณฑ์เดียวกับ G6: สัดส่วนคำตอบที่ดีที่สุด ≥ 0.8 = 3 ดาว, ≥ 0.5 = 2 ดาว, นอกนั้น 1 ดาว
