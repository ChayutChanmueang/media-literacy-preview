### 1. 🔴 [หน้า Consent] ถอดระบบเช็คตำแหน่งจาก GPS — ต้องแก้

**คำอธิบาย:**  
บนหน้ายินยอมข้อมูลมีปุ่ม **"ดึงพิกัดจาก GPS (แม่นยำขึ้น)"** ที่เรียก Browser Geolocation แล้วแปลงพิกัดเป็นจังหวัด/อำเภอ/ตำบลผ่าน OpenStreetMap Nominatim

จากการใช้งานจริงพบว่า:

1. **GPS ไม่ตรง** — พิกัดที่ดึงได้มักไม่ตรงกับพื้นที่ที่ผู้เรียนต้องการให้ระบบบันทึก โดยเฉพาะใน LINE in-app browser หรือเมื่อสัญญาณระบุตำแหน่งคลาดเคลื่อน
2. **ความต้องการกรอกที่อยู่เปลี่ยนตามความประสงค์** — บางครั้งผู้เรียนอยากกรอก**ที่อยู่บ้านเกิด** บางครั้งอยากกรอก**ที่อยู่ปัจจุบันที่เล่นเกม** GPS บังคับเป็นตำแหน่งเครื่องในขณะนั้น จึงไม่ตอบโจทย์

ดังนั้นฟีเจอร์นี้จึงไม่มีประโยชน์ และทำให้หน้าจอยุ่งโดยไม่จำเป็น

**ความสำคัญ:** ต้องแก้

**สิ่งที่ต้องทำ / สิ่งที่ทำแล้ว:**
- ลบปุ่มดึงพิกัด GPS, สรุปพื้นที่จาก GPS และปุ่ม "เสร็จสิ้น/แก้ไข" ที่ผูกกับ flow นี้
- ให้ผู้เรียนเลือก **จังหวัด / อำเภอ / ตำบล** จากรายการเองเสมอ
- ไม่เรียก `navigator.geolocation` และไม่ยิง Nominatim จากหน้า Consent
- ข้อความ PDPA ระบุว่าเก็บเฉพาะพื้นที่ที่ผู้เรียนเลือกเอง ไม่เก็บพิกัด GPS
- คอลัมน์ `gps_latitude` / `gps_longitude` ในฐานข้อมูลยังคงไว้ได้แต่ไม่ถูกเติมจาก UI นี้ (ส่งค่าว่าง)
