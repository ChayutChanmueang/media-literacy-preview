## 📋 รายละเอียดผลตอบรับ

---



### 1. [แอปโดยรวม] ลบ / ซ่อนแท็บปรับขนาด UI

**คำอธิบาย:**  
แท็บสำหรับเลือกขนาด UI (ปรับขนาดตัวอักษร/องค์ประกอบ) ควรถูกลบออกหรือซ่อนจากอินเทอร์เฟซ ฟีเจอร์นี้ทำให้หน้าจอดูรกและไม่จำเป็นสำหรับ flow การใช้งานปัจจุบัน

**สิ่งที่ต้องดำเนินการ:** ลบหรือซ่อน component แท็บปรับขนาด UI ตามเงื่อนไขที่เหมาะสม

---



### 2. [Start Menu] ลบ Manual Learning และทำให้ปุ่ม Auto Flow เรียบง่ายขึ้น

**คำอธิบาย:**  

- ตัวเลือก **Manual Learning** ใน Start Menu ควร **ลบออกหรือปิดใช้งานชั่วคราว**  
- ตัวเลือก **Learning with Auto Flow** ควรถูกออกแบบใหม่เป็นปุ่ม **Play** แบบเรียบง่าย  
- ⚠️ ฟังก์ชัน Auto Flow เดิมต้องคงไว้ไม่เปลี่ยนแปลง — เปลี่ยนเฉพาะ label และรูปแบบปุ่มเท่านั้น

**สิ่งที่ต้องดำเนินการ:** อัปเดต UI ของ Start Menu; ปิด Manual Learning; เปลี่ยน Auto Flow button เป็นปุ่ม Play แบบเรียบง่าย

---



### 3. [แอปโดยรวม] เพิ่มหน้าแนะนำก่อนเริ่มเกม

**คำอธิบาย:**  
ก่อนเริ่มเกม ควรแสดงหน้าแนะนำ (Intro Panel หรือ Scene) เพื่อให้ผู้ใช้เข้าใจบริบทของเกม เช่น วิธีเล่น เนื้อหาของเกม และข้อมูล onboarding อื่นๆ ที่เกี่ยวข้อง

**สิ่งที่ต้องดำเนินการ:** ออกแบบและ implement หน้า Intro Panel/Scene ที่แสดงครั้งแรกเมื่อเริ่มเกม

---



### 4. [แอปโดยรวม] ปุ่มตัวเลือก — ดีไซน์สม่ำเสมอ พร้อม Animation กด

**คำอธิบาย:**  
ปุ่มตัวเลือกที่ใช้ในเกมต่างๆ (ปฎิเสธ, ยอมรับ, นิ่งเฉย) มีสไตล์ที่ไม่สม่ำเสมอ ควรปรับให้:

- ใช้ **โทนสีที่สม่ำเสมอ** ในทุกเกม
- มีลักษณะ **นูนขึ้น** (มี visual depth/shadow)
- มี **animation เมื่อกด** (เช่น กดแล้วยุบลงหรือ scale เล็กลง)

**สิ่งที่ต้องดำเนินการ:** ทำให้ style ของ button component เป็นมาตรฐานเดียวกัน; เพิ่ม raised style และ press animation

---



### 5. [แอปโดยรวม] วิดีโอควรแสดงแบบเต็มหน้าจอหรือใช้พื้นที่หน้าจอมากที่สุด

**คำอธิบาย:**  
ปัจจุบันการเล่นวิดีโอไม่ได้ใช้พื้นที่หน้าจอเต็มที่ ลูกค้าต้องการให้วิดีโอแสดงในโหมด **เต็มหน้าจอ** หรือขยายให้ใช้พื้นที่หน้าจอให้มากที่สุดเท่าที่เป็นไปได้ เพื่อปรับปรุงประสบการณ์การรับชม

**สิ่งที่ต้องดำเนินการ:** อัปเดต component video player ให้แสดงแบบ fullscreen หรือขนาด viewport สูงสุด

---



### 6. [แอปโดยรวม] หลังดูคะแนน G13 แล้วให้กลับไปที่ Start Menu

**คำอธิบาย:**  
หลังจากผู้ใช้เล่น G13 เสร็จและดูคะแนนแล้ว การกดปุ่ม Finish / Return ควร **นำผู้ใช้กลับไปที่ Start Scene / Start Menu** แทนที่จะไปยังปลายทางปัจจุบัน

**สิ่งที่ต้องดำเนินการ:** อัปเดต onFinish handler หลังหน้าคะแนน G13 ให้ navigate กลับไปที่ Start Menu

---



### 7. [แอปโดยรวม] เล่นวิดีโอก่อน แล้วจึงให้ผู้ใช้เล่นเกม

**คำอธิบาย:**  
ปัจจุบันวิดีโอแนะนำจะเล่น **หลัง** จากเกม flow ที่ต้องการคือ:  
**วิดีโอ → เกม**  
ผู้ใช้ควรดูวิดีโอก่อน จึงจะสามารถเล่นเกมได้

> สอดคล้องกับผลตอบรับภายในข้อ #1 ใน [FB-2026-07-31-playtest.md](../feedback/FB-2026-07-31-playtest.md)

**สิ่งที่ต้องดำเนินการ:** สลับลำดับวิดีโอ/เกมใน flow logic ของทุกเกมที่ได้รับผลกระทบ

---



### 8. [G1] ออกแบบ UI ข้อความข่าวใหม่ให้ดูเหมือน LINE / SMS

**คำอธิบาย:**  
การแสดงข้อความข่าวใน G1 ในปัจจุบันไม่ได้ดูเหมือนแหล่งข่าวในชีวิตจริง ลูกค้าต้องการออกแบบใหม่ให้ดูเหมือน **แอปพลิเคชันส่งข้อความจริง** เช่น LINE หรือ SMS — พร้อมฟองข้อความ, ชื่อผู้ส่ง, timestamp และ visual styling ที่สมจริง

**สิ่งที่ต้องดำเนินการ:** ออกแบบ UI component ข้อความข่าวของ G1 ใหม่ให้เลียนแบบรูปแบบ chat/SMS

---



### 9. [G6] เพิ่มขนาดตัวอักษรในหน้า Level Intro

**คำอธิบาย:**  
ข้อความที่แสดงในหน้า Level Intro Scene ของ G6 มีขนาดเล็กเกินไป โดยเฉพาะสำหรับผู้ใช้สูงอายุ ควรเพิ่มขนาดตัวอักษรเพื่อให้อ่านได้ง่ายขึ้น

**สิ่งที่ต้องดำเนินการ:** เพิ่มขนาดตัวอักษรในหน้า G6 Level Intro; ตรวจสอบให้ตรงตามแนวทาง accessibility สำหรับผู้สูงอายุ

---



### 10. [G6] ลดเวลารอก่อนข้อความ Pop-Up ปรากฏ

**คำอธิบาย:**  
ตัวจับเวลา auto-advance ก่อนที่ข้อความจะปรากฏใน G6 ใช้เวลานานเกินไป การลดเวลารอจะช่วยปรับปรุง pacing และความน่าสนใจของเกม

> เกี่ยวข้องกับผลตอบรับภายในข้อ #4 ใน [FB-2026-07-31-playtest.md](../feedback/FB-2026-07-31-playtest.md) — ตัวจับเวลา 30 วินาทีบนหน้า Intro นานเกินไป

**สิ่งที่ต้องดำเนินการ:** ลด delay timer ของ message pop-up ใน G6

---



### 11. [G6] แจ้งเตือนผู้ใช้เมื่อกดองค์ประกอบหลอกลวง

**คำอธิบาย:**  
เมื่อผู้ใช้กดหรือแตะที่องค์ประกอบหลอกลวงที่กดได้ (เช่น ปุ่มหลอกลวงหรือลิงก์หลอกลวง) เกมควร **แสดงข้อความเตือน** เพื่อแจ้งให้ผู้ใช้ทราบว่าไม่ควรกดลิงก์ดังกล่าว ซึ่งช่วยเสริมวัตถุประสงค์การเรียนรู้ของเกม

**สิ่งที่ต้องดำเนินการ:** เพิ่ม in-game warning/toast notification เมื่อมีการโต้ตอบกับองค์ประกอบหลอกลวง

---



### 12. [G6] เปลี่ยนตัวเลือกเป็น ตอบกลับ / ไม่ตอบกลับ

**คำอธิบาย:**  
ระบบสามตัวเลือกในปัจจุบัน (ปฎิเสธ / ยอมรับ / นิ่งเฉย) ควรถูกแทนที่ด้วยระบบสองตัวเลือกที่เรียบง่ายกว่า:

- **ตอบกลับ** (Reply)
- **ไม่ตอบกลับ** (Not Reply)

**สิ่งที่ต้องดำเนินการ:** อัปเดตปุ่มตัวเลือกของ G6 และ game logic ที่เกี่ยวข้องให้ใช้ระบบสองตัวเลือกใหม่

---



### 13. [G13] ทำให้หน้า Intro น่าสนใจและสร้างแรงจูงใจมากขึ้น

**คำอธิบาย:**  
หน้าแนะนำของ G13 ควรเขียนใหม่ให้น่าสนใจและสร้างแรงจูงใจมากขึ้น เช่น นำเสนอในรูปแบบ "เกมฝึกสมองสนุกๆ" (เล่นเกมฝึกสมอง สนุกๆ) เพื่อกระตุ้นให้ผู้ใช้อยากมีส่วนร่วมและลดความลังเล

**สิ่งที่ต้องดำเนินการ:** เขียน copy ของหน้า Intro G13 ใหม่ให้น่าสนใจมากขึ้น; พิจารณาเพิ่ม visual หรือ copy ที่สร้างแรงบันดาลใจ

---



### 14. [G13] ขยายขนาดไอศกรีมและโคน (~3 เท่าของขนาดปัจจุบัน)

**คำอธิบาย:**  
Assets ไอศกรีมและโคนใน G13 มีขนาดเล็กเกินไปในปัจจุบัน ลูกค้าต้องการให้ขยายขนาดเป็นประมาณ **3 เท่าของขนาดปัจจุบัน** เพื่อปรับปรุงความชัดเจนและความรู้สึกในการเล่นเกม

**สิ่งที่ต้องดำเนินการ:** ขยาย sprites/assets ไอศกรีมและโคนใน G13 ให้มีขนาด ~3 เท่า

---



### 15. [G13] เพิ่มความยากขึ้นเรื่อยๆ

**คำอธิบาย:**  
เมื่อผู้เล่นเล่น G13 ต่อเนื่อง เกมควรยากขึ้นเรื่อยๆ mechanic ที่แนะนำคือ **เพิ่มความเร็วในการตกของไอศกรีม** ยิ่งเล่นนานยิ่งเร็ว ซึ่งสร้าง skill curve และเพิ่มแรงจูงใจในการเล่นซ้ำ

**สิ่งที่ต้องดำเนินการ:** implement การปรับความยากแบบ progressive ใน G13 (เช่น เพิ่มความเร็วการตกของ item ตามเวลาหรือคะแนน)
