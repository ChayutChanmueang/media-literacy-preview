## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกม "AI หรือ คน?" (G3) เพื่อฝึกสังเกตสื่อที่ AI สร้าง
**เพื่อให้** ปลอดภัยจากการรับข้อมูลข่าวสารที่ใช้ภาพหรือคลิป AI ในการหลอกลวงหรือสร้างข่าวเท็จ

---

## ✅ Acceptance Criteria
1. [ ] มีโจทย์ภาพหรือข้อสอบวิเคราะห์อย่างน้อย 6 ข้อ ให้ผู้ใช้เลือกตอบ 3 ทางเลือก คือ "สร้างโดย AI", "ภาพถ่ายจริง" หรือ "ไม่แน่ใจ / ต้องเช็กก่อน" ด้วยปุ่มขนาดใหญ่ตามเกณฑ์ Accessibility
2. [ ] แสดงเฉลยโดยใช้ระบบชี้เป้าหรือวงกลมเน้นจุดสังเกตบนตัวภาพจริง (เช่น นิ้วมือเบลอ, พื้นหลังบิดเบี้ยว, แสนเงาแปลกๆ)
3. [ ] ภาพหรือสื่อใดๆ ที่สร้างโดย AI ทั้งหมดในโครงการ จะต้องมีการกำกับป้าย `ai_disclosure` (เช่น "ภาพนี้สร้างด้วย AI") เสมอตามนโยบายจริยธรรมเนื้อหาของโครงการ
4. [ ] เมื่อผู้เล่นกดยืนยันเลือกตอบ "ไม่แน่ใจ / ต้องเช็กก่อน" ระบบจะแสดงข้อความชมเชยในหน้าเฉลยว่าเป็นทางเลือกที่รอบคอบและอธิบายชี้เป้าจุดสังเกตประกอบภาพ

---

## 🛠 Technical Tasks (Game G3 Development)
- [ ] ออกแบบระบบแสดงผลรูปภาพความละเอียดสูงที่รองรับการซูม (Zoomable Image Component) เพื่อให้มองเห็นรายละเอียดได้ชัดเจน
- [ ] พัฒนา Overlay Layer บนรูปภาพเพื่อทำไฮไลท์หรือตีกรอบสีชี้จุดสังเกตตอนแสดงผลหน้าเฉลย
- [ ] สร้าง Component ป้ายกำกับ `ai_disclosure` ให้แสดงผลมุมภาพอย่างชัดเจนและไม่รบกวนการเล่นเกม
- [ ] พัฒนา Logic การประมวลการตอบแบบ 3 ทางเลือก และส่งบันทึกสถิติการกดเลือกปุ่ม "ไม่แน่ใจ" ลงตาราง `action_logs`
- [ ] นำเข้าข้อมูลรูปภาพโจทย์และตำแหน่งพิกัดของไฮไลท์เฉลยในระบบ
