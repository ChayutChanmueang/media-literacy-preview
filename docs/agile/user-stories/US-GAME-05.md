## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกมกางโล่สะกดภัย "หยุด คิด ถาม ทำ" (G5) ที่เข้าใจง่ายและใช้เพียงแอคชั่นเดียว (แตะ)
**เพื่อให้** ซึมซับหลักคิดเพื่อระงับการกระทำเสี่ยงภัยออนไลน์ได้ง่ายขึ้น โดยไม่ถูกกดดันด้วยระบบควบคุมที่ซับซ้อน

*   **เอกสารออกแบบรายละเอียด (Detailed Design):** สามารถอ่านข้อกำหนดการวางหน้าจอและชุดข้อมูลโจทย์จำลองภัยพิบัติเสี่ยงออนไลน์เชิงลึกได้ที่ [G5 Detailed Design](../../gdd/design-g5.md)

---

## ✅ Acceptance Criteria
1. [ ] มีกลไกการควบคุมเพียงแอคชั่นเดียว (Single-Action) โดยผู้เรียนแตะ (Tap) บนสัญลักษณ์หรือข้อความภัยพิบัติที่กำลังตกลงมาโดยตรง
2. [ ] วัตถุภัยพิบัติจำลองสิ่งเร้า (เช่น ข้อความ "โอนเงินด่วนตอนนี้", "คุณได้รับโบนัส 100,000 บาท", "ลิงก์กรอกข้อมูลรับทอง") จะลอยลงมาจากด้านบนอย่างช้าๆ
3. [ ] เมื่อผู้เล่นแตะกางโล่สำเร็จ เกมจะแสดงผลอนิเมชั่น Slow-motion หรือหยุดชั่วคราว พร้อมแสดงคำแสดงสโลแกนทีละขั้น: **"หยุด"🛑 -> "คิด"🧠 -> "ถาม"💬 -> "ทำ"✅** อย่างชัดเจนเพื่อหยุดยั้งการตอบสนองที่รวดเร็วเกินไป
4. [ ] มีระบบสะสมระดับความมั่นใจ (Confidence Bar) เมื่อสลายภัยสำเร็จ และแสดงข้อความชื่นชมเชิงบวก (Positive Reinforcement) ท้ายเกมเมื่อแถบสะสมเต็ม
5. [ ] ไม่มีกลไกการจับเวลาที่กดดันหรือการจับแพ้ (ไม่มีหน้าจอ Game Over) หากแตะสลายภัยไม่ทัน ระบบจะใช้กล่องข้อความสอนความรู้เชิงบวกแทนการทำโทษ

## 🛠 Technical Tasks (Game G5 Development)
- [ ] ออกแบบ Interface เกมกางโล่ที่มีขนาดปุ่มและข้อความขนาดใหญ่ตามหลัก Accessibility สำหรับผู้สูงอายุ
- [ ] พัฒนา Logic การตกลงมาของสิ่งเร้าและระบบการตรวจจับการแตะเพื่อกางโล่ (Digital Shield Dynamics)
- [ ] พัฒนาอนิเมชั่นหยุดจอภาพ (Slow-motion timing) และการเรียงลำดับอักษรนำสโลแกนหลักของโครงการ
- [ ] พัฒนาระบบประมวลผลหลอดพลังความมั่นใจ (Confidence Bar) และหน้าจอให้ดาว/ชื่นชมท้ายเกม
- [ ] พัฒนาระบบการเก็บ Event และสถิติการเล่นส่งข้อมูลเข้าตารางฐานข้อมูล `action_logs`
