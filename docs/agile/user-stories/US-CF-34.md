## 📖 Description

**ในฐานะ** ผู้ใช้งานหรือผู้สูงอายุที่เข้ามาที่หน้าแรกของเว็บแอปพลิเคชัน (Landing Screen)  
**ฉันต้องการ** ให้ข้อความต้อนรับมีการเว้นวรรคตอนและไม้ยมกที่ถูกต้องตามหลักภาษาไทย ("สนุก ๆ")  
**เพื่อให้** หน้าเว็บดูสวยงาม เป็นทางการ และอ่านได้อย่างสบายตา  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

- ในข้อความต้อนรับบนหน้าแรก `src/app/page.tsx` (หรือในส่วนของข้อความแนะนำระบบ) ที่ปัจจุบันแสดงคำว่า **"สนุกๆ"** (ติดกันไม่มีช่องว่าง)  
- ปรับแก้ไขสตริงให้มีเว้นวรรคหน้าและหลังไม้ยมกเป็น **"สนุก ๆ"** (เช่น *"ชวนทุกท่านมาดูคลิปสั้นสนุก ๆ"*)
