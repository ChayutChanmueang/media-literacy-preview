## 🎛 สเปกปุ่มตอบ (เคาะแล้ว 2026-07-30)

เปลี่ยนจากเดิม **3 ปุ่มเรียงลงมา (~224px กินเกือบครึ่งจอ)** เป็น:

- **1 แถวแนวนอน 3 ปุ่มเท่ากัน** — ปุ่ม**สูงขึ้น**, ไอคอนอยู่บน + คำสั้นด้านล่าง (แนวตั้งในปุ่ม) เพื่อให้ 3 คอลัมน์บนจอ ~360px ยังอ่านได้
- **ปุ่มติดกัน ไม่เว้นช่องไฟ** แต่มี **เส้น border คั่นระหว่างปุ่มชัดเจน**; ทั้งชุดครอบด้วยกรอบมุมโค้งเดียว
- **ไอคอนบอก action** — ใช้ `lucide-react` (ติดตั้งแล้ว `^0.475.0`, เป็น SVG ตามที่ขอ ไม่ต้องเพิ่ม dep; ทางเลือก: Google Material Symbols แต่ต้องเพิ่มของใหม่):
  - จริง → 👍 `ThumbsUp`
  - ปลอม/มั่ว → 👎 `ThumbsDown`
  - ไม่แน่ใจ → ❓ `CircleHelp`
- **ย่อ label ให้ลง 3 คอลัมน์:** "น่าจะจริง"→**"จริง"**, "น่าจะปลอม (มั่ว)"→**"ปลอม/มั่ว"**, "ไม่แน่ใจ / ต้องเช็กก่อน"→**"ไม่แน่ใจ"** (ความหมาย "ต้องเช็กก่อน" สื่อผ่านไอคอน ❓ + หน้าเฉลย) — ⚠️ *ยืนยันการตัดคำ "น่าจะ" กับทีมวิชาการก่อน (โทน "น่าจะ" อาจตั้งใจสื่อความไม่ฟันธง)*
- **คงสีกำกับ + ไอคอนเสมอ** (ห้ามสื่อด้วยสีเดี่ยว): จริง=เขียว(success), ปลอม=แดง(error), ไม่แน่ใจ=teal(primary)
- **a11y:** label ≥20px, ไอคอน ~28–32px, ปุ่มสูง ≥ ~96px, touch ≥48px

## 🎬 หน้าเฉลย (Answer Reveal) — แบบ G6 (ปรับ 2026-07-30 รอบ 2)

ปัญหาเดิม: reveal ย้ำกล่องข่าวสาร (พร้อมแถบผลเป็นหัว) กินที่ครึ่งจอ จนคำอธิบายแทบไม่มีที่ → **เอากล่องข่าวสารออกจากหน้าเฉลย** ใช้โครงเดียวกับ G6:

1. **แถบผลด้านบน (verdict banner) แบบเดี่ยว** เต็มกว้าง สีตามผล (token): ถูก="ถูกต้อง เก่งมาก"(เขียว), ไม่แน่ใจ="รอบคอบมาก"(teal), ผิด="ยังไม่ถูก มาดูเฉลยกัน"(แดง) + ไอคอน ✓/⚠️
2. **กล่องคำอธิบายเต็มพื้นที่ที่เหลือ + scroll** (`CustomScrollArea`, scrollbar เสมอ) — หัวข้อปรับตามคำตอบ: ข่าวปลอม → **"⚠️ ทำไมข่าวนี้ถึงน่าสงสัย"**, ข่าวจริง → **"✅ ทำไมข่าวนี้เชื่อถือได้"**; เนื้อความ = `explanation` (คงข้อความชมเมื่อเลือก "ไม่แน่ใจ")
3. **ปุ่ม "ต่อไป" docked ล่างสุด** (แยกโซน ชิดขอบ แบบ G6 — ไม่ลอยทับแล้ว) — auto-advance 5 วิ + progress (`AutoAdvanceButton`) มีอยู่แล้ว (ข้าม req นี้)

**ไม่โชว์ตัวข่าวในหน้าเฉลยแล้ว** (เดิมย้ำ) — ฟอนต์: หัวข้อ/เนื้อความใช้ fluid clamp (ตาม font-scale ใหม่)
