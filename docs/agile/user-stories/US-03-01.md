> ℹ️ **หมายเหตุสำคัญ:** เรื่องย่อยนี้ถูกปรับเลื่อน (Deferred) จาก Sprint 03 ไปทำใน **Sprint 04** ตามมติของทีมโครงการ เพื่อนำ Feedback ตรงจากการใช้งานจริงในงานอบรมกระบวนกรเชียงใหม่ (6-7 ส.ค.) มาประเมินและทำการทดสอบร่วมกับกลุ่มเป้าหมายผู้สูงอายุจริงหลังงานอบรม


## 📖 Description
**ในฐานะ** ผู้สูงวัยที่เป็นผู้เรียน
**ฉันต้องการ** ให้แอปผ่านการเล่นทดสอบจริงโดยคนรุ่นเดียวกับฉัน
**เพื่อให้** มั่นใจว่าภาษาที่ใช้ ขนาดของหน้าจอ และการควบคุมการจิ้มปุ่มไม่ยากลำบากเกินไป

---

## ✅ Acceptance Criteria
1. [ ] วางแผนและจัดกระบวนการทดสอบกับผู้สูงอายุกลุ่มเป้าหมายจริง (อายุ 60 ปีขึ้นไป) จำนวนอย่างน้อย 3 คน
2. [ ] ทำการสังเกตและบันทึกจุดติดขัด (Pain points) ระหว่างเล่นเกม เช่น อนิเมชั่นตกเร็วไป หรือมองปุ่มเฉลยไม่ชัด
3. [ ] รวบรวมข้อเสนอแนะและทำการปรับปรุงแก้ไขโค้ดที่เกิดปัญหาเสร็จสิ้น

---

## 🛠 Technical Tasks (Senior User Testing)
- [ ] จัดทำใบประเมินและแบบทดสอบสำหรับการสังเกตการณ์การเล่นแอปของผู้สูงอายุ
- [ ] นัดหมายและทดสอบจริงกับผู้สูงอายุกลุ่มตัวอย่างอย่างน้อย 3 คน
- [ ] สรุปผล Pain points และดำเนินการปรับแก้ UI/UX ใน React components ตามลำดับ
