## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกมวิ่งหลบภัยไซเบอร์ (G7) ที่ควบคุมการเล่นเพียงแอคชั่นเดียว (แตะเพื่อกระโดด)
**เพื่อให้** ได้เรียนรู้หลักการหลบเลี่ยงไม่เข้าไปปฏิสัมพันธ์กับภัยสแกมและสิ่งเร้าแปลกปลอมในโลกออนไลน์ ด้วยรูปแบบเกมที่เข้าถึงง่ายและสนุกสนาน

---

## ✅ Acceptance Criteria
1. [ ] มีกลไกการเล่นแบบวิ่งด้านข้างอัตโนมัติ (Side-Scroller Auto-Runner) ควบคุมง่ายๆ โดยการแตะตรงไหนของจอภาพก็ได้ (Tap to Jump) เพื่อสั่งให้ตัวละครกระโดดข้ามอุปสรรค
2. [ ] มีอุปสรรคสิ่งกีดขวางจำลองแทนภัยออนไลน์ (เช่น ตู้โทรศัพท์แก๊งคอลเซ็นเตอร์, กล่อง SMS ชวนเชื่อ, ป้ายโฆษณาแจกเงินล้าน) วิ่งสวนเข้ามาเป็นระยะ
3. [ ] เมื่อกระโดดข้ามสิ่งกีดขวางได้สำเร็จ ระบบจะแสดงเสียงประกอบเชิงบวก (Happy SFX) พร้อมเก็บแต้มความมั่นใจเพิ่มขึ้นเรื่อยๆ
4. [ ] หากกระโดดพลาดจนชนสิ่งกีดขวาง ตัวละครจะไม่ล้มเจ็บ (เพื่อลดการสื่อภาพความรุนแรง) แต่เกมจะสโลว์ดาวน์และแสดงกล่องข้อความเตือนภัยและวิธีรับมือนั้นๆ ทันที
5. [ ] ไม่มีหน้าจอ Game Over ที่ทำโทษหรือตัดสินแพ้ แต่จะเน้นให้กระทำซ้ำและเรียนรู้เพื่อสร้างความมั่นใจในการก้าวข้ามด่านภัยพิบัติดิจิทัล

---

## 🛠 Technical Tasks (Game G7 Development)
- [ ] ออกแบบ Interface เกมและสร้างตัวละครผู้สูงอายุรวมถึงภัยสิ่งกีดขวางที่มีความต่างของสี (Contrast) และขนาดใหญ่เห็นได้เด่นชัด
- [ ] พัฒนา Logic การเลื่อนฉากและสิ่งเร้าด้านข้าง (Auto-scrolling stage structure) และกลไกกระโดดหลบ (Jump Physics)
- [ ] พัฒนาระบบชะลอความเร็ว (Freeze-on-hit) และ Overlay กล่องข้อความแนะนำขึ้นสอนทันทีเมื่อชนสิ่งกีดขวาง
- [ ] พัฒนาตัวนับคะแนนความสำเร็จเพื่อบันทึกและคำนวณผ่านเกณฑ์บทเรียน
- [ ] บันทึกการกระทำและประวัติความเร็วการชนสิ่งกีดขวางแบบ Asynchronous ลงตารางฐานข้อมูล `action_logs`
