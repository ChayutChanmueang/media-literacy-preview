## Story

**ในฐานะ** ผู้เล่น
**ฉันต้องการ** เห็นว่าการตัดสินใจของฉันส่งผลต่อครอบครัวและชุมชนอย่างไร แล้วได้ตอนจบตามผลรวม
**เพื่อที่จะ** รู้สึกว่าสิ่งที่ทำมีความหมาย ไม่ใช่แค่เก็บคะแนน — และไม่ถูกตำหนิเมื่อพลาด

## ขอบเขตของรอบนี้ (Prototype Scope)

**ทำในรอบนี้:**
- **3 ค่าสถานะ** ตาม §12: พลังงาน (โครงสร้างวัน), คะแนนรู้ทัน (ความก้าวหน้าส่วนตัว), ความปลอดภัยชุมชน (ผลรวมมินิเกม)
- ความปลอดภัยชุมชนขยับตามผล: ทำดี = เพิ่ม, พลาดบางส่วน = ไม่เพิ่ม/เพิ่มน้อย, เลือกเสี่ยง = ลดเล็กน้อย — **ไม่มี game over**
- **3 ตอนจบ** ตาม §16 (ชุมชนรู้ทันดีเยี่ยม / เริ่มรู้ทัน / ต้องช่วยกันอีกหน่อย) — **ไม่มีตอนจบล้มเหลว**, NPC ที่ช่วยไว้ปรากฏในฉากจบ
- ฉากเปิด (แนะนำเรื่อง) + ฉากจบ (สรุปตามค่าความปลอดภัยชุมชน)
- Consequence เชิงบวก/แก้ไข ไม่ลงโทษ (§19 SRS) — ตอบผิดอธิบายเหตุผล เปิดให้เรียนรู้

**ยังไม่ทำในรอบนี้:**
- เลือกตัวละครแม่น้ำอิง/พ่อจอม + ฉากเปิดเต็ม (อาจ mock ตัวเลือกไว้ก่อน — polish รอบหลัง)
- สถิติวิจัยครบชุด (→ US-WORLD-08/analytics)

## Acceptance Criteria (Prototype)

- [ ] HUD แสดง 3 ค่าสถานะถูกต้อง อัปเดตตามผลมินิเกม
- [ ] ความปลอดภัยชุมชนขยับตามกติกา §12.3 (เพิ่ม/คงที่/ลดเล็กน้อย) โดยไม่มีจอแพ้
- [ ] จบ 3 วัน → ได้ตอนจบ 1 ใน 3 ตามคะแนนรวม (ไม่มีตอนจบล้มเหลว)
- [ ] ฉากจบแสดง NPC ที่ผู้เล่นช่วย + ข้อความสรุปตามระดับความปลอดภัย
- [ ] ข้อความทุกจุดเป็นเชิงบวก/ให้กำลังใจ ไม่ตำหนิผู้เล่น (ตรวจตาม pillar §3.3)
