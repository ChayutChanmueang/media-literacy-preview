**ในฐานะ** ผู้ใช้ที่กำลังจะเข้าสู่เกม G13 "ต่อไอติมรู้ทันสื่อ"

## ✅ Acceptance Criteria

1. [ ] หน้า Intro G13 มี copy ภาษาไทยที่กระตุ้นความอยากเล่น เช่น นำเสนอเป็น "เกมฝึกสมองสนุกๆ" หรือ "ทดสอบสมาธิของคุณ"
2. [ ] มี visual ที่น่าสนใจ เช่น ภาพ/ไอคอนไอศกรีม หรือ animation เล็กน้อย
3. [ ] โทนเนื้อหาเป็นบวก มีพลัง และไม่รู้สึกเหมือนกำลังทำแบบทดสอบ
4. [ ] หน้า Intro ยังมีปุ่ม "เริ่มเล่น" ที่กดได้ชัดเจน
