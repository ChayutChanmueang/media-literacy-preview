## 📖 Description
**ในฐานะ** กระบวนกรและทีมดำเนินงาน
**ฉันต้องการ** สื่อนำทางและคิวอาร์โค้ด (QR Code) สำหรับผู้สูงอายุใช้แตะเข้าแอปเพื่อเริ่มเรียนได้อย่างแม่นยำ
**เพื่อให้** การจัดกิจกรรมอบรมเชียงใหม่วันที่ 6-7 ส.ค. ดำเนินไปอย่างราบรื่น ไม่ติดขัดที่ขั้นตอนการเปิดแอป

---

## ✅ Acceptance Criteria
1. [ ] จัดเตรียม QR Code สำหรับ Deep link บทเรียนต่าง ๆ ของระบบอย่างถูกต้อง
2. [ ] จัดทำคู่มือหรือสื่อประชาสัมพันธ์สำหรับการนำระบบไปใช้ในกลุ่มผู้สูงอายุจริงหน้างาน
3. [ ] ทดสอบการจำลองกิจกรรมร่วมกับกระบวนกร เพื่อซ้อมและประเมินขั้นตอนการไหล (Flow) ของกิจกรรม

- [ ] ซักซ้อมขั้นตอนกับกระบวนกรหน้างานเพื่อหาข้อขัดข้องและเตรียมแผนสำรอง (เช่น เปิด Chrome ปกติ)
