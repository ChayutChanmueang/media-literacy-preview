# User Story: US-03-04 - การจัดทำระบบเปลี่ยนทิศทางลิงก์เก่า (Legacy URL Redirection)

**Status:** 🏗 Planned

## 📖 Description
**ในฐานะ** ผู้เรียนสูงวัยที่ถือลิงก์ประชาสัมพันธ์เก่า
**ฉันต้องการ** ให้ลิงก์จากช่องทางเดิมของสถาบันหรือเอกสารเก่า สามารถนำทางฉันมายังระบบจริงที่ย้ายโดเมนแล้วได้โดยอัตโนมัติ
**เพื่อให้** ไม่สับสนจากข้อความแจ้งเตือน "ไม่พบหน้าเว็บ" หรือลิงก์เสีย

---

## ✅ Acceptance Criteria
1. [ ] กำหนดค่าการเปลี่ยนเส้นทาง (URL Redirection) จากพาร์ทหรือโดเมนย่อยสถาบันเดิม เช่น ผ่านการตั้งค่า `vercel.json` หรือ Cloudflare Page rules
2. [ ] ลิงก์ประชาสัมพันธ์เดิมทั้งหมดที่เผยแพร่ไปแล้ว ต้องนำทางผู้เรียนมายัง URL โดเมนปัจจุบันได้อย่างไร้รอยต่อ

---

## 🛠 Technical Tasks (Legacy URL Redirection)
- [ ] กำหนดการตั้งค่า redirect ใน `vercel.json` หรือเครื่องมือโฮสติ้งหลัก
- [ ] ทำการทดสอบจำลองการเข้าผ่าน URL คณะ/แหล่งทุนเดิม เพื่อยืนยันว่านำทางมายังแอปเวอร์ชันล่าสุด
