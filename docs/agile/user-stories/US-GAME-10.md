## Story

**ในฐานะ** ผู้สูงอายุที่อาจถูกหลอกให้ติดตั้งแอปแปลกปลอมลงมือถือ
**ฉันต้องการ** ฝึกสังเกตว่าเครื่องมีแอปปลอมอยู่ไหม แล้วลบออก
**เพื่อที่จะ** ป้องกันแอปดูดเงิน/รีโมตควบคุมเครื่องในชีวิตจริง

## ขอบเขตของรอบนี้ (Prototype Scope)

รอบนี้ทำเป็น **prototype เพื่อทดสอบว่ากลไก "ตรวจแล้วลบแอปปลอม" เข้าใจง่ายไหม** ยังไม่ใช่เวอร์ชันส่งมอบ:

**ทำในรอบนี้ (โค้ด):**
- กลไกครบตาม [design-g10.md](../../gdd/design-g10.md): 5 ด่าน (ตาราง 2×2 ×2 → 3×2 ×2 → 3×3 ×1), แตะแอปเปิดการ์ดตรวจสอบ (ชื่อ/ที่มา/สิทธิ์) → ลบปลอม/เก็บจริง, การ์ดเฉลย + red flags, ด่านผ่านเมื่อลบแอปปลอมครบ, ตัวนับ "เหลือแอปปลอมต้องหา", คำนวณดาว
- `src/components/G10WhoseApp.tsx` + คลังแอป `src/data/g10-app-items.json` (แอปจริง 12 + ปลอม 10)
- **ไอคอนใช้ emoji ชุดเดียวกันทั้งแอปจริงและปลอม** (ต่างที่ชื่อ/ที่มา/สิทธิ์) ตามหลักการ "หน้าตาเหมือนกันให้จำง่าย"
- ลงทะเบียนใน [Dev Game Hub](./US-03-R4.md) (`/dev/games`) — badge "🏗️ Prototype"

**ยังไม่ทำในรอบนี้:**
- ไอคอน/ภาพแอปจริง (ใช้ emoji เป็นตัวแทนชั่วคราว)
- คลังแอปฉบับสมบูรณ์ที่ทีมวิชาการ NAPLAB ตรวจ
- ผูกเข้า flow ผู้เรียนใน `/lessons/[id]/game` และบันทึกดาวลงระบบ
- กลไก **ลากไอคอนไปถังขยะ** (ยังใช้แตะ→ปุ่มลบ — drag-to-trash เป็น Open Question ใน design §11)

## Acceptance Criteria (Prototype) — โค้ดครอบคลุมแล้ว รอ playtest ยืนยัน

> ยังไม่ติ๊ก `[x]` เพราะยังไม่ได้เล่นคลิกจริงในเบราว์เซอร์ (component โหลดแบบ dynamic `ssr:false`)

- [ ] เล่นได้ครบ 5 ด่าน: ตาราง 2×2 (×2 ด่าน) → 3×2 (×2 ด่าน) → 3×3 (×1 ด่าน)
- [ ] เลเวล 1 แอปปลอม 1–2, เลเวล 2 แอปปลอม 1–2, เลเวล 3 แอปปลอมเหลือ 1 ตัวซ่อนในแอปจริง 8 ตัว
- [ ] แตะแอปเปิดการ์ดตรวจสอบเห็นชื่อ + ที่มา (Store/ลิงก์) + สิทธิ์ที่ขอ (ไฮไลต์สิทธิ์อันตราย: อ่าน SMS/ควบคุมหน้าจอ/ติดตั้งแอป)
- [ ] ลบแอปปลอมถูก = แอปหาย + เสียงชื่นชม, ลบแอปจริง/เก็บแอปปลอม = การ์ดนุ่มนวลไม่ลงโทษ แอปยังอยู่ให้แก้ใหม่
- [ ] ด่านผ่านเมื่อลบแอปปลอมครบ ไม่มีจับเวลา ไม่มีจอแพ้
- [ ] มีปุ่ม **"ครบแล้ว ✓"** — ถ้าลบปลอมครบไปด่านต่อทันที, ถ้ายังเหลือจะเปิด popup เฉลยแอปที่มองข้าม (นับเป็นพลาดในการคิดดาว) แล้วไปต่อ
- [ ] ไอคอนแอปจริงและปลอมใช้ชุดหน้าตาซ้ำเดิม ต่างกันที่ชื่อ/ที่มา/สิทธิ์
- [ ] จบเกมส่งดาวผ่าน `onFinish(stars)` จาก first-try accuracy (≥80% = 3, ≥50% = 2, ต่ำกว่า = 1)
