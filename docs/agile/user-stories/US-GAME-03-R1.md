## 🔍 การขยายรูป — โหมดเต็มจอ + Pinch Gesture (ปรับ 2026-07-31)

**ปัญหาเดิม:** ปุ่มซูมเดิมแค่ขยายภาพ (`object-cover scale-150`) **ภายในกรอบภาพ** เท่านั้น — ผู้สูงอายุยังเห็นรายละเอียดไม่ชัด และคำว่า "ซูม" ผู้สูงอายุบางคนไม่เข้าใจ

**สเปกใหม่:**
1. **เปลี่ยนชื่อปุ่มเป็น "ขยายรูป"** (เลิกใช้คำว่า "ซูม"/"ซูมขยาย") + ไอคอนขยาย (`Maximize2`) — ปุ่ม toggle เดิม (ขนาดปกติ/ซูมขยาย) ถูกแทนด้วยปุ่มเปิดโหมดเต็มจอปุ่มเดียว
2. **กดแล้วเปิดภาพแบบเต็มจอ (fullscreen overlay)** — ทับทั้งหน้าจอจริง (`fixed inset-0`, เกินกรอบ `#root-container` 480px ได้) พื้นหลังทึบเพื่อให้เห็นภาพชัด
3. **ใช้นิ้วทำ gesture ย่อ/ขยายได้ตามปกติ** — เนื่องจาก viewport ของแอปตั้ง `maximumScale:1, userScalable:false` (ปิด pinch-zoom ของเบราว์เซอร์ทั้งแอป) จึงต้อง**ทำ pinch-to-zoom + pan เองด้วย Pointer Events** (2 นิ้ว = ย่อ/ขยาย, 1 นิ้วลากเมื่อซูมอยู่ = เลื่อนดู); จำกัด scale ~1×–5×; ปล่อยนิ้วแล้วถ้าใกล้ 1× ให้ snap กลับพอดีเฟรม
4. **ปุ่ม "ปิด" ขนาดใหญ่ + ไอคอนกากบาท (`X`) อยู่ด้านล่าง** — กดเพื่อปิดโหมดเต็มจอ / ย่อรูปกลับไปในกรอบภาพเดิม (touch ≥ ขนาดปุ่มหลักผู้สูงอายุ); รองรับปุ่ม Esc ด้วย (a11y)
5. **ป้าย `ai_disclosure`** ถ้ามี ให้แสดงในโหมดเต็มจอด้วย (คงนโยบาย AI Content แม้ดูภาพเต็มจอ)
6. แยกเป็น component ใช้ซ้ำได้: `FullscreenImageViewer` (เกมอื่นที่มีภาพ เช่น G9/G10 นำไปใช้ต่อได้)

## 🎬 หน้าเฉลย (Answer Reveal) — แบบ G6 (ปรับ 2026-07-30 รอบ 2)

ปัญหาเดิม: reveal ย้ำการ์ดภาพ (พร้อมแถบผลเป็นหัว) กินที่ จนคำอธิบายไม่มีที่ → **เอาการ์ดภาพออกจากหน้าเฉลย** ใช้โครงเดียวกับ [G6](./US-GAME-06-R1.md):
1. **แถบผลด้านบนแบบเดี่ยว** เต็มกว้าง สีตามผล + ไอคอน (ถูก=เขียว/ไม่แน่ใจ=teal/ผิด=แดง)
2. **กล่องคำอธิบายเต็มจอ + scroll** (`CustomScrollArea`) — หัวข้อปรับตามคำตอบ: ภาพ AI → **"⚠️ ทำไมภาพนี้ถึงปลอม (AI สร้าง)"**, ภาพจริง → **"✅ ทำไมภาพนี้เป็นของจริง"**; เนื้อความ = `explanation` (บรรยายจุดสังเกตเป็นข้อความ)
3. **ปุ่ม "ต่อไป" docked ล่างสุด** (แบบ G6) + auto-advance 5 วิ มีอยู่แล้ว (ข้าม req)
- **ไม่โชว์ภาพในหน้าเฉลยแล้ว** (เดิมย้ำ) — ⚠️ ผู้เล่นเห็นภาพเฉพาะตอนโจทย์ (ซูมได้); **ป้าย `ai_disclosure` ย้ายเข้าไปแสดงในกล่องคำอธิบาย** (นโยบาย AI Content บังคับให้แสดงในหน้าเฉลย ตอนไม่มีภาพแล้ว) — flag ทีมวิชาการ
- ไม่มีวงกลมแดง/hotspot (data `hotspots` = dead ตัดทีหลังได้)

## 🎛 สเปกปุ่มตอบ (ปรับ 2026-07-30 — ให้เหมือน G1 ทุกอย่าง ตามคำสั่งผู้ใช้)

โครง + label + ไอคอน **เหมือน [US-GAME-01-R1](./US-GAME-01-R1.md) เป๊ะ**: 1 แถว 3 ปุ่มเท่ากัน, **ชิดขอบล่างจอ**, ติดกัน, เส้น border คั่นชัด, `radius 25px 25px 0 0`, ปุ่มสูง (~100px) ไอคอนบน+คำล่าง

- **label + ไอคอน (เปลี่ยนจาก Bot/Camera เดิม → เหมือน G1):**
  - **จริง** → 👍 `ThumbsUp` (เขียว success) = ภาพถ่ายจริง → `handleAnswer('real')`
  - **ปลอม** → 👎 `ThumbsDown` (แดง error) = สร้างโดย AI → `handleAnswer('ai')`
  - **ไม่แน่ใจ** → ❓ `CircleHelp` (teal primary) → `handleAnswer('unsure')`
- ⚠️ **Divergence จาก GDD (ต้องยืนยันทีมวิชาการ):** GDD §G3 ใช้คำ "สร้างโดย AI" / "ภาพถ่ายจริง" — การเปลี่ยนเป็น "จริง/ปลอม" คือตีความภาพ AI = "ปลอม (ทำขึ้น)" เพื่อสั้น/สอดคล้อง G1 ตามคำสั่งผู้ใช้ **logic เดิม (real/ai/unsure) + ป้าย `ai_disclosure` ในหน้าเฉลยไม่เปลี่ยน**; ประเด็นถก: ภาพ AI ≠ "ของหลอกลวง" เสมอไป — ให้ทีมวิชาการชี้ขาดว่าคำ "ปลอม" เหมาะไหม
- a11y: ปุ่ม 22px, ไอคอน ~34px, สูง ~100px, touch ≥48px; มีไอคอนเสมอ
- **ปัดซ้าย-ขวา** ยังใช้ได้คู่การแตะปุ่ม (ตาม GDD) — ไม่ตัด swipe
