## 📖 Description

**ในฐานะ** ผู้ชมคลิปและผู้เล่นระบบรู้ทันสื่อ  
**ฉันต้องการ** เห็นชื่อคลิปและบทเรียน **"ใคร ๆ ก็ทำสื่อได้"** เขียนเว้นวรรคหน้าหลังไม้ยมกตามมาตรฐานภาษาไทย  
**เพื่อให้** ดูสบายตา สมบูรณ์แบบ และสอดคล้องกับข้อความในส่วนอื่น ๆ ของแอปพลิเคชัน

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

- ตรวจสอบในหน้าแสดงวิดีโอ (Video Player Screen) รวมถึงหัวเรื่องคลิปบทที่ 1 หรือใน Registry  
- คำว่า `"ใครๆก็ทำสื่อได้"` ที่ปรากฏอยู่ ให้แก้เป็น **`"ใคร ๆ ก็ทำสื่อได้"`** (ใส่เว้นวรรคหน้าไม้ยมก 1 ช่อง และหลังไม้ยมก 1 ช่อง)
