## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกมตอบคำถามประเมินการแชร์ข้อมูลส่วนบุคคล "แชร์ดีไหม?" (G4)
**เพื่อให้** ตระหนักและสามารถระวังภัยจากการเผยแพร่ข้อมูลความเป็นส่วนตัวออนไลน์ (Online Privacy) ไม่ให้ตกเป็นเป้าหมายของมิจฉาชีพ

---

## ✅ Acceptance Criteria
1. [ ] แสดงภาพจำลองสถานการณ์การกระทำหรือสิ่งที่ผู้เล่นมักแชร์ลงโซเชียลมีเดียทีละข้อ (จำนวนโจทย์อย่างน้อย 5 ข้อ)
2. [ ] มีตัวเลือกขนาดใหญ่ 3 ตัวเลือก: "แชร์ได้ปลอดภัย" (สีเขียว), "ไม่ควรแชร์เด็ดขาด" (สีแดง) หรือ "ไม่แน่ใจ / ต้องเช็กก่อน" (สีเหลือง)
3. [ ] หลังเลือกคำตอบ ระบบจะแสดงเฉลยทันทีพร้อมอธิบายความเสี่ยงและผลกระทบของประเภทข้อมูลนั้นๆ อย่างเป็นมิตรและลึกซึ้ง (เช่น โจรกรรมตัวตน, ชี้พิกัดบ้านเพื่อขโมยของ)
4. [ ] สนับสนุนการทำงานร่วมกับระบบเสียงอ่านโจทย์และเฉลยเพื่อความง่ายต่อผู้ที่มีปัญหาทางสายตา
5. [ ] ไม่มีกลไกการจับเวลาที่กดดันหรือการจับแพ้ด้วยความล้มเหลว
6. [ ] เมื่อผู้เล่นกดยืนยันเลือกตอบ "ไม่แน่ใจ / ต้องเช็กก่อน" ระบบจะแสดงข้อความชมเชยในหน้าเฉลยชื่นชมความรอบคอบและชี้แนะเกณฑ์วิเคราะห์ภัยส่วนบุคคลเพิ่มเติม

---

## 🛠 Technical Tasks (Game G4 Development)
- [ ] ออกแบบ Interface สำหรับการเลือกตอบแนวตั้งที่มีภาพประกอบขนาดใหญ่ชัดเจนและปุ่มกดขนาดใหญ่ 3 ทางเลือก สอดคล้องกับหลัก Accessibility
- [ ] พัฒนาระบบฐานข้อมูลเนื้อหาโจทย์ ภาพประกอบ พิกัด และคำอธิบายเฉลย
- [ ] พัฒนา Logic การคำนวณสถิติตอบแบบ 3 ทางเลือก (แชร์ได้/ห้ามแชร์/ไม่แน่ใจ) และส่งข้อมูล Asynchronous logs ไปบันทึกยังตาราง `action_logs`
