## 📖 Description

**ในฐานะ** ผู้สูงอายุที่กำลังเลือกข้อมูลพื้นฐาน (จังหวัด/อำเภอ/ตำบล และช่วงอายุ) ในหน้าแรกก่อนเข้าเกม  
**ฉันต้องการ** เห็นคำว่า **"อื่น ๆ"** ในตัวเลือกอายุที่สะกดและเว้นวรรคถูกต้อง และมี **ตัวอักษรตัวเลือกพื้นที่ขนาดใหญ่เพียงพอ**  
**เพื่อให้** อ่านได้ง่าย กดเลือกได้อย่างแม่นยำ ไม่ต้องเกร็งหรือเพ่งสายตาตามหลักการรองรับผู้สูงอายุ  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

1. **เว้นวรรคไม้ยมกตัวเลือกอายุ:**  
   - ในตัวเลือกช่วงอายุ ให้ปรับคำว่า `"อื่นๆ"` เป็น `"อื่น ๆ"` (มีเว้นวรรคด้านหน้าและด้านหลังไม้ยมก)  
2. **ขยายขนาดตัวหนังสือตัวเลือกพื้นที่ (Province/District Selector):**  
   - ลูกค้าสังเกตว่าขนาดตัวหนังสือตอนเลือกพื้นที่ (Dropdown หรือ Radio) มีขนาดเล็กลง ให้ตรวจสอบ Tailwind class  
   - ปรับขยายขนาดฟอนต์ให้ใหญ่ขึ้น (อย่างน้อย $\ge 18\text{px}-20\text{px}$) และเพิ่มความสูงปุ่มหรือ padding ให้เหมาะสม เพื่อให้ผู้สูงอายุอ่านง่ายและทัชสะดวกที่สุด
