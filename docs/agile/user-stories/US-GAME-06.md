# User Story: US-GAME-06 - เกมจำลองแชท LINE (G6 - LINE Chat Simulation Game)

**Status:** 🏗 Planned
**Epic:** [Product Backlog](../01-product-backlog.md)
**Owner:** TBD
**Version:** 1.0 | **Last Updated:** 2026-07-05

---

## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกมจำลองแชท LINE (G6) ที่มีมิจฉาชีพแอดไลน์ทักแชทเข้ามาหลอกลวง
**เพื่อให้** เกิดความตระหนักรู้และคุ้นเคยกับลักษณะบทสนทนาหลอกลวงของมิจฉาชีพในสภาพแวดล้อมจำลองที่คล้ายแอปพลิเคชัน LINE ที่ใช้จริง

---

## ✅ Acceptance Criteria
1. [ ] จำลองห้องแชทของ LINE Platform ที่มีรายละเอียดสมจริง (เช่น ชื่อบัญชีผู้ส่ง, แถบสนทนา, ฟองคำพูดแชท)
2. [ ] จำลองสถานการณ์หลอกลวงอย่างน้อย 3 รูปแบบ (เช่น เจ้าหน้าที่รัฐทวงภาษีค้างจ่าย, การเสนอสิทธิ์ลุ้นโบนัสปีใหม่, หรือการชักชวนลงทุนวัยเกษียณ)
3. [ ] ผู้ใช้สามารถใช้นิ้วมือแตะเพื่อเลือกหา "จุดที่ผิดปกติ" (Red Flags Hotspots) บนหน้าแชทจำลองได้จริง (เช่น การเร่งรัดโอนเงินด่วน, การแนบลิงก์น่าสงสัย, หรือการแอบอ้างตำแหน่งเจ้าหน้าที่ระดับสูง)
4. [ ] แสดงเฉลยโดยการตีกรอบจุดผิดปกติแต่ละจุดสีแดงพร้อมคำอธิบาย และสรุปขั้นตอน "หยุด คิด ถาม ทำ" พร้อมช่องทางการโทรศัพท์แจ้งความออนไลน์
5. [ ] มีระบบบอกใบ้ (Hint System) คอยแนะนำเมื่อผู้เล่นแตะไม่เจอจุดสังเกตเพื่อช่วยลดความอึดอัดในการเล่น

---

## 🛠 Technical Tasks (Game G6 Development)
- [ ] พัฒนา UI Component หน้าจอแชท LINE จำลองที่ตัวอักษรใหญ่ ปุ่มกดง่าย สอดคล้องกับข้อกำหนดการออกแบบของผู้สูงอายุ
- [ ] พัฒนาระบบ Interactive Hotspots สำหรับตรวจจับการแตะจุดผิดปกติในบทสนทนา
- [ ] พัฒนาระบบคำนวณคะแนนจับสัญญาณมิจฉาชีพ และระบบ Hint เมื่อผู้เล่นใช้เวลาค้นหานานเกินเกณฑ์
- [ ] ออกแบบ Overlay เฉลยแสดงความรู้อย่างละเอียดพร้อมไฮไลท์ตำแหน่งที่ถูกต้องบนหน้าจอแชท
- [ ] พัฒนาระบบ Asynchronous Event Logging ส่งข้อมูลลงฐานข้อมูลตาราง `action_logs`
