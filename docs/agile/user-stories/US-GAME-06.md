## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกมจำลองแชท LINE (G6) ที่มีมิจฉาชีพแอดไลน์ทักแชทเข้ามาหลอกลวง
**เพื่อให้** เกิดความตระหนักรู้และคุ้นเคยกับลักษณะบทสนทนาหลอกลวงของมิจฉาชีพในสภาพแวดล้อมจำลองที่คล้ายแอปพลิเคชัน LINE ที่ใช้จริง

---

## ✅ Acceptance Criteria
1. [ ] จำลองห้องแชทของ LINE Platform ที่มีรายละเอียดสมจริง (เช่น ชื่อบัญชีผู้ส่ง, แถบสนทนา, ฟองคำพูดแชท)
2. [ ] จำลองสถานการณ์หลอกลวงอย่างน้อย 3 รูปแบบ (เช่น เจ้าหน้าที่รัฐทวงภาษีค้างจ่าย, การเสนอสิทธิ์ลุ้นโบนัสปีใหม่, หรือการชักชวนลงทุนวัยเกษียณ)
3. [ ] ข้อความบทสนทนาทยอยขึ้นเองอัตโนมัติทีละฟอง (จำลองว่ามีการสนทนาใหม่เข้ามาจากคนแปลกหน้า) เมื่ออ่านครบทุกฟองแล้ว ผู้เล่นต้องเลือกตอบกลับ 1 ใน 3 ทาง คือ **ยอมรับ** (ทำตามคำสั่งมิจฉาชีพ), **ปฏิเสธ** (ตอบกลับว่าไม่ยอม), หรือ **นิ่งเฉย** (ไม่ตอบกลับ)
4. [ ] หลังเลือกตอบกลับ แสดงผลลัพธ์ของทางเลือกนั้น (ปลอดภัย/เสี่ยง พร้อมไอคอนกำกับ ไม่ใช้สีสื่อความหมายเดี่ยว) และตีกรอบจุดผิดปกติ (Red Flag) ทุกจุดในบทสนทนาสีแดงพร้อมคำอธิบาย รวมถึงสรุปขั้นตอน "หยุด คิด ถาม ทำ" พร้อมช่องทางการโทรศัพท์แจ้งความออนไลน์
5. [ ] มีระบบบอกใบ้ (Hint System) คอยแนะนำเมื่อผู้เล่นอ่านบทสนทนาจบแล้วแต่ยังไม่กดเลือกตอบกลับนานเกินไป เพื่อช่วยลดความอึดอัดในการตัดสินใจ

## 🛠 Technical Tasks (Game G6 Development)
- [ ] พัฒนา UI Component หน้าจอแชท LINE จำลองที่ตัวอักษรใหญ่ ปุ่มกดง่าย สอดคล้องกับข้อกำหนดการออกแบบของผู้สูงอายุ
- [ ] พัฒนาระบบ Auto-play เปิดเผยฟองข้อความอัตโนมัติทีละฟอง พร้อม Typing Indicator และปุ่มตอบกลับ 3 แบบที่ปลดล็อกเมื่ออ่านจบ
- [ ] พัฒนาระบบคำนวณดาวจากสัดส่วนทางเลือกตอบกลับที่ปลอดภัย และระบบ Hint เมื่อผู้เล่นตัดสินใจนานเกินเกณฑ์
- [ ] ออกแบบ Overlay เฉลยแสดงผลลัพธ์ของทางเลือกที่เลือก พร้อมไฮไลท์ตำแหน่ง Red Flag บนหน้าจอแชท
- [ ] พัฒนาระบบ Asynchronous Event Logging ส่งข้อมูลลงฐานข้อมูลตาราง `action_logs`
