## 📖 Description

ปรับถ้อยคำและปุ่มในเกม G1 (`src/components/G1FactCheck.jsx`) ให้ชัดเจน/ถูกหมวด และแก้ปัญหา label ปุ่มไม่ตรงกับสิ่งที่เกิดขึ้นจริง

---

## 🎯 สิ่งที่ต้องแก้

**1) วิธีเล่น (GameIntro / หน้าแนะนำ)**
- ใช้/เพิ่มข้อความวิธีเล่น: **"ลองอ่านข้อความต่อไปนี้ แล้วพิจารณาว่าจริงหรือไม่"**
- ปัจจุบัน `objective="อ่านข่าวที่ถูกแชร์กันมา แล้วช่วยกันตัดสินว่าเป็นข่าว "จริง" หรือ "มั่ว""` + `instructions=[...]` → ปรับให้มีประโยคนี้

**2) หมวดนำหน้า claim (prefix)**
- ข้อ "ดื่มน้ำมะนาวผสมโซดา...ทำลายเซลล์มะเร็ง" (id `g1-q3`) ขึ้นต้น `ข่าวสารการเตือนภัย:` → **ไม่เหมาะ** ควรเป็น **`ข่าวสารสุขภาพ:`**
- **ทบทวน prefix ของทุกข้อ** ว่าตรงหมวดจริงไหม (เช่น ข้อพายุฝน `g1-q?` = การเตือนภัยจริง คงไว้ได้; ข้อสุขภาพ/การเงิน/ราชการ ควรใช้หมวดให้ตรง)

**3) ปุ่มข้อสุดท้าย "ดูคะแนนสรุป" → ต้องมีหน้าคะแนนจริง + หน้าชื่อคลิปคั่น** (requirement ใหม่ 2026-08-04)

flow ใหม่หลังจบเกม (G1/G3/G6) ในโหมด flow:
1. กดปุ่มข้อสุดท้าย → **หน้าสรุปคะแนน (ดาว)** — ใช้ `summary` page เดิม (โชว์ดาว) แต่แก้ flow-next ให้ตรง flow ปัจจุบัน (`flow.ts`: G1→topic-3, G3→topic-6, G6→G13)
2. จากหน้าคะแนน → **หน้าชื่อคลิป** (คั่นก่อนดูคลิป) — รูปแบบเดียวกับหน้า Start Menu ([US-CF-22](./US-CF-22.md)) แต่:
   - บรรทัดบนใช้ **"รับชมคลิป"** (ไม่ใช่ "พร้อมแล้วไปดูคลิป"), บรรทัดล่างคง **"กันเลย!"**
   - ชื่อคลิป: ก่อน G3 = **"ทำไมคนถึงเชื่อข่าวปลอม"**, ก่อน G6 = **"เชื่อได้หรือไม่"** (topic-1 "ใครๆก็ทำสื่อได้" ใช้ Start Menu อยู่แล้ว)
   - ปุ่ม **"ดูคลิป"** กดเองได้ + **auto-advance 15 วิ** (แถบ progress) ครบแล้วเข้าวิดีโอให้เอง
3. → วิดีโอสั้น → เกมถัดไป

**การทำ:** หน้าชื่อคลิปทำเป็น **phase "intro" ของ `video/page.tsx`** (แสดงก่อนเล่นวิดีโอ เมื่อ flow + topic-3/topic-6); สร้าง component `ClipTitleCard` ใช้ร่วมกับ Start Menu; ปุ่ม "ดูคลิป" ใช้ `AutoAdvanceButton delayMs={15000}`
