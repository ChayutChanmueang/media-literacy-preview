## 📖 Description

**ในฐานะ** ผู้เรียนและผู้สูงอายุที่กำลังจะเริ่มเข้าชมวิดีโอคลิปแรก  
**ฉันต้องการ** เห็นข้อความชวนชมคลิปที่ตัวสะกดถูกต้อง ไม่มีคำผิด และสื่อชื่อเรื่องคลิปอย่างตรงประเด็นว่า **“ยุคโซเชียลมีเดีย ใคร ๆ ก็ทำสื่อได้"**  
**เพื่อให้** เข้าใจบริบทเนื้อหาก่อนดูและไม่สะดุดกับคำผิด  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

- ในหน้าก่อนถึงคลิปรู้ทันสื่อ (Video Intro / Start Menu / ClipTitleCard) ที่แสดงข้อความเชิญชวนผู้เล่น  
- **ข้อความเดิม (มีคำผิดและไม่มีเว้นวรรค):**  
  *"พรอ้มแล้วไปดูคลิป"ใครๆก็ทำสื่อได้"กันเลย!"* (คำว่า "พรอ้ม" พิมพ์ผิด และไม้ยมกไม่เว้นวรรค)  
- **แก้ไขเป็น:**  
  *"พร้อมแล้วไปดูคลิป “ยุคโซเชียลมีเดีย ใคร ๆ ก็ทำสื่อได้" กันเลย!"*  
  (แก้ไขคำสะกด "พร้อม", เพิ่มประโยค "ยุคโซเชียลมีเดีย", และใส่เว้นวรรคหน้า-หลังไม้ยมก "ใคร ๆ")
