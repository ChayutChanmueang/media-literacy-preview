**Owner:** TBD

## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกม "จริงหรือมั่ว?" (G1) เพื่อฝึกแยกแยะข่าวจริง-ข่าวปลอม
**เพื่อให้** รู้เท่าทันข่าวสารและไม่หลงเชื่อหรือแชร์ข้อมูลที่บิดเบือน

---

## ✅ Acceptance Criteria
1. [ ] มีโจทย์คำถามเกี่ยวกับข่าวสารและข้อความลวงอย่างน้อย 5 ข้อ
2. [ ] มีปุ่มเลือกตอบชัดเจน 3 ตัวเลือก คือ "จริง", "มั่ว" และ "ไม่แน่ใจ / ต้องเช็กก่อน" โดยใช้ขนาดปุ่มขนาดใหญ่และสีสังเกตง่ายตามหลักการออบแบบผู้สูงอายุ
3. [ ] แสดงหน้าจอเฉลยพร้อมคำอธิบายเหตุผลและจุดสังเกตอย่างละเอียดทุกข้อทันทีหลังกดยืนยันคำตอบ
4. [ ] ไม่มีกลไกการจับเวลา (No Timer) เพื่อให้ผู้สูงอายุสามารถใช้เวลาอ่านและทำความเข้าใจได้อย่างเต็มที่
5. [ ] เมื่อผู้เล่นกดยืนยันเลือกตอบ "ไม่แน่ใจ / ต้องเช็กก่อน" ระบบจะแสดงข้อความชมเชยในหน้าเฉลยว่าเป็นทางเลือกที่รอบคอบและให้ข้อมูลช่องทางการตรวจสอบประกอบ

---

## 🛠 Technical Tasks (Game G1 Development)
- [ ] ออกแบบ Interface หน้าตาเกม G1 ตามเกณฑ์ Accessibility (ตัวอักษรใหญ่ คอนทราสต์สูง)
- [ ] พัฒนาระบบเก็บข้อมูลและโครงสร้างโจทย์เกม G1 (คำถาม, รูปภาพประกอบ, เฉลย, คำอธิบายเหตุผล)
- [ ] พัฒนา Logic การตอบคำถามแบบ 3 ทางเลือกและเปลี่ยนข้อ และรวบรวมสถานะตอบถูก/ผิด/ไม่แน่ใจ
- [ ] พัฒนาระบบส่งข้อมูลประวัติการกดปุ่ม "ไม่แน่ใจ" เพื่อเก็บบันทึกประชากรลงฐานข้อมูล `action_logs`
- [ ] พัฒนาหน้าสรุปคะแนนเมื่อเล่นครบทุกข้อ พร้อมปุ่มนำทางไปกิจกรรมถัดไปตาม Sequence
