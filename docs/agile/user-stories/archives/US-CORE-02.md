**Status:** ✅ Done
**Epic:** [Core / โครงระบบ](../01-product-backlog.md)
**Owner:** TBD
**Version:** 1.1 (Completed) | **Last Updated:** 2026-07-03

## 📖 Description
**ในฐานะ** ผู้เรียนวัยเก๋าและกระบวนกรอบรม
**ฉันต้องการ** หน้าแรกต้อนรับและขอความยินยอม (Onboarding & Consent) ที่รวมข้อมูลการเลือกช่วงอายุและนโยบายความเป็นส่วนตัว (PDPA) อยู่ในหน้าจอเดียว โดยใช้การตรวจจับพิกัดพื้นที่ผ่านเลข IP อุปกรณ์อัตโนมัติ
**เพื่อให้** ขั้นตอน Onboarding ใช้การกดคลิกเพียงแค่ 2 ครั้ง (เลือกช่วงอายุ และ กดยอมรับเริ่มเรียนรู้) ลดอุปสรรคการสัมผัสและความยากในการกรอกข้อมูลสำหรับผู้สูงอายุ

---

## ✅ Acceptance Criteria
1. [x] นำเสนอแบบฟอร์ม Onboarding ทั้งหมด (อายุ นโยบาย PDPA ตรวจพิกัด) รวมอยู่บนหน้าจอเดียวจบ (Unified Onboarding)
2. [x] มีปุ่มตัวเลือกวิทยุ (Radio Option) ขนาดใหญ่ คอนทราสต์สูง สำหรับการระบุกลุ่มช่วงอายุ (50-59, 60-69, 70-79, 80+)
3. [x] ตรวจพิกัด จังหวัด/อำเภอ/ตำบล ของอุปกรณ์ผู้ใช้อัตโนมัติจาก IP (IP Geolocation Tracker) โดยไม่มีการเก็บที่อยู่ IP ดิบ
4. [x] ตัดฟอร์มกรอกเมนู Dropdown เลือกตำบล/อำเภอ/จังหวัดที่ซับซ้อนทิ้งทั้งหมดเพื่อความรวดเร็วและลดขั้นตอนการคลิก
5. [x] แสดงแถบผลลัพธ์การค้นหาพิกัดโดยอัตโนมัติจาก IP แจ้งให้ผู้เรียนทราบอย่างเปิดเผย

## 🛠 Technical Tasks (Consent & Location API)
- [x] รวมสเตป ConsentScreen.jsx เป็นหน้าจอเดียวและจัดเลย์เอาต์ตามเกณฑ์ความง่ายของผู้สูงอายุ
- [x] พัฒนากลไกการระบุพิกัดโดยอัตโนมัติจำลอง IP Geolocation บนหน้าจอ
- [x] ปรับโครงสร้าง submit payload ส่งข้อมูลช่วงอายุและพิกัดที่พบแบบ IP-lookup เข้าสู่ตาราง `sessions` ใน Supabase
- [x] ทำการลบเมนูกรอกตัวเลือกภูมิศาสตร์และลบข้อมูล json ฐานตำบล/อำเภอ/จังหวัดออกเพื่อลดขนาดแอปพลิเคชัน
