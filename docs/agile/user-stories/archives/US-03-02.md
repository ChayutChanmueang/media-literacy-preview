# User Story: US-03-02 - การทดสอบในสภาพแวดล้อม LINE browser และเครือข่ายจำกัด (LINE Browser & Network Testing)

**Status:** ✅ Done
**Epic:** [Product Backlog](../01-product-backlog.md)
**Owner:** TBD
**Version:** 1.1 | **Last Updated:** 2026-07-15

---

## 📖 Description
**ในฐานะ** ผู้เรียนสูงวัยที่เปิดลิงก์จากข้อความ LINE
**ฉันต้องการ** ให้แอปพลิเคชันทำงานได้เสถียรบนเบราว์เซอร์ภายในแอป LINE (LINE in-app browser) แม้ในเขตที่อินเทอร์เน็ตมีความเร็วจำกัด
**เพื่อให้** การเรียนรู้ไหลลื่นไม่มีอาการค้าง ดับ หรือเสียงอ่าน/วิดีโอไม่เล่น

---

## ✅ Acceptance Criteria
1. [ ] ทดสอบการทำงานของคลิปวิดีโอและระบบเกมทั้งหมดบน LINE in-app browser ของเครื่องจริงทั้ง iOS และ Android
2. [ ] จำลองคุณภาพเครือข่าย 3G (ช้า/ไม่เสถียร) ในการทดสอบ เพื่อตรวจสอบเวลาโหลดและการส่ง event logs
3. [ ] ยืนยันว่าการเล่นเสียงอ่าน/การแสดงผลรูปภาพความละเอียดสูงไม่ก่อให้เกิดการหยุดทำงานของแอป

---

## 🛠 Technical Tasks (LINE & Network Testing)
- [ ] ทดสอบการกด Deep link จากแอป LINE บนมือถือ iOS และ Android
- [ ] ตรวจสอบการทำ Fallback ในกรณีกดเล่นวิดีโอหรือวิดีโอ YouTube iframe บล็อกในแอป LINE
- [ ] ปรับตั้งค่าการจองการสตรีมเสียง/โหลดรูปภาพให้ไม่เป็น blocking ในระบบเน็ตช้า
