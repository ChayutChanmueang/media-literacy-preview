## 📖 Description

**ในฐานะ** ผู้เล่นและผู้สูงอายุที่เล่นเกมปิดท้ายบทเรียน (G13)  
**ฉันต้องการ** ให้เกมมีชื่อเรียกอย่างเป็นทางการว่า **"ต่อไอติมฝึกสมอง"** และไม่มีข้อความคำภาษาอังกฤษว่า "ไม่มี game over" ปรากฏอยู่  
**เพื่อให้** ชื่อเกมดูน่าสนุก มีคุณสมบัติส่งเสริมการเรียนรู้ชัดเจน และปราศจากศัพท์ภาษาอังกฤษหรือคำที่ไม่จำเป็นสำหรับวัยเก๋า  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

1. **เปลี่ยนชื่อเกม:**  
   - ปรับชื่อเกม G13 จากเดิมให้กลายเป็น **"ต่อไอติมฝึกสมอง"** ทั้งในหน้า GameIntro, แดชบอร์ด, และส่วนหัวเรื่อง  
2. **ตัดคำว่า "ไม่มี game over":**  
   - ค้นหาและนำข้อความว่า *"ไม่มี game over"* (หรือข้อความอ้างอิงถึง Game Over) ออกจากคำอธิบายกติกาและหน้าต่างเกมทั้งหมด
