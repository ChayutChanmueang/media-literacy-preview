# User Story: US-CF-39 - G3 เกม AI: เปลี่ยนชื่อเป็น "AI หรือ ของจริง" ตัดคำเตือนบนรูป และตรวจสอบภาพกับคำตอบ

## 📖 Description

**ในฐานะ** ผู้สูงอายุและผู้เรียนที่กำลังฝึกเล่นเกมแยกแยะภาพ AI ในเกม G3  
**ฉันต้องการ** ให้เกมชื่อ **"AI หรือ ของจริง"** ที่ตรงไปตรงมา, ไม่มีข้อความคำเตือนหรือเฉลยกราย ๆ บนรูปภาพ, และภาพที่เฉลยว่า "รูปจริง" ต้องมีความคมชัด สมบูรณ์ และถูกต้องจริง ๆ  
**เพื่อให้** ไม่เกิดความสับสนในการวิเคราะห์ภาพ และได้เล่นอย่างมั่นใจโดยไม่มีป้ายเตือนมาบดบังหรือรบกวนสมาธิ  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

1. **เปลี่ยนชื่อเกม G3:**  
   - จากเดิม ("AI หรือ คน?" / "AI หรือเปล่า?") ให้ปรับเป็น **"AI หรือ ของจริง"** ทั้งในหน้า GameIntro และในแดชบอร์ดบทเรียน  
2. **ตัดข้อความบนรูปและเฉลย:**  
   - ปัจจุบันบริเวณภาพหรือในคำเฉลยมีข้อความว่า *"ภาพนี้จำลองโดย AI เพื่อการศึกษา"* ปรากฏอยู่ ให้นำสตริงหรือป้ายกำกับนี้ **ออกทั้งหมด**  
3. **ตรวจสอบรูปภาพกับคำตอบในคลังโจทย์ (G3 Dataset / 17 Questions):**  
   - ผู้ทดสอบแจ้งว่าพบโจทย์ภาพ "แม่ค้าขายผัก", "คนทำนา", และ "คนทำอาหาร" ซึ่งระบบเฉลยว่าเป็น **รูปจริง** แต่ลักษณะภาพอาจสร้างความสับสนหรือมีบางภาพเกิดข้อผิดพลาด  
   - ให้ตรวจสอบคลัง `src/data/g3-questions.json` และไฟล์ใน `public/assets/g3-images/` ยืนยันความสอดคล้องของค่า `isAi` และหากภาพใดดูคลุมเครือ ให้ทำการแก้ไขหรืออัปเดตไฟล์รูปจริงที่ชัดเจนยิ่งขึ้น

## ✅ Acceptance Criteria

1. [ ] ชื่อของเกม G3 ถูกเปลี่ยนเป็น `"AI หรือ ของจริง"` ในทุกจุดของ UI
2. [ ] ไม่มีข้อความ `"ภาพนี้จำลองโดย AI เพื่อการศึกษา"` ปรากฏอยู่บนแบนเนอร์รูปภาพหรือบนหน้าต่างเฉลย
3. [ ] โจทย์รูปภาพเกี่ยวกับแม่ค้าขายผัก คนทำนา และคนทำอาหาร ใน `g3-questions.json` มีข้อมูล `isAi` และไฟล์รูปภาพที่สมจริง ชัดเจน ถูกต้อง 100%
