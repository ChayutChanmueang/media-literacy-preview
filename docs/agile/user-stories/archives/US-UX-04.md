# User Story: US-UX-04 - รูปแบบการเรียนรู้ 2 หมวด (Flow & Manual Modes)

**Status:** ✅ Done
**Epic:** [Product Backlog](../../01-product-backlog.md)
**Owner:** NAPLAB Dev Team
**Version:** 1.0 | **Last Updated:** 2026-07-03

---

## 📖 Description
**ในฐานะ** ผู้สูงอายุและผู้นำทางกระบวนการเรียนรู้ (Facilitator)
**ฉันต้องการ** รูปแบบการดำเนินบทเรียน 2 หมวด ได้แก่ โหมดเรียนต่อเนื่องอัตโนมัติ (Flow) และโหมดเลือกบทเรียนอิสระ (Manual)
**เพื่อให้** ฉันสามารถเรียนรู้ตามขั้นตอนได้อย่างราบรื่นที่สุดโดยไม่ต้องคลิกกลับหน้าหลักบ่อยๆ หรือเลือกทบทวนรายบทเรียนที่ต้องการได้อย่างอิสระ

---

## ✅ Acceptance Criteria
1. [x] หน้าแดชบอร์ดแสดงตัวเลือกสลับโหมดการเรียนรู้แบบสองคอลัมน์สีสันตัดกันชัดเจน
2. [x] **หมวดที่ 1 (Flow Mode):** เมื่อจบแบบฝึกหัดใน Reward Screen ปุ่มหลักจะเปลี่ยนเป็น "เรียนบทเรียนถัดไป" นำพาไปยังบทถัดไปโดยอัตโนมัติ (และนำไปสู่หน้าเกียรติบัตรเมื่อจบวิชาที่ 3)
3. [x] **หมวดที่ 2 (Manual Mode):** เมื่อจบแบบฝึกหัด ปุ่มหลักจะแสดงข้อความ "กลับหน้าหลักแผนผังเรียน" เพื่อให้ผู้เรียนกลับมาสืบค้นในหน้าแผนที่บทเรียนตามปกติ
4. [x] ข้อมูลการเลือกโหมดถูกบันทึกและซิงค์ร่วมกับระบบ localStorage เพื่อไม่ให้ค่าหายเมื่อเปิดบน LINE Browser
