## Story

**ในฐานะ** ผู้สูงอายุที่ได้รับ SMS และสายโทรเข้าจากคนแปลกหน้าอยู่เป็นประจำ
**ฉันต้องการ** ฝึกคัดแยกว่าข้อความหรือเบอร์ไหนมาจากมิจฉาชีพผ่านเกมกระโดดข้ามแพที่เล่นง่าย
**เพื่อที่จะ** ตรวจสอบก่อนกดหรือก่อนรับสายได้ด้วยตัวเองในชีวิตจริง

## ขอบเขตของรอบนี้ (Prototype Scope)

รอบนี้ทำเป็น **prototype เพื่อทดสอบว่ากลไกสนุกและเล่นเข้าใจไหม** ยังไม่ใช่เวอร์ชันส่งมอบ:

**ทำในรอบนี้:**
- กลไกการเล่นครบวงจรตาม [design-g8.md](../../gdd/design-g8.md) — เลือกแพ, ห่วงยาง, โบนัส, เรือกู้ภัย, จบด่าน, สรุปดาว
- **ใช้ emoji และ SVG/CSS วาดเอง** เป็นกราฟิกชั่วคราว ยังไม่ต้องใช้ assets จริงจากทีมออกแบบ
- คลังโจทย์ตัวอย่างพอให้เล่นครบ 5 ด่าน (ยังไม่ผ่านการตรวจของทีมวิชาการ)
- เข้าทดสอบผ่าน [Dev Game Hub](./US-03-R4.md) ที่ `/dev/games`

**ยังไม่ทำในรอบนี้ (ยกไป Sprint 05):**
- assets จริง (ภาพตัวละคร, พื้นหลังทะเลสาบ, เสียงประกอบ)
- คลังโจทย์ฉบับสมบูรณ์ที่ทีมวิชาการ NAPLAB ตรวจแล้ว (เป้าหมาย SMS 20 + สายโทรเข้า 15)
- การผูกเข้าบทเรียนจริงใน `/lessons/[id]/game` และการบันทึกดาวลงระบบ
- ปุ่มเสียงอ่านข้อความ (รอผลตัดสินใจเรื่อง TTS vs เสียงอัด)

> ⚠️ **ไม่ผูกเข้า flow ผู้เรียนก่อนงานอบรมเชียงใหม่ 6–7 ส.ค.** — Sprint 03 มีงาน QA และ migration ค้างอยู่แล้ว เกมนี้เข้าถึงได้ทาง Dev Game Hub เท่านั้นจนกว่าทีมจะอนุมัติ

## Acceptance Criteria (Prototype)

- [x] เล่นได้ครบ 5 ด่าน ไล่ระดับ: ด่าน 1–2 SMS ล้วน → ด่าน 3 สายโทรเข้าล้วน → ด่าน 4–5 ผสมทั้งสองชนิด
- [x] แต่ละหน้าจอแสดงแพ **5 แถว** และ **กล้องไม่เลื่อนตามตัวละคร** — ฉากเลื่อนครั้งเดียวเมื่อกระโดดครบทั้งหน้าจอ (กติกาลดอาการเวียนศีรษะ)
- [x] แตะ 2 จังหวะ: แตะแพเพื่อขยายอ่านข้อความเต็ม → แตะปุ่มยืนยันจึงกระโดด (กันกดพลาดจากมือสั่น)
- [x] มีระบบห่วงยาง 5 หน่วย — กระโดดผิดเสีย 1 พร้อมการ์ดเฉลยจุดสังเกต, กระโดดถูกครบ 5 แพติดกันได้เพิ่ม 1 (สูงสุด 5)
- [x] ห่วงยางหมดแล้ว **ไม่มีหน้าจอแพ้** — เรือกู้ภัยพาไปทบทวนจุดสังเกตที่พลาด แล้วเติมห่วงยาง 3 กลับมาเล่นต่อจากแพเดิม
- [x] แถวที่ยังไม่ถึงคิวแตะไม่ได้ และตำแหน่งแพสลับใหม่ทุกครั้งที่ตอบผิด (กันเดาจากตำแหน่ง)
- [x] ไม่มีการจับเวลาใดๆ และไม่มีคำว่าแพ้/ผิดพลาดในเชิงตำหนิ — ใช้ ✓ ✗ กำกับคู่สีเสมอ
- [x] จบเกมส่งดาวผ่าน `onFinish(stars)` คำนวณจากสัดส่วนการกระโดดถูกครั้งแรก (≥80% = 3 ดาว, ≥50% = 2 ดาว, ต่ำกว่า = 1 ดาว)
- [x] ยิง event ครบตามที่ระบุใน design doc §10 (`game_start`, `raft_inspect`, `jump_correct`, `jump_wrong`, `ring_bonus`, `rescue_shown`, `level_complete`, `game_complete`)
- [x] รองรับ `prefers-reduced-motion` — ปิดการลอยของแพและเปลี่ยนการเลื่อนฉากเป็น fade
- [~] ตัวหนังสือ: การ์ดขยายอ่าน 22px, ปุ่ม 22px, touch target ผ่านทั้งหมด — **แต่ข้อความตัวอย่างบนแพเป็น 17px** เพราะต้องใส่แพ 5 แถวในหน้าจอเดียวโดยไม่ให้เลื่อน (ข้อความเต็มขนาด 22px อยู่ในการ์ดขยายอ่านซึ่งเป็นจุดที่ผู้เล่นใช้ตัดสินใจจริง) — ต้องให้ผู้สูงอายุจริงลองอ่านใน User Testing ก่อนสรุปว่ารับได้ไหม
