## 📖 Description

**ในฐานะ** ผู้เรียนที่เล่นเกม G6 "จำลองแชท LINE"
**ฉันต้องการ** เลือกตอบสนองต่อข้อความด้วยตัวเลือก "ตอบกลับ" หรือ "ไม่ตอบกลับ" แทนระบบสามตัวเลือกเดิม
**เพื่อให้** การตัดสินใจชัดเจน ตรงประเด็น และสอดคล้องกับบริบทการแชทจริง

---

## ✅ Acceptance Criteria

1. [x] หน้าจอใน G6 ปรากฏปุ่มตัวเลือกเพียง 2 ตัวเลือก: "ตอบกลับ" และ "ไม่ตอบกลับ" แทนระบบสามตัวเลือกเดิม (ปฎิเสธ/ยอมรับ/นิ่งเฉย)
2. [x] ปุ่มมีขนาดใหญ่, อ่านง่าย และรองรับการทำงานบนหน้าจอขนาดต่างๆ
3. [x] Game logic, คะแนน, และคำชี้แจงเฉลยปรับเปลี่ยนสอดคล้องกับระบบ 2 ตัวเลือกใหม่
4. [x] ตัวเลือก "ตอบกลับ" ถูกนับเป็นตัวเลือกที่ไม่ควรทำ และ "ไม่ตอบกลับ" นำไปสู่การตัดสินใจที่ปลอดภัยและถูกต้อง
5. [x] หน้าจอใน G6 ในสถานการณ์ทั้งหมดใช้งานระบบตัวเลือกนี้อย่างทั่วถึงและสมบูรณ์
