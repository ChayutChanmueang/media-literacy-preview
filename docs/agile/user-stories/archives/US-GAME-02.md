## 📖 Description
**ในฐานะ** ผู้สูงอายุ
**ฉันต้องการ** เล่นเกมตอบคำถามวิเคราะห์จุดน่าสงสัย "จับสัญญาณมิจ" (G2) ในรูปแบบ Content-Focused Quiz
**เพื่อให้** สามารถวิเคราะห์สาร สังเกตลักษณะเด่นของข้อความ/SMS หลอกลวงเบื้องต้นได้ และระงับความเชื่อข้อมูลข่าวสารอย่างรวดเร็ว

---

## ✅ Acceptance Criteria
1. [ ] แสดงโจทย์สถานการณ์ภัยออนไลน์จากช่องทางต่างๆ (เช่น รูปภาพโพสต์เฟซบุ๊กปลอม, ข้อความ SMS แนบลิงก์, หรือข้อความเร่งรัดทวงหนี้) อย่างน้อย 4 สถานการณ์
2. [ ] มีตัวเลือกปุ่มกดขนาดใหญ่ 3 ตัวเลือกอย่างชัดเจน: "มิจฉาชีพ / ปลอม", "ปลอดภัย / จริง" หรือ "ไม่แน่ใจ / ต้องเช็กก่อน"
3. [ ] แสดงคำเฉลยทันทีพร้อมระบบตีกรอบระบุจุดน่าสงสัยในเชิงวิชาการเพื่อสอนความรู้ (เช่น โดเมนลิงก์แปลกปลอม .xyz, เบอร์ผู้ส่งแปลกๆ)
4. [ ] เมื่อผู้เล่นกดยืนยันตัวเลือก "ไม่แน่ใจ" ระบบจะแสดงผลคำชมเชิงบวกชื่นชมความรอบคอบและให้คำแนะนำขั้นตอนการตรวจเช็กข่าวสารเพิ่มเติม
5. [ ] ไม่มีระบบการแพ้แบบจับเวลา เพื่อให้ผู้สูงอายุอ่านทำความเข้าใจและแยกแยะได้อย่างอิสระ

- [ ] พัฒนาหน้าแสดงผลเฉลยที่มีกรอบไฮไลท์เน้นจุดสังเกตบนรูปภาพ
