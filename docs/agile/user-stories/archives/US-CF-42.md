## 📖 Description

**ในฐานะ** ผู้สูงอายุและผู้เรียนที่เพิ่งเล่นเกมต่อไอติมฝึกสมองเสร็จและคลิกปุ่ม "เสร็จสิ้นบทเรียน"  
**ฉันต้องการ** พบกับหน้าจอแสดงเกียรติยศและความยินดีที่ระบุว่า **"เก่งมากท่านได้เรียนรู้ครบถ้วน"** ก่อนจะกลับสู่เมนูหลัก  
**เพื่อให้** เกิดความรู้สึกภาคภูมิใจว่าตนเองได้เดินทางผ่านหลักสูตรและทำภารกิจสำเร็จสิ้นสุดแล้วจริง ๆ (Closure & Positive Reinforcement)  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

- ในปัจจุบัน เมื่อผู้เล่นกดปุ่ม **"เสร็จสิ้นบทเรียน"** ในหน้าต่างสรุปผลของ G13 ระบบจะสั่ง redirect ย้อนกลับไปยัง `/lessons` (Start Menu) ทันที (ตาม Spec ของ [US-CF-06](./US-CF-06.md) และ [US-CF-32](./US-CF-32.md))  
- ลูกค้าปรารถนาให้ **เพิ่มหน้าจอใหม่อีก 1 หน้า** เป็นจุดพัก/ประกาศความยินดี (Completion / Victory Screen)  
- หน้าจอนี้ต้องมีองค์ประกอบ:  
  1. ข้อความเชิดชูหลัก: **"เก่งมากท่านได้เรียนรู้ครบถ้วน"** (ตัวหนังสือขนาดใหญ่พิเศษ สีสว่าง โดดเด่น)  
  2. กราฟิกเสริมบรรยากาศความน่าชมเชย (เช่น ดวงดาว ถ้วยรางวัล ดอกไม้ หรือไอคอนเกียรติยศ)  
  3. ปุ่มนำทางด้านล่างเพียง 1 ปุ่ม คือ **"กลับไปหน้าหลัก"** สำหรับกลับไปยัง Start Menu

---

## ✅ Acceptance Criteria

1. [x] หลังคลิก "เสร็จสิ้นบทเรียน" ที่จบ G13 ในระบบ Flow ผู้ใช้งานจะถูกพาไปยังหน้าจอ completion ใหม่ แทนการย้อนเข้า Start Menu ทันที
2. [x] หน้าจอใหม่แสดงข้อความ `"เก่งมากท่านได้เรียนรู้ครบถ้วน"` ด้วยฟอนต์ $\ge 24\text{px}$ จัดกึ่งกลาง สวยงาม เป็นสัดส่วน
3. [x] มีปุ่มกดที่ล่างจอเพียง 1 ปุ่ม คือ **"กลับไปหน้าหลัก"** ซึ่งกดแล้วพาผู้ใช้กลับเข้าสู่ `/lessons` หรือ Start Menu อย่างสมบูรณ์ โดยไม่มีปุ่ม "เล่นทบทวน" หรือ action อื่น
4. [x] รองรับการทำงานแบบ Single-Screen ไม่เลื่อน (Zero-scroll) บนหน้าจอโทรศัพท์มือถือผู้สูงอายุ
