## 📖 Description

**ในฐานะ** ผู้เล่นและผู้สูงอายุในมินิเกมจำลองแชทไลน์ (G6)  
**ฉันต้องการ** คำอธิบายและข้อคำถามที่กระชับ สื่อความง่าย รวมถึงตัวเลือกตอบโต้แบบ **"กดตอบทันที"** และ **"หยุดคิด"**  
**เพื่อให้** สอดคล้องกับพฤติกรรมการตัดสินใจจริงในชีวิตประจำวัน (หยุด-คิด-ถาม-ทำ) และไม่รู้สึกสับสนกับตัวเลือกเดิม  

---

## 🎯 สิ่งที่ต้องแก้ / รายละเอียดงาน

1. **ปรับข้อความคำแนะนำวิธีเล่น / คำสั่งการสังเกต:**
   - จากเดิม: *"สังเกต/แตะจุดสีแดง (Red Flag) ที่น่าสงสัย"*  
     👉 **แก้เป็น:** *"สังเกตจุดที่น่าสงสัยในข้อความ"*
   - จากเดิม: *"เลือกว่าจะตอบกลับข้อความนี้อย่างไร"*  
     👉 **แก้เป็น:** *"หลังจากอ่านข้อความแล้วคุณจะทำอย่างไร"*
2. **ปรับประโยคคำถามก่อนเลือกตอบและปุ่มตัวเลือก:**
   - จากเดิม: *"อ่านข้อความข้างบนแล้ว ท่านจะเลือก "ตอบกลับ" หรือ "ไม่ตอบกลับ" ดี?"*  
     👉 **แก้เป็น:** *"อ่านข้อความในไลน์นี้แล้ว ท่านจะทำอย่างไร"*
   - **เปลี่ยนปุ่มตัวเลือกทั้ง 2 ปุ่มเป็น:**  
     • **กดตอบทันที** (ตัวเลือกที่เสี่ยง / ไม่ปลอดภัย)  
     • **หยุดคิด** (ตัวเลือกที่ปลอดภัย / ถูกต้องตามคำขวัญ)

## ✅ Acceptance Criteria

1. [x] คำสั่งและข้อความชี้แนะใน G6 เปลี่ยนเป็น `"สังเกตจุดที่น่าสงสัยในข้อความ"` และ `"หลังจากอ่านข้อความแล้วคุณจะทำอย่างไร"`
2. [x] ประโยคคำถามที่หน้าตัดสินใจเปลี่ยนเป็น `"อ่านข้อความในไลน์นี้แล้ว ท่านจะทำอย่างไร"`
3. [x] ปุ่มตัวเลือก 2 ปุ่มเปลี่ยนจาก ตอบกลับ/ไม่ตอบกลับ เป็น **`"กดตอบทันที"`** และ **`"หยุดคิด"`** โดยปุ่ม "หยุดคิด" เป็นการกระทำที่ระบบเฉลยถูกต้องและชมเชย
4. [x] ลิงก์ตรรกะคะแนนและ analytics logging ยังทำงานได้ตามปกติ
