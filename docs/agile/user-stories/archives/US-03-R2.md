> ℹ️ **หมายเหตุสำคัญ:** เรื่องย่อยนี้ถูกยกเลิก (Cancelled) ตามมติของทีมโครงการ เนื่องจากไม่มีความจำเป็นต้องทำเอกสารประสานงานขอโดเมนใหม่ แต่จะใช้วิธีทางเทคนิคในการตั้งค่า URL Redirect (ตามงาน [US-03-04](./US-03-04.md)) แทนเพื่อความรวดเร็วและไม่พึ่งพาเจ้าหน้าที่ภายนอก


## 📖 Description
**ในฐานะ** ผู้พัฒนาโครงการและทีมประสานงาน
**ฉันต้องการ** เอกสารเสนอเปลี่ยนชื่อโดเมนจาก subdomain แหล่งทุนเดิมไปเป็นชื่อที่พิมพ์และจดจำง่าย
**เพื่อให้** ผู้สูงอายุสามารถเข้าถึงแอปพลิเคชันได้ง่ายขึ้น และพร้อมสำหรับส่งมอบให้เจ้าหน้าที่ไอทีดำเนินการต่อ

---

## ✅ Acceptance Criteria
1. [ ] จัดทำเอกสารเปรียบเทียบและข้อเสนอชื่อโดเมนที่เหมาะสม (จำง่าย สั้น ไม่ซับซ้อน)
2. [ ] ระบุขั้นตอนและพารามิเตอร์ DNS Records (A, CNAME) สำหรับเชื่อมต่อ Vercel หรือเซิร์ฟเวอร์หลักให้ชัดเจนตามแนวทาง [dns-setup.md](../../wiki/dns-setup.md)
3. [ ] ได้รับข้อมูลประสานงานและจัดส่งเอกสารให้เจ้าหน้าที่ผู้ดูแลระบบฝั่งแหล่งทุนพิจารณาอนุมัติ

## 🛠 Technical Tasks (Domain Handoff)
- [ ] ร่างข้อเสนอชื่อโดเมนใหม่ที่จำง่ายสำหรับผู้สูงวัย
- [ ] ตรวจเช็คค่าคอนฟิก DNS (CNAME, SSL) ในคู่มือ `wiki/dns-setup.md`
- [ ] จัดส่งรายละเอียดข้อเสนอและประสานงานกับผู้ดูแลเครือข่ายภายนอก
